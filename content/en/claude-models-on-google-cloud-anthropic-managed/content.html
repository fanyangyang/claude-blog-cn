Claude Models on Google Cloud (Anthropic managed) is now generally available, giving Google Cloud customers the full set of Claude Platform features, with Google Cloud IAM credentials, billing, and commitment retirement. Claude also remains available via the Google managed offering, where Google is the data processor.

Access the complete Claude Platform on Google Cloud

With the Anthropic managed offering, Google Cloud customers now receive the full set of Claude API features, with new features and betas shipping the same day they go live on the native Claude Platform.

The Anthropic managed offering works with existing Google Cloud IAM credentials, so teams can stay within the tools and permissions they already manage. Billing is through a single Google Cloud invoice and Claude usage draws down your existing Google Cloud commitment.

Claude Models on Google Cloud (Anthropic managed) is currently available with US and Global endpoints.

今天，我们推出了直接从 Slack 向 Claude Code 委派任务的能力。该功能目前以研究预览版（research preview）的形式进行 Beta 测试，让 Claude 可以轻松地将 Slack 对话中的上下文带入编程会话。

从讨论到实现

工程工作的关键上下文往往存在于 Slack 中，包括 Bug 报告、功能请求和工程讨论。当 Bug 报告出现或队友需要修复代码时，你现在可以在 Slack 中 @Claude，它会利用周围的上下文自动启动一个 Claude Code 会话。适用场景包括：

  • Bug 调查与修复：让 Claude 在 Bug 被报告后立即调查并修复。
  • 快速代码评审与修改：让 Claude 根据团队反馈实现小功能或重构代码。
  • 协作调试：当团队讨论提供了关键上下文（如错误复现步骤或用户报告）时，Claude 可以利用这些信息来指导其调试思路。

自动将任务路由到 Claude Code

此功能是对我们现有的 Slack 版 Claude 应用的扩展，允许 Claude 将任务转发给网页版 Claude Code。当你在 Slack 中 @Claude 时，Claude 会审阅你的消息，判断这是否是一项编程任务。如果是，将自动创建一个新的 Claude Code 会话。你也可以手动告诉 Claude 将请求作为编程任务处理。

Claude 会从 Slack 中最近的频道和消息串中收集上下文，注入到 Claude Code 会话中。Claude 会根据你在网页版 Claude Code 中已授权的代码仓库，利用这些上下文自动选择在哪个仓库上执行任务。

随着 Claude Code 会话的推进，Claude 会向你的 Slack 消息串回传状态更新。任务完成后，你会收到一个指向完整会话的链接，可以在其中查看变更，以及一个用于创建 pull request 的直达链接。

开始使用

要开始使用，请先通过 Slack App Marketplace 在你的 Slack 工作区中安装 Claude 应用。安装完成后，使用你的 Claude 账户登录，然后就可以在编程任务中 @Claude。你需要拥有 网页版 Claude Code 的访问权限，Claude 才能路由编程任务。

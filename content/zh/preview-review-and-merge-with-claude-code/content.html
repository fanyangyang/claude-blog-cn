今天，我们发布了一系列 Claude Code 改进：预览运行中的应用、自动审查代码、自动修复并合并 PR，以及在桌面端、移动端和 CLI 之间无缝切换。这些更新共同帮你减少围绕代码的琐碎劳动，把更多时间花在你真正享受的部分。

写代码，即刻看到它运行

Claude Code 桌面端现在可以启动开发服务器，并直接在桌面界面中预览你正在运行的应用。Claude 会查看 Web 应用界面、读取控制台日志、捕获错误并持续迭代，你不必再切换到浏览器，手动向 Claude 描述你看到的内容。你还可以在预览中选中界面元素，把反馈直接传给 Claude 继续迭代。

推送之前先审查代码

当改动看起来没问题后，可以使用全新的“Review code”按钮让 Claude 进行审查。Claude 会检查你的本地 diff，并直接在桌面端的 diff 视图中留下评论，突出 Bug、提出建议、就地指出潜在问题。 

在代码离开你的机器之前，你就有了一双“第二只眼”来发现明显问题，还可以让 Claude 处理这些行内评论并修改代码。

不离开应用就能盯住 PR

对于托管在 GitHub 上的代码，你还可以直接在桌面应用中监控 Pull Request 的状态。在你开启一个 PR 之后，Claude Code 会通过底层的 GitHub CLI 跟踪其状态，包括 CI 检查的通过与失败。

你还可以开启自动修复（auto-fix），让 Claude 自动尝试修复它检测到的任何 CI 失败。如果开启了自动合并（auto-merge），Claude 还会在所有检查通过后尝试合并 PR。 

你可以在一个 Claude Code 会话中处理某个任务并开启 PR，然后接着去做新任务。后台的 Claude Code 会持续监控原任务的 PR，并尝试修复 CI 失败，这样等你切回那个任务时，PR 已经可以合并（或已被自动合并）。

从上次中断的地方继续

会话现在可以跟着你走。当你在 CLI 中启动 Claude Code 会话后，运行 /desktop 即可把完整会话上下文带入桌面应用。

你也可以使用“Continue with Claude Code on the web”按钮，把本地桌面应用的会话迁移到云端。在桌面应用上开始一个任务，然后通过 Claude 移动应用在网页端或手机上继续处理。

开始使用

这些更新现已面向所有用户开放。更新或下载Claude Code 桌面端即可开始。详细信息请查阅文档。

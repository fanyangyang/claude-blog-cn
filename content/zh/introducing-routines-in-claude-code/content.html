今天，我们以研究预览版的形式在 Claude Code 中推出 Routines（例行任务）。一个 routine 是你只需配置一次的 Claude Code 自动化——包括提示词、仓库和连接器——之后可以按计划运行、由 API 调用触发或响应事件。Routines 运行在 Claude Code 的 Web 基础设施上，因此不依赖你的笔记本电脑是否开着。

开发者已经在用 Claude Code 自动化软件开发周期，但在此之前，cron 任务、基础设施以及 MCP 服务器之类的额外工具都得自己管理。Routines 自带对你的仓库和连接器的访问能力，所以你可以把自动化打包好，设成按计划运行或按触发器运行。

工作原理

定时 routine

给 Claude Code 一条提示词和一个执行频率（每小时、每晚或每周），它就会按计划运行：

Every night at 2am: pull the top bug from Linear, attempt a fix, and open a draft PR.

如果你此前在 CLI 中使用 /schedule，那些任务现在就是定时 routine。 

API routine

你也可以把 routine 配置为由 API 调用触发。每个 routine 都有自己独立的端点和认证令牌。POST 一条消息，就会返回一个会话 URL。把 Claude Code 接入你的告警系统、部署钩子、内部工具——任何能发 HTTP 请求的地方：

Read the alert payload, find the owning service, and post a triage summary to #oncall with a proposed first step.

如果你是在 Claude 平台上构建云端托管的 agent，而不是自动化 Claude Code，那么 Claude Managed Agents 的定时部署可以为你的 agent 提供同样的按计划运行能力。

Webhook routine，首先支持 GitHub

为 routine 设置订阅，使其在 GitHub 仓库事件发生时自动启动。Claude 会为每一条匹配你过滤条件的 PR 创建新会话并运行你的 routine。

Please flag PRs that touch the /auth-provider module. Any changes to this module need to be summarized and posted to #auth-changes.

Claude 会为每个 PR 开一个会话，并持续把该 PR 的后续更新喂给这个会话，以便它处理评论和 CI 失败之类的后续事项。

我们计划在未来把基于 webhook 的 routine 扩展到更多事件源。

团队都在构建什么

在早期创建 routine 的用户中，已经浮现出一些常见模式：

定时 routine

  • 待办管理：每晚对新 issue 做分类、打标签、指派，并把摘要发到 Slack
  • 文档漂移：每周扫描已合并的 PR，标记引用了已变更 API 的文档，并提开更新 PR

API routine

  • 部署验证：你的 CD 流水线在每次部署后发请求，Claude 对新构建跑冒烟检查、扫描错误日志中的回归，并向发布频道发布"通过/不通过"结论
  • 告警分诊：把 Datadog 指向 routine 的端点，Claude 拉取调用链、与近期部署做关联，赶在值班人员点开告警页之前就备好修复草稿
  • 反馈处理：文档反馈小组件或内部仪表盘把报告发过来，Claude 带着该 issue 的上下文对仓库开启会话并起草改动

GitHub routine

  • 库移植：每有一个 PR 合并进 Python SDK，就触发一个 routine 把改动移植到对应的 Go SDK，并开一个配对的 PR
  • 定制代码审查：PR 打开时，按你们团队自己的安全与性能清单跑一遍，在人工审查者介入前留下行内评论

开始使用

Routines 从今天起面向已启用 Claude Code on the web 的 Pro、Max、Team 和 Enterprise 计划的 Claude Code 用户开放。前往 claude.ai/code 创建你的第一个 routine，或在 CLI 中输入 /schedule。

Routines 消耗订阅用量限额的方式与交互式会话相同。此外，routines 还有每日限额：Pro 用户每天最多运行 5 个 routine，Max 用户每天最多 15 个，Team 和 Enterprise 用户每天最多 25 个。超出限额后，你可以通过额外用量（extra usage）运行更多 routine。更多信息请查阅文档。

Model Context Protocol 的第五个规范版本 MCP 2026-07-28，于今日正式发布。最新规范将 MCP 迁移到无状态核心，同时强化了授权机制，并正式转正了官方扩展。相关支持正在各 Claude 产品中陆续推出。

MCP 有哪些新内容‍

MCP 的月度 SDK 下载量近期突破 4 亿次，今年增长了 4 倍，已成为连接 AI 智能体与应用的行业标准。MCP 2026-07-28 是迄今为止最重要的规范版本之一：

无状态核心。MCP 从双向有状态协议转向请求/响应模型。服务器现在可以部署在 serverless 和边缘基础设施上。这简化了为 Claude 构建 MCP 服务器的体验，也便于在采用规模增长时进行扩展。 

标准化扩展。MCP Apps 和 Tasks 现在通过带版本管理的扩展框架发布，为开发者提供了一条正式途径来添加交互式 UI、长时间运行任务等能力，而无需改动核心协议。

授权强化。授权机制现在与生产环境的 OAuth 2.0 和 OIDC 部署保持一致，MCP 服务器可以无需变通方案即可接入 Entra 或 Okta 等企业身份系统。

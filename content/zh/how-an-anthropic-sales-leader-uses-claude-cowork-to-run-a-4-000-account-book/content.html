销售管理岗位的核心是做判断：把团队的时间投向哪里，以及向管理层如何汇报本季度的走势。而围绕这些决策的配套工作——比如从四个系统里拼凑数据、每次数字刷新后重新对齐基线——过去占据了我一周中的大部分时间。Claude Cowork 改变了这个局面：数据的组装和格式化都由它来处理，我得以把更多时间投入到客户沟通和战略决策上。

我负责 Anthropic 美国中型市场（mid-market）的 go-to-market，也就是说我要负责 4,000 个客户账号，分布在“中型市场科技公司”和“行业客户”两大板块。中型市场指那些已经不再是创业公司、但还没成为大型企业的科技公司；行业客户则涵盖其余所有领域，从金融服务、医疗到零售和制造业。

我的工作有三个节奏：每天的客户通话准备、每周向 Anthropic 销售管理层提交的预测汇总，以及针对全部 4,000 个账号的季度性区域和潜在客户名单工作。每一项单独做都不轻松，而要把三件事同时做好，过去几乎不可能。

我试过 Claude Code，但始终习惯不了在终端里工作。Claude Cowork 把同样的引擎包装进了一个我能顺手的界面。那一刻我豁然开朗：我终于有办法把工作交出去，并且相信它能被完成。

我在 Claude Cowork 里每天、每周、每季度跑什么

Claude Cowork 为我省下的时间，大部分来自每天约 90 分钟的小型效率提升，也就是那些它替我运行的微优化。

每天早晨，一个定时任务会运行一个 skill，扫描我的 Google 日历，为每一个缺少会议室的外部会议预订会议室。另一个 skill 在每次会议前运行客户通话准备：从 BigQuery 拉取消费数据、从 Salesforce 拉取商机进展，汇总成一份简报，等我打开笔记本电脑时已经在那里等我了。调度器本身比 skill 是更大的解锁——一旦准备工作不再是一条我必须记得去敲的命令，而是自动运行，我就再也不会忘记它。

更高一层的是周五的预测，每周为我节省约三个小时。一个定时 skill 从 Salesforce 的 Forecast 标签页拉取商机记录和已提交的预测数据、从 BigQuery 拉取 token 消费、再从若干内部文档中提取笔记，然后按照 Anthropic 销售管理层要求的准确格式组装成一页式网页报告：核心指标、重点商机、上升与下滑的项目，以及从每位一线经理那里汇总上来的预测快照。这个 skill 会在周一预测电话会议之前把页面部署到一个内部共享链接。我周一的任务是补充评述：Claude 负责呈现“是什么”，我负责“为什么”。

我在 Claude Cowork 里跑过的最大项目，是针对整个中型市场板块的客户倾向评分。每个财年，名单里的每个账号都需要一个分数，帮助对应的 AE（客户经理）排定区域优先级。在以前的公司和岗位，这类工作要在 RevOps、FP&A 和市场团队之间耗费数百小时。我一个晚上就做完了。

我先与 Claude 一起定义了两套五维度评分标准：一套用于科技类账号，一套用于行业类账号。科技类账号的维度包括 agent 机会、内部转型、AI 投入度、相对现有消费的空白空间、以及行业匹配度。行业类账号采用另一套标准，维度包括知识工作者密度（例如律所通常非常高，而制造业较低，因为大量员工在车间），以及通过公司招聘页面上 AI 相关职位出现的频次来衡量的公开 AI 投入。

标准确定后，我把这份 4,000 个账号的名单交给 Claude Cowork。它通宵运行，结合深度网络调研、Salesforce 数据和 BigQuery 数据，逐个为每个账号打分，并为每个维度给出分数和书面理由。接着我让 Claude Cowork 基于结果构建了一个交互式仪表盘。每位 AE 点进自己区域的扇区，就能看到账号按分数排列，以及每个维度的评分理由；把鼠标悬停在某个账号上，还会浮现潜在用例和可供参考的对标案例。这个仪表盘把评分从一次数据演练变成了一件真正能用的销售工具。

所有提示词都不涉及技术细节。模式就是：告诉 Claude 按哪些维度打分，跑一个测试区域，检查输出，调整权重（“我觉得 D4 的权重可能偏高了，调低一点”），再跑下一个区域。 

Claude Cowork 为什么对我有效

让 Claude Cowork 真正在我这里扎根的是界面。提示词就像普通的英文句子，输出落在我已经在用的格式里（文档、网页和 Salesforce 更新），而且内置了“人在环中”模式——Claude 提案、我批准，然后才发布。 

销售行业里有很多人正是为了客户沟通才入行的。Claude Cowork 能把这些时间还给他们。

销售团队应该从哪里入手

我自己一周的经验里，有两个模式值得带回销售团队。

第一，把准备工作放进日程。定时任务会自己运行，那些单件不大、合计耗时可观的小事，我再也不用记着去做。把团队要求的固定格式写进 skill 也很重要：我的预测报告恰好就是管理层阅读的版式，所以我周一的时间都花在评述上而不是排版上。如果你需要起点，Anthropic 的 Sales 插件自带一组基础 skills，包括通话准备那个。这些 skills 本来就是设计出来供你定制、以匹配团队实际工作方式的。

第二，把大型战略项目作为 Claude Cowork 的通宵例行任务来跑。4,000 个账号的评分是最典型的例子，但同样的思路也适用于 TAM 测算、客户调研、薪酬基准对标——任何过去因为团队腾不出时间而一拖再拖的事。有需要的话，第二天早上再润色提示词就行。

在 Claude Cowork 出现之前，数据组装、报告排版，以及数字一变就得重新对齐基线，填满了我的一周。现在，这些时间都回来了，我可以投入到真正推动业绩的战略和客户关系工作上。

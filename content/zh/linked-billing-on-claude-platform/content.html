今天，我们在 Claude Platform 上推出 beta 版的关联计费（linked billing）。编码智能体、工作流自动化工具等第三方平台，可以让终端客户为 Claude API 用量付费，而无需共享 API 密钥。终端客户保留其现有的 Anthropic 账单设置并自行设定支出限额，平台则获得一种更简单、更安全的方式来提供 Claude。

比共享 API 密钥更安全的选择

在第三方平台上为 Claude API 用量付费，通常意味着要共享一个 API 密钥，而密钥的作用就像密码：任何持有密钥的人都可以发起计入该客户账单的请求，因此平台必须妥善保管它。

借助关联计费，客户改为关联自己的 Claude Platform 组织，用量直接计入该组织。整个过程没有任何 API 密钥的交接，因此平台无需存储、加密或轮换客户的密钥，客户的 API 密钥也永远不会离开其组织。

平台可以查看每个已关联客户的用量。客户可以逐个批准要关联的平台、设置支出限额，并随时解除关联。

平台无需自建计费体系，即可向客户提供 Claude

关联计费为平台提供了向客户提供 Claude 的新方式。平台发送请求，Anthropic 直接向终端客户计费。借助关联计费，平台可以：

  • 更快上线。 Anthropic 托管审批流程和计费，平台无需构建计量或开票系统。
  • 按客户了解用量。 在 Console 中，或通过 Usage and Cost Analytics API（beta）以编程方式，获取每个已关联客户的请求数、token 用量和所用模型。
  • 决定由谁付费。 对每个请求分别决定由平台还是终端客户付费，平台因此可以按产品或实例把 Claude API 成本转嫁给客户，或自行承担部分功能。

客户获得更多可见性与控制权

客户可以通过 Anthropic 的托管流程轻松关联平台。随后，他们可以从现有的 Anthropic 承诺用量中扣减，或按用量付费。借助关联计费，客户还可以：

  • 一次关联，覆盖整个组织。 拥有 Owner、Admin 或 Billing 角色的 Console 用户批准关联后，个人开发者与大型团队都能以相同方式使用。
  • 为每个平台设置限额。 客户可以为每个平台设置月度支出限额，也可以设置适用于所有平台的默认限额。
  • 看清 API 支出流向。 Console 会显示每个已关联平台的支出。
  • 随时解除关联。 客户可以直接在 Console 中解除关联。

请求在平台所属的组织中运行，因此客户组织内的设置（如 IP 允许列表、加密密钥和数据保留策略）不会生效。

目前支持关联计费的平台包括 Asana、ClickHouse、Factory、Gumloop、Harness、Higgsfield AI、Kilo Code、Linear、Major、Mintlify、Omni、OpenArt、Niteshift、Railway、Ramp、Runlayer、Tessera、Tines 和 Warp。

开始使用

关联计费今日起在 Claude Platform 上以 beta 版提供。第三方平台可以在 Console 中创建应用，并按照文档中的步骤添加支持。Claude Platform 客户可以从任意受支持的平台关联其组织，并在 Claude Marketplace 上找到提供关联计费的平台。

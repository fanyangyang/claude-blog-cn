Computer Use、Skills API 和 Files API 今日在 Claude Platform 上全面可用。Computer Use 还新增了一个浏览器使用工具，适用于在 Web 应用中工作的 AI 代理。

在 Claude Platform 上构建 AI 代理

Computer Use 让你可以构建能够操作可见软件的 AI 代理。新的 浏览器使用工具 将这一能力扩展到 Web。

Skills API 和 Files API 让你可以将专业知识和文档赋予代理。技能是一个包含指令、脚本和模板的文件夹，Claude 仅在任务需要时加载。

全面可用后的新功能

  • Computer Use：更新后的工具让 Claude 每次可执行多个操作。Computer Use 现在也符合 HIPAA 监管工作负载要求。
  • 浏览器使用工具：新增工具，使用多操作轮次并增加页面结构。
  • Skills API：更简单的 API，用于上传和管理自己的技能版本。
  • Files API：自动文件过期、5 倍更高的速率限制，以及每个组织 1 TB 的存储空间。

Computer use、Skills API 和 Files API 即日起在 Claude Platform 上正式全面可用。Computer use 还新增了 browser use 工具，面向在 Web 应用中工作的 agent。它们合在一起，让你可以构建能操作软件、运用团队专长并返回成品文件的 agent。

在 Claude Platform 上构建 agent

Computer use 让你构建能操作“看得见”的软件的 agent。给定一张截图，agent 会像坐在键盘前的人一样点击、输入和滚动。因此它能在从未为自动化设计的应用中工作。新增的 browser use 工具把这一点延伸到网页。除了截图，agent 还会读取页面结构，并对具体字段或按钮采取行动，而不是对着屏幕上的某个位置操作。

Skills API 和 Files API 让你把专长和文档交给这个 agent。Skill 是包含指令、脚本和模板的文件夹，Claude 只在任务需要时加载。通过 Skills API ，你可以上传并版本管理自己的 skill，再把它们附加到任意请求。它们运行在 Claude 的代码执行沙箱中，因此你无需自行托管。Files API 是 agent 读写文档的存储：一次上传 PDF 或电子表格，之后用 ID 引用而不必重新发送，并下载 agent 创建的文件。

假设你在构建一个理赔 agent。它从 Files API 读取受理文档，遵循一份编码了团队申报流程的 skill，用 browser use 工具在保险公司的网页门户完成提交，再把确认结果存回为文件。已经全面可用的 code execution 和 web search，可以进入同一个循环。

正式发布带来的变化

  • Computer use：更新后的 computer use 工具让 Claude 每轮可以执行多项操作，而不再每次模型调用只做一步，因此任务用更少调用、更短时间即可完成。Computer use 现在也符合我们 BAA 下受 HIPAA 监管的工作负载。 
  • Browser use 工具：即日起随 computer use 新增。它使用同样的多操作轮次，并加入页面结构，因此 agent 定位网页元素比仅靠像素更可靠。
  • Skills API：更简洁的 API，用于上传并版本管理你自己的 skill。
  • Files API：自动文件过期、5 倍更高的速率限制，以及每个组织 1 TB 存储。

开始使用

computer use 工具、browser use 工具、Skills API 和 Files API 现已在 Claude Platform 上可用。Skills API 和 Files API 也可通过 Microsoft Foundry 使用，更新后的 computer use 和 browser use 工具即将登陆 Google Cloud 的 Vertex AI。现有的 beta 集成在你迁移期间仍然可用。请参阅 computer use、browser use 工具、Skills API 和 Files API 的文档开始使用。

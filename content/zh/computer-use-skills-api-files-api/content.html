Computer use、Skills API 和 Files API 今天起在 Claude 平台正式发布（GA）。Computer use 还为在 Web 应用中工作的智能体新增了浏览器使用工具。三者结合，让你可以构建能够操作软件、运用团队专业知识并交付成品文件的智能体。

在 Claude 平台上构建智能体

Computer use 让你能够构建可以操作它们“看得见”的软件的智能体。给它一张屏幕截图，智能体就会像坐在键盘前的人一样点击、输入和滚动。这使其能够在那些从未为自动化而设计的应用中工作。全新的浏览器使用工具（browser use tool）将这一能力扩展到了 Web。除了截图之外，智能体还能读取页面结构，直接作用于特定字段或按钮，而非屏幕上的某个坐标位置。

Skills API 和 Files API 让你可以把你的专业知识和文档交给智能体。Skill 是一个由指令、脚本和模板组成的文件夹，只有当任务需要时 Claude 才会加载它。通过 Skills API，你可以上传自己编写的 Skills 并进行版本管理，然后将其附加到任何请求中。它们在 Claude 的代码执行沙箱中运行，因此无需你自行托管。Files API 则是智能体读取和写入文档的存储服务：只需上传一次 PDF 或电子表格，之后的请求中通过 ID 引用它即可，无需重复发送，还可以下载智能体生成的文件。

假设你要构建一个理赔智能体。它从 Files API 读取受理文档，遵循一个封装了团队申报流程的 Skill，使用浏览器使用工具在保险公司的 Web 门户中完成提交，最后把确认凭证保存为文件。此前已正式发布的代码执行和 Web 搜索能力，也可以接入同一个工作循环。

正式发布带来了哪些新特性

  • Computer use：更新后的 computer use 工具允许 Claude 每轮执行多个操作，而不是每次模型调用只执行一个，任务因此可以用更少的调用和更短的时间完成。同时，Computer use 现已可在我们的 BAA 协议下用于受 HIPAA 监管的工作负载。 
  • 浏览器使用工具：今天在 computer use 中全新推出。它同样支持多操作轮次，并新增了页面结构信息，使智能体定位 Web 元素时比仅凭像素更可靠。
  • Skills API：更简洁的 API，用于上传和管理你自己 Skills 的版本。
  • Files API：自动文件过期、5 倍提升的速率限制，以及每个组织 1 TB 的存储空间。

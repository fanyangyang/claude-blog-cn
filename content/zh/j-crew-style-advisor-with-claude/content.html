在线上，购物通常是一件商品一件商品地发生：顾客找到一件毛衣后，还得再去找搭配的裤子和鞋子。为了改变这一点，J.Crew 今天推出了 Style Advisor——一位驻扎在 JCrew.com (opens in new tab) 的 AI 造型师，帮助顾客按整套造型购物。J.Crew 团队使用 Claude Code (opens in new tab)，并结合多个 Claude 模型（从 Fable 到 Haiku）来构建它，每个模型都匹配到最擅长的工作。该功能现已在美国的女装和男装品类上线。

40 多年来，J.Crew 自己的造型师通过平衡比例、色彩与层次，并以出人意料的方式组合单品，打造出完整的造型。Style Advisor 把这份专业能力带到了线上。顾客描述自己的需求，比如参加海滩婚礼或第一次求职面试要穿什么，它就会给出从 J.Crew 自有拍摄大片中提取的整套造型。顾客还可以继续细化，于是购物变成了一场视觉对话。

它是如何构建的

J.Crew 的产品团队使用 Claude Fable (opens in new tab) 5.1（Anthropic 面向复杂、开放式工作的模型）来规划 Style Advisor 应当如何像造型师一样思考，随后在 Claude Code 中用 Claude Opus (opens in new tab) 5.5 构建了可运行的原型。J.Crew 的工程师把这个原型推向了生产环境。在每一次对话中，Claude Sonnet (opens in new tab) 5.5 担任造型师，决定回复的每一步；而 Claude Haiku (opens in new tab) 5.5 负责快速、聚焦的任务，让 Style Advisor 迅速作答。由于每一套造型都来自 J.Crew 的造型师，其推荐结果始终与 J.Crew 的造型理念保持一致。

顾客如何使用 Style Advisor

  • 按整套造型购物。每一条推荐都源于 J.Crew 造型师为品牌目录拍摄打造的造型，Style Advisor 用照片呈现它们，让顾客看到完整搭配。
  • 从单件出发搭配。顾客可以从一件单品开始，获得补全整套造型的单品建议。
  • 按场合穿搭。顾客可以说明自己要去的场合——无论是度假、节日派对还是婚礼——并获得相应的推荐。
  • 获得 J.Crew 的视角。Style Advisor 采用与门店里 J.Crew 造型师相同的造型原则。

下一步

发布之初，Style Advisor 帮助顾客发现新的造型灵感，更有信心地购物。随着时间推移，J.Crew 计划根据每位顾客的偏好和过往购买进一步个性化建议，并将其推广到更多市场和产品线。

“随着消费者期望不断演变，AI 为零售打开了新的可能性，J.Crew 正在挑战传统的线上购物模式，从单品搜索转向更连贯、更由灵感驱动的体验，”J.Crew Group 首席执行官 Libby Wadle 表示。“很长一段时间以来，我们一直在思考顾客未来会希望如何购物，以及我们如何引领这一演变，而不是被动应对。我们看到了从根本上重新思考购物体验的机会。通过与 Anthropic 的合作，我们把 J.Crew 数十年的造型、商品和创意专长汇聚在一起，共同塑造顾客行为的下一步。”

“J.Crew 拥有时尚界最具辨识度的审美视角之一，其团队用 Claude 以一种全新的方式把这份专业能力带给顾客，”Anthropic 首席商务官 Paul Smith 表示。“他们用前沿模型构建体验，再用更快、更高效的模型来运行它，因此顾客能得到迅速且忠于品牌造型风格的答案。”

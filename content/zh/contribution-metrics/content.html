今天，我们在 Claude Code 中推出贡献指标（contribution metrics），现已进入公开测试阶段。工程团队现在可以衡量 Claude Code 对团队效率的影响，跟踪在 Claude 协助下交付的 PR 和提交的代码。

我们自己在 Anthropic 的实践

Anthropic 的工程团队大量使用 Claude Code，贡献数据帮助我们量化了它的影响。随着 Claude Code 在内部的采用率提升，我们观察到每位工程师每天合并的 PR 增加了 67%。各团队现在有 70–90% 的代码是在 Claude Code 协助下编写的。

虽然单看 Pull Request 并不足以完整衡量开发效率，但我们发现它是工程团队所关心事项的一个良好近似：更快地发布功能、修复 Bug、取悦用户。

Claude Code 中全新的贡献指标可以帮助你在自己的组织中衡量这种影响。

用 Claude Code 衡量效率

通过集成 GitHub，贡献指标会呈现以下数据：

  • 合并的 Pull Request：跟踪有无 Claude Code 协助所创建的 PR
  • 提交的代码：查看有无 Claude Code 协助提交到仓库的代码行数
  • 按用户划分的贡献数据：识别团队内的采用模式

贡献数据通过将 Claude Code 的会话活动与 GitHub 提交和 PR 进行匹配来计算。我们的计算方式偏保守，只有当我们高度确信 Claude Code 参与其中时，相应代码才会计入“协助”。

这些指标会出现在你现有的 Claude Code 分析面板中，工作区管理员和所有者均可访问。无需外部工具或数据管道。只需安装我们的 GitHub App 并完成组织 GitHub 账号的认证，指标就会自动呈现在面板上。

贡献指标旨在补充你现有的工程 KPI。将它与 DORA 指标、冲刺速度或其他度量结合使用，理解引入 Claude Code 给团队带来的方向性变化。

开始使用

代码贡献指标现已面向 Claude Team 和 Enterprise 客户提供测试版。启用步骤如下：

  1. 为你的组织安装 Claude GitHub App
  2. 前往 Admin settings > Claude Code 并打开 GitHub Analytics
  3. 完成你的 GitHub 组织认证

随着团队使用 Claude Code，指标将自动开始生成。详细的设置说明和指标解读指南请查阅文档。

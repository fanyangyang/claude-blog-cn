Claude 现已在 Amazon Bedrock 上正式发布（GA）。Amazon Bedrock 是一项完全托管的服务，为 Amazon Web Services（AWS）客户提供安全的基础模型云端访问，以及构建生成式 AI 应用的工具。

这意味着每一位 AWS 客户现在都可以使用 Claude 进行构建，并且很快就能用上一系列令人兴奋的新功能——包括 Agents for Amazon Bedrock，我们团队在它的开发过程中发挥了重要作用。

Agents for Amazon Bedrock 目前处于预览阶段，它可以编排并调用广受欢迎的 AWS Lambda 函数来执行 API 调用。通过这一功能，Claude 可以承担更广泛的 Agent 角色：理解用户请求、将复杂任务拆解为多个步骤、通过持续对话收集更多细节、查找信息，并采取行动满足请求。例如，一个提供 Claude 聊天助手服务的电商应用，将不再局限于查询商品库存——它还能真正帮客户修改订单、办理换货、查找相关的用户手册。

我们还于近期宣布，将通过这项服务提供 Claude 模型的安全定制和微调。这一技术利用 AWS 客户的专业知识和专有数据来优化 Claude 的性能，从而产出更相关的结果，同时限制有害输出的可能性。

Claude 在 Amazon Bedrock 上的正式发布，推进了我们帮助企业负责任地整合变革性 AI 的工作。未来几个月，我们将发布更多应用层解决方案，帮助组织从 Claude 中获得最大价值。

自 4 月宣布与 Amazon Bedrock 集成以来，Claude 获得了包括 LexisNexis、Lonely Planet 和 Ricoh USA 在内的领先企业的强劲自然增长采用。

知名资产管理公司 Bridgewater Associates 也在利用我们最先进的模型 Claude，打造一款全新的、由 AI 驱动的投资分析师助手（Investment Analyst Assistant），为其团队的初级成员提供支持。

Bridgewater 致力于从根本层面理解经济，揭示驱动全球市场的那些永恒而普遍的因果关系。为了揭示这些关系，Bridgewater 的分析师们投入大量时间去理解假设，并系统地对其进行压力测试，而这一过程往往通过代码完成。

例如，一位分析师可能会研究美联储紧缩政策对大宗商品价格的影响，创建关键的数据可视化（包括图表和表格）来验证假设、综合分析结果并分享研究。Bridgewater 的团队正在借助 Amazon Bedrock 上的 Claude，让这一流程更高效、更可扩展。

"Claude 是我们即将推出的 Amazon Bedrock 上的投资分析师助手背后的高性能模型，它能够接受基础指令、生成 Python 代码、排查并修正错误，并输出图表和表格，就像一位第一年或第二年的分析师那样，"Bridgewater Associates AI/ML 首席技术官 Aaron Linsky 表示。"当投资分析师助手对下一步行动不确定时，它还会在尝试执行之前先提出澄清性问题。"

Linsky 继续说道："我们的投资分析师助手还支持就地编辑代码，这让我们的分析师可以自行决定何时借助 Claude、何时自己动手做简单的修改。这带来了更快的迭代循环，让投资分析师助手能够在更新后的代码库上继续迭代——这是许多其他聊天式助手根本不具备的能力。"

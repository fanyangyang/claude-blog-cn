更新： 你现在可以在请求中添加 web fetch 工具，Claude 将抓取并分析任意网页 URL 的内容。2025 年 9 月 10 日

今天，我们在 Anthropic API 上推出网页搜索（web search）——一项全新工具，让 Claude 能够获取来自整个互联网的最新信息。启用网页搜索后，开发者可以构建由 Claude 驱动、能提供最新洞察的应用和智能体。

用互联网最新信息为 AI 智能体赋能

开发者现在在调用 Messages API 时启用网页搜索工具，即可用当前的真实数据来增强 Claude 的全面知识。

当 Claude 收到一个需要最新信息或专业知识的请求时，它会运用自身的推理能力判断网页搜索工具是否有助于给出更准确的回答。如果搜索互联网有帮助，Claude 会生成有针对性的搜索查询、检索相关结果、分析其中的关键信息，并给出附有原始来源引用的全面回答。

Claude 还可以智能体方式运行，进行多次渐进式搜索，利用先前结果指导后续查询，从而完成轻量级研究并生成更全面的回答。开发者可以通过调整 max_uses 参数来控制这一行为。。在幕后，Claude 还可能不断优化查询，以给出更准确的回答。

借助网页搜索，开发者现在无需管理自己的网页搜索基础设施，就能构建利用实时信息的 AI 解决方案。

用例

网页搜索让 Claude 能够支持广泛受益于实时数据和专业知识的用例，覆盖各行各业。具体包括：

  • 金融服务：构建分析实时股价、市场趋势和监管动态的 AI 智能体。
  • 法律研究：创建访问最新法院判决、监管变化和法律新闻的工具。
  • 开发工具：让 Claude 参考最新的 API 文档、GitHub 发布和技术动态。
  • 效率工具：构建能整合最新公司报告、竞争情报或行业研究的智能体。

在信任与可控的基础上构建

每条来自网页的回答都包含来源引用，用户可以直接核实信息。这对要求准确性和可问责性的敏感用例尤为重要。

组织可以通过以下管理设置实施额外的控制：

  • 域名白名单：指定 Claude 可以搜索和从中获取信息的域名，确保结果只来自经过批准的来源。
  • 域名黑名单：阻止 Claude 访问某些可能包含敏感、竞争性或不适合你组织的内容的域名。
  • 组织级管理：管理员可以在组织层面允许或禁止使用网页搜索。

用网页搜索增强 Claude Code

网页搜索现也已登陆 Claude Code，将互联网上的最新信息引入开发工作流。

启用网页搜索后，Claude Code 可以访问当前的 API 文档、技术文章，以及开发工具和库的相关信息。在处理新出现或快速演进的框架、排查罕见错误，或实现需要特定版本 API 参考的功能时，这尤其有价值。

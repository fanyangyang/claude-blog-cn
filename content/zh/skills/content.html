Claude 现在可以使用 Skills 来提升它执行特定任务的表现。Skills 是包含指令、脚本和资源的文件夹，Claude 可以按需加载它们。

只有在与当前任务相关时，Claude 才会访问某个 Skill。使用时，Skills 能让 Claude 更擅长处理专业任务，比如操作 Excel，或遵循你组织的品牌规范。

你此前已经在 Claude 应用中见过 Skills 的实际运作——Claude 用它来创建电子表格、演示文稿等文件。现在，你可以构建自己的 Skills，并在 Claude 应用、Claude Code 和我们的 API 中统一使用。

Skills 的工作原理

在处理任务的过程中，Claude 会扫描可用的 Skills，寻找相关的匹配项。一旦匹配成功，它只会加载所需的最少信息和文件——在获取专业能力的同时保持快速响应。

Skills 具有以下特点：

  • 可组合：Skills 可以叠加使用。Claude 会自动识别需要哪些 Skills，并协调它们的使用。
  • 可移植：Skills 在所有地方都采用相同的格式。一次构建，即可在 Claude 应用、Claude Code 和 API 中通用。
  • 高效：只在需要的时候加载需要的内容。
  • 强大：Skills 可以包含可执行代码，适合那些传统编程比逐 token 生成更可靠的任务。

你可以把 Skills 理解为一份自定义的入职培训材料，让你把专业知识打包封装，使 Claude 成为你最看重领域里的专家。如果想深入了解 Agent Skills 的设计模式、架构和开发最佳实践，请阅读我们的工程博客。

Skills 适用于所有 Claude 产品

Claude 应用

Skills 已面向 Pro、Max、Team 和 Enterprise 用户开放。我们为文档创建等常见任务提供了现成的 Skills，也提供了可自定义的示例，还支持创建你自己的自定义 Skills。

Claude 会根据你的任务自动调用相关的 Skills——无需手动选择。你甚至可以在 Claude 工作时的思维链中看到 Skills 的身影。

创建 Skills 非常简单。"skill-creator" Skill 会提供交互式引导：Claude 会询问你的工作流，生成文件夹结构，格式化 SKILL.md 文件，并打包你需要的资源，全程无需手动编辑文件。

在设置中启用 Skills。对于 Team 和 Enterprise 用户，管理员需要先在组织范围内启用 Skills。

Claude 开发者平台（API）

Agent Skills（我们通常简称 Skills）现在可以添加到 Messages API 请求中，新的 /v1/skills 端点让开发者能够以编程方式控制自定义 Skills 的版本管理。Skills 需要Code Execution Tool beta，后者为 Skills 的运行提供所需的安全环境。

使用 Anthropic 官方创建的 Skills，可以让 Claude 读取并生成带公式专业 Excel 电子表格、PowerPoint 演示文稿、Word 文档以及可填写的 PDF。开发者也可以创建自定义 Skills，针对特定用例扩展 Claude 的能力。

开发者还可以通过 Claude Console 轻松创建、查看和升级 Skills 的版本。

循环（Loop）入门

眼下关于循环工程（loop engineering）或"设计循环"而非给编码 agent 写提示词的讨论很多。如果你在 X 上花些时间想弄清楚循环到底是什么，会找到好几种不同的答案。

在 Claude Code 团队，我们把循环定义为 agent 反复执行工作周期，直到满足停止条件。我们基于以下几点把循环分为几种类型：

  • 如何触发
  • 如何停止
  • 使用哪种 Claude Code 原语
  • 每类循环最适合什么类型的任务。

我们将介绍主要的循环类型、各自的适用场景，以及如何在控制 token 用量的同时保持代码质量。并非所有任务都需要复杂的循环；从最简单的方案开始，再有选择地使用这些模式。

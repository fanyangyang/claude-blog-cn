今天，Microsoft 宣布 Claude 模型现已登陆 Microsoft 365 Copilot，通过 Microsoft 的生产力平台将 Claude 带给数百万企业用户。

从 Microsoft 的 Researcher 智能体和 Copilot Studio 开始，企业客户现在可以在既有模型选项之外选择 Claude Sonnet 4 和 Opus 4.1，让组织在选择契合自身业务需求的 AI 时拥有更大的灵活性。

Claude Sonnet 4 和 Claude Opus 4.1 的加入，帮助 Microsoft 把全行业最好的 AI 创新引入 Microsoft 365 Copilot，为工作场景调优，并适配你的业务需求。

Anthropic 模型如今在 Microsoft 365 Copilot 中的呈现方式：

  • Researcher 智能体：Microsoft 的推理智能体现在可以由 Claude Opus 4.1 驱动。无论你是在制定详尽的市场进入策略、分析新兴产品趋势，还是撰写全面的季度报告，现在都可以选择你偏好的模型来支撑深度工作。Researcher 帮助你处理复杂的多步骤研究——不仅在网络和可信第三方数据上进行推理，还能覆盖你工作内容中的邮件、聊天、会议、文件等全部信息，随时提供专家级支持——现在你还可以自主选择模型。
  • Copilot Studio：Claude Sonnet 4 和 Claude Opus 4.1 模型现已在 Copilot Studio 中作为可选模型提供，让你能够轻松创建和定制企业级智能体。借助此次发布，你可以构建、编排和管理由 Anthropic 模型驱动的智能体，用于深度推理、工作流自动化以及灵活的智能体任务。利用 Copilot Studio 中的多智能体系统和提示工具，你可以根据需要为特定任务选用 Claude。

完成开通后，你就可以在 Researcher 中轻松选用 Claude。

开始使用

Researcher 中的 Claude 从今天起通过 Microsoft 的 Frontier Program，面向选择开通的 Microsoft 365 Copilot 授权客户逐步推出。要构建智能体，用户也可以通过 Frontier Program 选择在 Copilot Studio 中试用 Claude。Anthropic 模型托管在 Microsoft 托管环境之外，并受 Anthropic 的条款与条件约束。要开始使用，组织的管理员可以在 Microsoft 365 管理中心启用对 Anthropic 模型的访问。请在此处了解更多。

敬请期待 Microsoft 365 生态中更多的 Claude 体验，并访问 anthropic.com/enterprise 了解 Claude 的企业能力以及我们对安全、可信 AI 的承诺。更多细节请参阅 Microsoft 的发布博客。

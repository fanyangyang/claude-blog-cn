我们正在为 Claude Enterprise 引入更丰富的管理员分析、模型级使用权限和支出提醒。随着 Claude 在整个组织中承担越来越困难、越来越复杂的 agent 工作，其用量和成本模式也与标准的聊天工具有所不同。这些控制手段让管理员既能看清 Claude 的使用情况，又有管理成本的工具。

今天的更新建立在 Anthropic 已提供的控制能力之上：各级别的支出上限、访问与模型路由、支持导出和 Analytics API 的用量分析仪表盘，以及投入档位控制。更丰富的分析和更细粒度的成本控制，是我们数月来持续构建的控制面板上最新的补充。

追踪采用情况与成本

管理员分析仪表盘现在可以按组和按用户展示用量与成本，产出门类（如创建的 Artifacts、编辑的文件、使用的 Skills 和连接器）会直接显示在对应成本旁边。管理员可以按 IT 团队已在管理的 SCIM 组进行筛选，让数据细分与现有组织架构保持一致。

Claude Code 也获得了更丰富的洞察：管理控制台中新增了两个聚焦价值与用量的标签页。用量页展示全组织的活跃开发者、会话数和最常用命令，每日更新。价值页汇总用量和成本数据，帮助管理员一眼看懂 Claude Code 的价值——估算生产力提升、每次提交的成本和年度价值。每一项公式都在标签页中公开可见，且输入参数可调。

Analytics chat 现在能回答范围更广的问题，并产出可深入挖掘的更丰富的 Artifacts。管理员可以用自然语言提问——"哪些团队这个月的 Claude 用量翻了一倍？"或"我们在哪些席位上获得的价值最高？"——Claude 会返回可导出并与利益相关方分享的图表。

用量和成本数据可通过 Analytics API 以编程方式获取，财务和 IT 团队可以把 Claude 的用量与成本数据接入他们已在使用的工具——如 Datadog Cloud Cost Management 和 CloudZero——与其余云和 AI 支出放在一起查看。结果可按日期范围、团队、产品或模型筛选。Skills 可上报自身的用量和成本，新的端点还可以追踪插件采用情况和 Artifacts 创建量。

管理员可以将用量可见性下放到单个用户——成本、产品和模型细分，以及支出限额的使用进度——这样没有人会撞上突如其来的停用。用户也可以查看自己随时间变化的用量趋势，包括最依赖哪些产品、模型和 Skills，以及这些活动在支出上的累计。

支出管理控制

模型默认值与使用权限让管理员可以设定聊天、Cowork 和 Claude Code中新会话默认使用的 Claude 模型，这样日常工作就不必默认落在最贵的选项上。管理员可以控制哪些模型对特定角色或整个组织开放。

支出阈值提醒会在组织级支出限额的 75% 和 90% 处通知管理员，让他们有充足时间在上限拦住任何人之前调高限额。用户会在 75% 和 95% 阈值处收到应用内通知，并且无需离开 Claude 就能直接向管理员申请提高限额。

对于需要跨众多组管理限额的组织，Admin API 可以把成本控制工作流搬进脚本，让控制能力随组织一起扩展。可以大规模地自动化审批限额上调申请、找出接近支出限额的成员、标记快速变化的用量。

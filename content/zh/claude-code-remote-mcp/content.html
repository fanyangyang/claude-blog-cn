今天，我们宣布 Claude Code 支持远程 MCP 服务器。将你喜爱的工具和数据源接入 Claude Code，个性化你的编程体验，无需管理本地服务器。

将 Claude Code 作为你的主力开发界面

Claude Code 可以访问 MCP 服务器暴露的工具和资源，从而能够从你的第三方服务——如开发工具、项目管理系统和知识库——中拉取上下文，并在这些服务中执行操作。

你可以将 Claude Code 与任何远程 MCP 服务器集成，而且随着服务器生态不断壮大，新的能力也在持续上线。

例如，通过将 Claude Code 与 Sentry MCP 服务器集成，你可以访问 Sentry 中的错误和问题。然后，你可以在终端中直接基于这些问题的上下文进行调试。

你还可以将 Claude Code 与 Linear MCP 服务器集成，在当前项目的上下文中工作。

"Linear 的 MCP 集成将 Linear 的项目和问题直接带入了 Claude Code，"Linear 工程负责人 Tom Moor 表示。"借助来自 Linear 的结构化实时上下文，Claude Code 可以拉取问题详情和项目状态——工程师在规划、编写代码和管理问题之间切换时可以保持心流。标签页更少，复制粘贴更少。软件更好，交付更快。"

无缝连接，维护成本极低

与本地服务器相比，远程 MCP 服务器大大降低了维护成本：只需将厂商的 URL 添加到 Claude Code——无需手动配置。更新、扩容和可用性都由厂商负责，你可以专注于构建，而不是管理服务器基础设施。

Claude Code 还为远程 MCP 服务器提供了原生 OAuth 支持，确保与你现有账户的安全连接。只需对服务器进行一次身份验证，剩下的都由 Claude Code 处理——无需管理 API 密钥，也无需存储凭证。

开始使用

远程 MCP 服务器支持现已在 Claude Code 中上线。查看文档快速上手，或浏览我们的 MCP 目录寻找推荐的服务器。

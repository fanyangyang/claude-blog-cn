今天我们宣布 Cowork 的一系列更新，其中包括新的 plugins，让企业各部门的团队都能按照自己期望的方式塑造 Claude。作为其中一部分，我们继续在此前的更新之上扩展 Claude 在金融服务领域能做的事。

Claude 现在可以跨 Excel 和 PowerPoint 工作——在应用之间携带上下文，端到端地完成多步骤金融任务。我们还推出了五个新的金融 plugins、面向 FactSet 和 MSCI 的新 MCP 连接器，以及由 LSEG 和 S&P Global 打造的合作伙伴 plugins。

对金融从业者而言，这意味着一个端到端的工作流——跨多个市场数据提供商进行研究，再到更新模型、制作演示材料——现在可以在单个会话中完成，无需切换工具，也不会在路上丢失上下文。

从数据到交付物

金融工作散落在许多不同的地方。一份交易备忘录来自某个模型，模型来自数据，而数据又会回流到演示材料中。Claude 现在可以在 Excel 和 PowerPoint 之间流转而不丢失上下文——把取数、更新模型、制作交付物当作一个连续任务来完成。

一位股票分析师可以让 Claude 分析财报、更新财务模型并制作一页摘要幻灯片——全程无需切换工具。当输入发生变化时，Claude 会自动更新工作流的其余部分。

Claude 跨 Excel 和 PowerPoint 工作的能力现以 research preview 形式，面向 Mac 和 Windows 的所有付费计划开放。

新的金融 plugins

我们推出五个由 Anthropic 构建的 plugins，以及若干由合作伙伴构建的 plugins。每一个都带有与相应职能实际运作方式相符的领域专长、预期输出质量和工作流模式。

这 5 个由 Anthropic 开发的 plugins 现已全部在我们的公开仓库中提供。

  • 首先是金融分析（financial analysis）插件，覆盖所有金融分析师都需要的基础工作流，包括市场与竞争研究、财务建模，以及 PowerPoint 模板创建和质量检查。

其他插件则支持关键金融职能特有的工作流：

  • 投资银行（Investment banking）帮助银行从业者处理交易工作流：审阅交易文件、构建可比公司分析、准备路演材料。
  • 股票研究（Equity research）加速研究工作流——解析财报电话会议纪要、用新指引更新财务模型、起草研究简报。
  • 私募股权（Private equity）为项目寻源和尽职调查而构建。Claude 可以审阅大量文档集、提取标准化财务数据、对情景建模，并按投资标准为机会打分。‍
  • 财富管理（Wealth management）帮助理财顾问分析投资组合、识别偏离度和税务敞口，并大规模生成再平衡建议。

除了这五个插件，金融从业者还依赖专有数据和专业化平台，这是任何通用插件都无法复制的。我们的合作伙伴构建了自己的连接器和 plugins，把机构数据直接带入 Claude 的上下文，让用户的工作流建立在他们团队本就信任的确切数据源之上。

合作伙伴主导的连接器与 plugins

在已支持的金融类 MCP 连接器之外，两个新的 MCP 连接器让 Claude 可以直接访问机构数据平台。

  • FactSet 连接器将实时市场数据、基本面分析、盈利预估和研究洞见带入 Claude，用值得信赖的机构级数据增强用户的金融分析与投资研究工作流。
  • MSCI 连接器把 MSCI 广受信赖的指数数据带入 Claude，让用户能够访问 MSCI 的专有指数数据，快速洞悉指数表现、敞口、成分和方法论。

多家合作伙伴也发布了各自的 plugins，可以在上面提到的同一个金融服务 plugins 仓库中找到。

  • S&P Global 插件把 Capital IQ Pro 带入 Claude 的上下文。Skills 包括公司概览页（tear sheet）、行业交易摘要和财报电话会议前瞻。
  • LSEG 插件让金融专业人士可以直接在 Claude 中使用 LSEG 的市场数据与分析能力。可以用实时收益率曲线构建 DCF 模型、用实时新闻撰写晨报、用最新的跨资产定价再平衡投资组合、用真实融资经济性分析交易。面向拥有有效 LSEG 数据授权的用户提供。

开始使用

所有由 Anthropic 开发的 plugins——金融分析、投资银行、股票研究、私募股权和财富管理——今天即可使用，可在我们的公开金融插件仓库中找到；LSEG 和 S&P Global 由合作伙伴开发的 plugins 也在同一仓库。你可以直接安装，也可以把它们作为起点，按照你们公司的特定工作流、术语和需求进行定制。

要把 Claude 连接到 FactSet、MSCI 或其他企业数据源，请前往 Claude 设置中的连接器目录。在那里，管理员可以授权连接，并把它们打包成给团队使用的 plugins。

想让 Claude 跨 Excel 和 PowerPoint 工作，请下载 Claude in Excel 和 Claude in PowerPoint 加载项。想要更全面地了解 Cowork 和各个职能的 plugin 更新，请参阅配套的博客文章。

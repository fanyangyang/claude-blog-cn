构建更好的 AI 智能体

与 Claude Opus 4 和 Sonnet 4 相配合，这些测试版功能让开发者能够构建这样的智能体：执行代码以完成高级数据分析、通过 MCP 服务器连接外部系统、跨会话高效存储和访问文件，并借助高性价比的缓存将上下文保持长达 60 分钟——无需构建自定义基础设施。

例如，一个项目管理 AI 智能体可以通过 MCP 连接器与 Asana 交互来查阅任务并分配工作，通过 Files API 上传相关报告，利用代码执行工具分析进展与风险，并全程保持完整上下文——同时通过延长提示词缓存时间来控制成本。

这些能力与网页搜索和引用（Citations）等现有功能一起，构成了构建 AI 智能体的完整工具箱。下面我们来详细了解每一项新能力。

代码执行工具

我们在 Anthropic API 上推出代码执行工具，让 Claude 能够在沙盒环境中运行 Python 代码，生成计算结果和数据可视化。这让 Claude 从一个写代码的助手，变成一位可以在 API 调用中直接迭代可视化图表、清洗数据集并提炼洞察的数据分析师。

借助代码执行工具，Claude 可以加载数据集、生成探索性图表、识别模式，并根据执行结果迭代优化输出——全部在一次交互中完成。这意味着 Claude 可以端到端地处理复杂的分析任务，而不只是给你一段让你自己去运行的代码。

主要用例包括：

  • 金融建模：生成财务预测、分析投资组合、计算复杂的财务指标。
  • 科学计算：执行模拟、处理实验数据、分析研究数据集。
  • 商业智能：创建自动化报告、分析销售数据、生成业绩仪表盘。
  • 文档处理：跨格式提取和转换数据、生成格式化报告、自动化文档工作流。
  • 统计分析：对数据集执行回归分析、假设检验和预测建模。

使用代码执行工具的组织每天可免费获得 50 小时的使用额度，超出部分按每容器每小时 $0.05 计费。请查阅文档了解详细定价。

MCP 连接器

Anthropic API 上的 MCP 连接器让开发者无需编写客户端代码，即可将 Claude 连接到任何远程 Model Context Protocol（MCP）服务器。

此前，连接 MCP 服务器需要构建自己的客户端框架来处理 MCP 连接。现在，Anthropic API 会自动处理所有连接管理、工具发现和错误处理。只需在 API 请求中添加一个远程 MCP 服务器的 URL，你就能立即使用强大的第三方工具，大幅降低构建具备工具使用能力的智能体的复杂度。

当 Claude 收到一个配置了 MCP 服务器的请求时，它会自动：

  • 连接指定的 MCP 服务器
  • 获取可用的工具
  • 推理应该调用哪个工具、传递哪些参数
  • 以智能体方式持续执行工具调用，直到获得足够的结果
  • 管理身份验证和错误处理
  • 返回整合了相关数据的增强响应

远程 MCP 服务器的生态正在不断壮大，这意味着你无需构建一次性的集成，就能轻松为 AI 应用添加新能力。你可以与任何远程 MCP 服务器集成，包括来自 Zapier 和 Asana 的服务器。更多远程 MCP 服务器请见我们的文档。

Files API

Files API 简化了开发者在使用 Claude 构建应用时存储和访问文档的方式。你不再需要在每次请求中管理文件上传，而是只需上传一次文档，即可在多次对话中反复引用。

这让开发工作流更加顺畅，尤其适合需要处理大型文档集的应用，例如知识库、技术文档或数据集。

Files API 将与代码执行工具集成，使 Claude 能够在代码执行过程中直接访问和处理上传的文件，并生成图表（chart）和图形（graph）等文件作为响应的一部分。这意味着开发者只需通过 Files API 上传一次数据集，之后就可以让 Claude 在多个会话中对其进行分析，无需重复上传。

扩展提示词缓存

开发者现在可以在提示词缓存标准的 5 分钟生存时间（TTL）之外，选择扩展的 1 小时 TTL（需支付额外费用）——12 倍的时长提升，可以显著降低长时间运行的智能体工作流的成本。借助扩展缓存，客户可以为 Claude 提供大量背景知识和示例，同时将长提示词的成本最多降低 90%、延迟最多降低 85%。

这使得构建能够长时间保持上下文的智能体变得切实可行，无论它们是在处理多步骤工作流、分析复杂文档，还是与其他系统协作。过去因成本过高而难以维继的长时间运行智能体应用，如今可以高效地大规模运行。

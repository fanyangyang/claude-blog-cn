我们看到 Claude Code 改变了开发者的工作方式。工程师从逐行手写代码，变成描述想法、审阅 Claude 构建的成果。他们重新找回了构建的乐趣。我们的目标是把这种魔力带给每个团队，而今天，我们正在扩展 Claude 能做到的事。我们推出全新的 artifact 类型：Claude Sheets、Claude Whiteboards 和 Claude Data。我们还通过升级交互式连接器，让你更轻松地在最常用的应用里工作。Claude Meetings 即将推出。

你的所有连接器与上下文

在 Claude Code 中，Claude 需要的上下文已经在代码库里了。对其他团队而言，上下文散落在邮件、应用和云盘之中。Claude 通过基于 Model Context Protocol (opens in new tab)（MCP）构建的连接器来获取这些上下文——MCP 是我们为连接 AI 与你使用的工具而推出的开放标准。Claude Marketplace 列出了 9,000 多个连接器和插件，其中也包括社区构建的版本。

交互式连接器 (opens in new tab)把这一点推进得更远。从今天起，合作伙伴可以把应用直接嵌入 Claude，让你无需切换标签页就能在 Adobe、Atlassian 等工具中工作。来自 Salesforce（beta）、NetSuite 和 Workday（beta）的插件自带内置技能，销售可以为通话做准备，财务可以分析财务数据，HR 团队可以处理休假和报销。

更快地把想法变为现实，且可团队协作

从今天起，Claude 可以与你的团队一起构建电子表格、白板和仪表盘。这些功能可与它现有的文档、幻灯片和设计 (opens in new tab)能力配合使用，也能与 Claude Motion (opens in new tab)（beta）配合，后者可帮你把内容变成短动画。在每一种形式里，Claude 都能迅速领会你的需求，让你的思考决定工作节奏：

  • 全新的 artifact 类型 (opens in new tab)：
    • 在 Claude Sheets 中，你的团队与 Claude 一起构建电子表格，协作整理数据，创建和编辑公式，并在多个标签页之间工作。
    • Claude Whiteboards 是一块数字白板，团队可以在会议中一起铺陈和整理想法，然后让 Claude 总结结论。
    • Claude Data（原 Dashboards）可连接 Snowflake、Salesforce 等工具，并使用你数据团队认证的定义（beta）来创建仪表盘、可视化数据故事或带旁白的短视频。

你还可以让 Claude 按团队的工作方式构建自定义 artifact，例如客户跟踪表、每日简报、项目状态看板或合同审阅表。由于 Claude 在每一步都带着同样的上下文，一个想法可以从白板延续到电子表格再到仪表盘，无需重复交代细节。

即将推出的 Claude Meetings 让你把 Claude 加入通话，在对话过程中记录要点并更新团队正在处理的文档。

为企业打造，也与企业共建

随着 Claude 开始连接更多工具，企业需要更好的方式来管理它的访问权限和操作。我们内置了安全与合规控制，帮助企业满足自身要求，同时我们自己最敏感的工作也用同一个 Claude 完成。在 Enterprise 方案中，管理员决定谁可以使用哪些产品和连接器，并能在细粒度层面为组织设置支出上限。

这种控制同样适用于 Claude 所连接的工具。借助 Claude auto-connect (opens in new tab)（现已在符合条件的 Team 和 Enterprise 方案中处于 beta 阶段），连接 Notion、Atlassian 或 Dropbox 等应用只需一次性设置。员工首次在 Claude 中使用该工具时即自动连接，无需逐个单独连接。

无论工具以何种方式连接，Claude 都在你现有的权限范围内工作。管理员还可以限制每个连接器能做什么，也就是说 Claude 也许能读取 Slack，但不能代表你发送消息。

保护敏感业务数据是我们构建方式的核心，随着 Claude 承担更长、更复杂的工作，我们也在持续加固这些保护：

  • Enterprise 组织的数据 (opens in new tab)在传输中和静态存储时均加密。
  • 在 Enterprise 方案中，安全团队可以查看 Claude 的使用情况 (opens in new tab)，通过审计日志和 Compliance API 实现，后者可与包括 Splunk 和 CrowdStrike 在内的 100 多个安全与合规工具配合。
  • 在 Enterprise 的全新 Claude 体验中，每个云端会话都运行在各自隔离的虚拟机 (opens in new tab)中，连接器凭据则保存在其外部。

跟得上你想法的工作方式

现代工作围绕软件来组织，而 Claude 围绕你来运转。它通过你连接的工具体会团队的工作，帮你以需要的格式把想法变为现实，并在管理员设定的控制范围内运行。这样你就有更多时间专注于重要目标并取得进展。

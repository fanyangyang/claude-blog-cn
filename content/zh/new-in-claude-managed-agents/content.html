今天，我们以研究预览版的形式在 Claude Managed Agents 中推出 dreaming（梦境）功能。Dreaming 是对记忆能力的延伸：它会回顾过往会话、发现规律，帮助智能体自我改进。同时，我们也在向使用 Managed Agents 的开发者开放 outcomes（成果标准）、多智能体编排和 webhooks。这些更新共同让智能体在极少人工干预的情况下，更有能力处理复杂任务。

用 dreaming 构建自我改进的智能体

Dreaming 是 Claude Managed Agents 中的一套定时流程：它会审查智能体的会话和记忆存储、提炼规律并整理记忆，让智能体随时间不断进步。你可以自行决定控制程度：dreaming 可以自动更新记忆，也可以让你在变更生效前先进行审查。

Dreaming 能够发现单个智能体自己察觉不到的规律，包括反复出现的错误、智能体们逐渐收敛出的工作流程，以及团队内部共有的偏好。它还会对记忆进行重构，让记忆在持续演变的过程中始终保持高信噪比。这对于长期运行的工作和多智能体编排尤其有用。

记忆与 dreaming 结合，构成了一套面向自我改进智能体的健壮记忆系统。记忆让每个智能体在工作过程中随手记录所学；dreaming 则在会话之间打磨这些记忆——汇集各智能体的共有经验，并让记忆保持最新。

Dreaming 已在 Claude Platform 的 Managed Agents 中提供，开发者可以在此申请访问权限。

Outcomes：为智能体的工作定义质量标准

借助 outcomes，你只需写一份描述"成功长什么样"的评价标准，智能体就会朝着这个目标努力。一个独立的评分器会在自己的上下文窗口中依据你的标准评估输出结果，因此不会受到智能体自身推理的影响。一旦发现问题，评分器会精确指出需要修改之处，智能体再进行新一轮尝试。

当智能体清楚"好"的标准是什么时，它们才能发挥出最佳水平——比如一个结构框架、一套演示规范，或一组必须满足的要求。有了 outcomes，智能体可以对照这个标准检查自己的工作，并自我修正直到输出足够好，无需人工逐次审查。

Outcomes 对那些需要注重细节和全面覆盖的任务尤其有效。它同样适用于主观质量评判，比如文案是否符合品牌调性、设计是否遵循视觉规范。在测试中，相比标准的提示循环（prompting loop），outcomes 将任务成功率最高提升了 10 个百分点，且在最困难的问题上提升幅度最大。Outcomes 也提升了文件生成质量：在我们内部基准测试中，docx 任务成功率提升 8.4%，pptx 提升 10.1%。

现在你还可以定义一个 outcome，让智能体自行运行，完成后通过 webhook 通知你。

多智能体编排：用多个智能体处理复杂任务

当工作量大到单个智能体难以做好时，多智能体编排可以让一个主控智能体把任务拆分，并将每一部分委派给拥有独立模型、提示词和工具的专家智能体。例如，主控智能体可以主导一项调查，同时让各个子智能体分头梳理部署历史、错误日志、指标和客服工单。

这些专家智能体在共享文件系统上并行工作，并把结果汇入主控智能体的整体上下文。由于事件持久化保存、每个智能体都记得自己做过什么，主控智能体可以在工作流中途与其他智能体核对进展。你还可以在 Claude Console 中追溯每一个步骤：哪个智能体做了什么、以什么顺序、为什么这么做——任务如何被委派和执行，全程清晰可见。

团队正在用它们构建什么

各团队正在利用 dreaming、outcomes 和多智能体编排，打造能够验证自身工作、跨会话学习、并行处理复杂任务的智能体：

  • Harvey 使用 Managed Agents 协调长文起草、文档创建等复杂法律工作。借助 dreaming，他们的智能体能记住跨会话学到的东西，包括文件类型的处理技巧和特定工具的使用规律。在其测试中，任务完成率提升了约 6 倍。
  • Netflix 平台团队构建了一个分析智能体，用于处理来自不同来源、数百次构建的日志。当变更影响到数千个应用时，关键是找出其中反复出现的问题。多智能体编排让智能体能够并行分析各批次日志，只把值得处理的问题模式呈现出来。
  • Every 旗下的 Spiral 正在用多智能体编排和 outcomes 驱动其新 API 和 CLI 背后的写作智能体。主控智能体运行在 Haiku 上：接收请求，必要时快速追问，然后把起草工作委派给运行在 Opus 上的子智能体。当用户需要多份草稿时，子智能体会并行运行。写作质量是 Spiral 的核心价值，因此他们用 outcomes 来保障质量：每份草稿都会依照 Every 编辑原则与用户文风（两者都取自记忆）组成的评分标准打分，只有达标草稿才会被返回。
  • Wisedocs 基于 Managed Agents 构建了文档质量检查智能体，用 outcomes 按照其内部准则为每次审查评分。如今审查速度提升了 50%，同时始终符合团队标准。

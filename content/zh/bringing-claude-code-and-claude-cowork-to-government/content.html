Claude Code 和 Claude Cowork 现已在 Claude for Government Desktop 中进入公开测试阶段。它构建在与商业客户所用完全相同的应用之上，并通过 FedRAMP High 授权环境交付。

借助 Claude Code，公共部门团队可以构建和现代化改造支撑公共服务的软件系统。Claude Cowork 则可直接处理桌面上的文件，让机构工作人员把备忘录撰写、RFP 审查、案例工作和演示文稿交给 Claude 完成。

扩展后的体验还附带更多治理能力。管理员可以设置配置默认值，并在各部门之间分配和控制支出。安全团队和授权官员可获得防篡改的审计日志，以及支撑机构 ATO（运行授权）流程的文档。

今天的发布让各机构在执行自身使命的过程中，更容易采购、授权和分配 AI。

新增内容

Claude Code 与 Claude Cowork。各机构将以与商业用户相同的节奏获得新功能。会话历史存储在机构管理的本地设备上，推理则在 FedRAMP High 授权环境内运行。

契合拨款制度的计费方式。项目办公室可以通过标准席位把 AI 支出与专项资金挂钩，也可以自定义席位层级，设定支出和模型限制；用量按固定额度购买，并设有不得超过的硬性上限。管理员可以在管理控制台中按用户、按模型追踪用量，余额不足时会收到自动消耗预警。

与部门组织架构相匹配的管理方式。部门级管理员可以将席位和预付用量分配给下属机构，同时允许各机构自行管理用户。管理员可以使用 SCIM 组映射为特定席位层级设置速率限制、金额上限和可用模型。此外，分层配置可为下属机构设定默认值，包括 Claude 可以连接哪些服务、开放哪些功能，以及指导 Claude 与用户交互方式的指令。

内建于设计的监督机制。每一项管理操作都会记录在哈希链式审计日志中，组织管理员可以直接在产品中查看。Anthropic 侧的敏感操作需要双人审批。用量导出仅包含计量数据，因此各机构无需移动敏感材料即可回应 ATO 和督察长（IG）的请求。

安全与监督

对于评估桌面端部署的安全团队，我们将以公开文档的形式发布 FedRAMP 安全配置指南，客户可以据此以安全的方式配置他们的 Claude for Government 产品。

此外，FedRAMP 要求我们提供正式的变更通知，其中包含与本次变更相关的详情。

最后，新桌面客户端的渗透测试摘要现已提供，后续的渗透测试摘要将在可用时陆续提供。变更通知和渗透测试摘要可通过 Anthropic 信任中心在签署 NDA 的前提下获取。该应用通过标准的机构 MDM 平台部署。

Code Review 的新变化

编码代理不断提高团队的代码编写速度，但代码审查这一瓶颈并未缓解。为了正式发布，我们让 Code Review 变得更快、更能发现关键缺陷，也更容易针对每个仓库进行调优。

自从我们发布研究预览以来，Code Review 变得更加敏锐，能捕获更多原本会流入生产的缺陷。我们还在 Anthropic 内部对 pull request 运行 Code Review，这让我们看到审查会拖慢自家工程师的地方。在预览期间使用 Code Review 的团队反馈了其余情况：它能在人工审查者查看 PR 之前就发现真实问题，但他们希望审查更安静、与每次变更的规模相匹配，并且更快。以下是我们发布的内容：

  • 速度：与预览期间相比，大多数审查现在的完成速度快约 3 倍（从约 20 分钟缩短到 6-10 分钟）。
  • 质量：能发现更多关键缺陷，并提供清晰、简洁的发现，用几句话说明问题是什么、触发条件以及修复方法。
  • 灵活性：管理员可为每个仓库选择 Quick、Standard 或 Deep 模式，常规代码库获得快速检查，最关键的部分获得深度审查。每个级别都提供高质量的审查。

开始使用

Code Review 现已面向 Team 和 Enterprise 计划正式发布。

  • 管理员：在您的 Claude Code 设置中启用 Code Review，安装 GitHub App，然后选择要运行审查的仓库。
  • 开发者：启用后，审查会在新的 PR 上自动运行。无需任何配置。

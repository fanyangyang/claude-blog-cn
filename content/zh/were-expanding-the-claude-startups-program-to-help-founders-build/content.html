今天，我们正在扩大 Claude Startups——这是我们的一个面向在 Claude 上创办公司的创始人的项目。成员福利包括一年的 Claude Team 套餐、API 额度、运行一家 AI 原生公司所需工具的特惠、与 Anthropic Applied AI 团队的交流时间，以及更多。

为什么我们要扩大这个项目

把一个想法变成产品从来没有像现在这样容易。一个小团队可以在创纪录的时间内做出原型，没有编程背景的人也能发布可用的软件。但想法只是第一步。当人人都能快速构建时，就更难知道什么能让你的产品脱颖而出，尤其是当底层模型还在不断改进的时候。创始人还必须承担起步的成本，而合适的工具既难找到，也难以快速配置好。这正是紧密合作发挥作用的地方：与构建模型的人相处的时间，可以帮助你了解模型的走向、决定在哪里实现差异化，并在早期就解决这些挑战。

这就是我们创建 Claude Startups 的原因。自今年早些时候推出该项目以来，成员们已经获得了 Claude 额度和工具、与开发者社区的联系，以及生态新闻和产品功能的访问权限。许多快速成长的 AI 原生公司已经加入了该项目，而在下一阶段，我们将向更多公司开放。

今天就开始构建

我们希望建立在 Claude 之上的创始人能够成功，而在早期我们能做的最有用的事情，就是从一开始就让你访问我们的模型和产品。Claude 每隔几个月就会在能力上有实质性的提升，而为未来而构建的公司可以在模型发布当天就投入使用。

Claude Startups 成员可以获得高达 $7,000 的 Claude 产品和额度用于构建*：

  • 一年免费 Claude Team：面向新加入 Team 的公司，最多五个 Premium 席位。
  • 一次性 $1,000 API 额度用于起步：一旦你通过审核即可获得，让你可以立即开始——接入 API、测试几个想法，并运行早期评估。

运行 AI 原生公司的工具

全新的 Claude Startup Stack 是一系列面向创业公司所用工具的福利，从销售到设计再到数据工程。成员可以获得来自使用 Claude 构建的公司提供的、价值高达 $45,000 的折扣和额度**。

更多福利

成员还可以获得支持体系来发展业务，从触达新客户，到与我们的团队一起解决技术问题，再到与其他创始人一起学习。

  • 与 Anthropic 保持紧密联系：成员可以预约与 Anthropic Applied AI 团队的线上交流时间。

  • 与社区建立联系：获得 Founder House、黑客松和线下聚会等活动的参与机会（名额有限），并可访问 Startup Newsletter，其中包含产品和生态新闻，以及被专题报道的机会。

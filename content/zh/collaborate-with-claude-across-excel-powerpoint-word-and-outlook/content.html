跨四个应用的一场对话

大多数工作并不局限于单一应用，所以 Claude 会像你一样在应用之间流转。在 Outlook 中分拣邮件，在 Word 中打开附件、按团队模板起草一份备忘录，在 Excel 中搭建配套分析，最后在 PowerPoint 中做成一份演示文稿——全程无需重复解释你在做什么。在 Excel 中调整一个假设条件后，PowerPoint 里的图表和 Word 备忘录中的数字也会自动更新。

Claude 可以跨打开的文件工作，所以只要把电子表格、演示文稿和备忘录并排打开，改动就会在它们之间自动流转。

对话会随每个文件保存，你可以关掉侧边栏，第二天重新打开，用键盘或语音从上次停下的地方继续。 

Claude for Outlook

Claude for Outlook 把 Claude 带进了你的收件箱。让 Claude 分拣你的收件箱，它会按照需要你回复的、它可以代拟的、以及无关噪音来分类整理邮件。回复会以草稿形式出现在 Outlook 的撰写窗格中，收件人、主题和正文都已填好。日历邀请会检查与会人的空闲时间，并在 Outlook 原生的事件表单中打开。

在 Word 或 Excel 中打开附件时，Claude 已经知道发件人的要求。每封回复和日历邀请在发出前都会经过你的审阅，你不点击发送，任何内容都不会发出。

在整个组织内部署 Claude for Microsoft 365 

Claude for Excel、PowerPoint 和 Word 现已正式发布，并配备了 IT 管理员和组织所需的管控能力。一个 AppSource 上架条目覆盖 Excel、PowerPoint 和 Word，另一个单独的条目提供测试阶段的 Outlook。管理员可以在 Microsoft 管理中心部署这两者。

企业管理员可以配置 OpenTelemetry，将提示词、工具调用和文档引用流式传输到自己的收集器，安全团队因此能清楚看到 Claude 在每个应用中的所作所为。Analytics API 则按用户、按应用、按天细分活动数据。

组织可以通过 Claude 账户使用全部四个插件，也可以通过现有的 LLM 网关，把流量路由到运行在 Amazon Bedrock、Google Cloud 的 Vertex AI 或 Microsoft Foundry 上的 Claude 模型。

Microsoft 365 Copilot 客户还可以直接在 Excel 和 PowerPoint 中使用 Claude AI 模型。

一场跨越四个应用的对话

大多数工作并不只活在一个应用里，所以 Claude 会像你一样在它们之间移动。在 Outlook 里分诊一封邮件，在 Word 中打开附件、按团队模板起草备忘录，在 Excel 里做出支撑分析，再把它变成 PowerPoint 演示——全程不必重新解释你在做什么。在 Excel 里调整一个假设，PowerPoint 中的图表和 Word 备忘录里的数字也会自动更新。

Claude 可以跨打开的文件工作，因此把电子表格、演示和备忘录并排打开，改动就会在它们之间流动。

对话会随每个文件保留，因此你可以关掉侧边栏，第二天再打开，用键盘或语音从停下的地方继续。 

Claude for Outlook

Claude for Outlook 把 Claude 带进你的收件箱。让 Claude 分诊收件箱，它会按需要你回复的、它可以替你起草的，以及噪音进行分类。回复会作为草稿落在 Outlook 的撰写窗格中，收件人、主题和正文都已填好。日历邀请会检查与会者空闲时间，并在 Outlook 原生事件表单中打开。

在 Word 或 Excel 中打开附件时，Claude 已经知道发件人要求什么。你在发出之前会审阅每一封回复和每一份日历邀请，在你点击发送之前，什么都不会发出。

在组织内部署 Claude for Microsoft 365 

Claude for Excel、PowerPoint 和 Word 现已全面可用，并具备 IT 管理员和组织所需的控制。一个 AppSource 列表覆盖 Excel、PowerPoint 和 Word，另一个列表加入处于 beta 的 Outlook。管理员可以从 Microsoft admin center 部署两者。

Enterprise 管理员可以配置 OpenTelemetry，把提示词、工具调用和文档引用流到自己的 collector，让安全团队看清 Claude 在每个应用中做了什么。Analytics API 会按用户、按应用、按天拆分活动。

组织可以用一个 Claude 账户访问全部四个加载项，或通过现有的 LLM 网关，把流量路由到运行在 Amazon Bedrock、Google Cloud 的 Vertex AI 或 Microsoft Foundry 上的 Claude 模型。

Microsoft 365 Copilot 客户也可以直接在 Excel 和 PowerPoint 中使用 Claude AI 模型。

组织如何使用 Claude for Microsoft 365

开始使用

所有付费计划上的 Mac 和 Windows 用户都可以使用 Claude for Microsoft 365. Claude for Outlook 以 beta 形式在所有付费计划上提供。管理员可以通过 Microsoft admin center 从 Microsoft AppSource 部署这些加载项。

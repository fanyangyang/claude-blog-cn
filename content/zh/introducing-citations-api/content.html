更新：现已在 Amazon Bedrock 中可用。（2025 年 6 月 30 日）

今天，我们推出 Citations——一项全新的 API 功能，让 Claude 的回答有据可查。Claude 现在可以为其生成回答所依据的确切句子和段落提供详细的引用，从而产出更可验证、更值得信赖的内容。

Citations 已在 Anthropic API 和 Google Cloud 的 Vertex AI 上正式发布。

以验证建立信任

所有 Claude 模型在设计上都经过训练，力求可信、可控。Citations 在此基础上更进一步，解决了 AI 应用中的一个特定需求：验证 AI 生成回答背后的来源。

在此之前，开发者需要依赖复杂的提示词来指示 Claude 附上来源信息，往往导致效果不稳定，并需要在提示词工程和测试上投入大量时间。有了 Citations，用户只需将源文档添加到上下文窗口中，在查询模型时，Claude 就会自动为其输出中依据这些来源推断的论断附上引用。

我们的内部评估显示，Claude 内置的引用能力优于大多数自定义实现，召回准确率最多可提升 15%。1

用例

借助 Citations，开发者可以在以下用例中构建问责能力更强的 AI 解决方案：

  • 文档摘要：为长文档（如案件卷宗）生成简明摘要，每个要点都可追溯到其原始出处。
  • 复杂问答：在大型文档语料库（如财务报表）中为用户查询提供详细解答，回答中的每个要素都能追溯到相关文本的具体章节。
  • 客户支持：构建能够通过参考多份产品手册、FAQ 和支持工单来回答复杂问题的支持系统，并始终标明信息的准确来源。

工作原理

启用 Citations 后，API 会将用户提供的源文档（PDF 文档和纯文本文件）按句子切块处理。这些句子块连同用户提供的上下文，会与用户的查询一起传递给模型。此外，用户也可以为源文档提供自己划分的内容块。

Claude 会分析查询并生成回答，对于任何源自参考材料的论断，都会基于所提供的内容块和上下文附上精确引用。被引用的文本会指向源文档，从而最大限度地减少幻觉。

这种方式在灵活性和易用性上更胜一筹：它不需要文件存储，并能与 Messages API 无缝集成。

定价

Citations 采用我们标准的按 token 计费模式。虽然处理文档可能消耗额外的输入 token，但返回引用文本本身的输出 token 无需付费。

"CoCounsel 要想让执业律师信任并立即上手使用，就必须为自己的工作提供引用。我们最初自己实现了这个功能，但构建和维护起来非常困难。这正是我们很高兴测试 Anthropic Citations 功能的原因。它让引用和链接到一手来源在构建、维护和部署给用户方面都变得容易得多。这一能力不仅有助于将幻觉风险降到最低，还增强了对 AI 生成内容的信任。Citations 功能将使我们能够为律师打造一个更准确、更全面的 AI 助手，"Thomson Reuters CoCounsel 产品负责人 Jake Heller 表示。

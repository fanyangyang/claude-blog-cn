现在，你可以在 Claude Cowork 和 Claude Code 中开启让 Claude 使用你的电脑来完成任务的能力。当 Claude 无法使用它所需的工具时，它会通过指点、点击和浏览你屏幕上的内容来亲自完成任务。它可以打开文件、使用浏览器、自动运行开发工具——无需任何配置。

该功能目前作为 research preview 面向 Claude Pro 和 Max 订阅用户开放。它与 Dispatch 配合使用效果尤佳——Dispatch 让你可以通过手机给 Claude 分配任务。

Claude 如何使用你的电脑

Claude 会优先选用最精准的工具，首先尝试 Slack 或 Google Calendar 等服务的连接器。当没有可用的连接器时，Claude 可以直接控制你的浏览器、鼠标、键盘和屏幕来完成任务。它会滚动页面、点击打开、按需探索，但始终会先征得你的明确许可。

我们在构建这一能力时加入了能将风险（包括提示注入）降到最低的保障机制。当 Claude 使用你的电脑时，我们的系统会自动扫描模型内部的激活，以检测此类活动。你还可以随时叫停 Claude，而且 Claude 在访问新的应用之前始终会先请求许可。

与编写代码或处理文本的能力相比，computer use（电脑操作）仍处于早期阶段。Claude 可能会犯错，而且在我们持续改进保障机制的同时，威胁也在不断演变。我们建议从你信任的应用开始，不要用它处理敏感数据。出于这个原因，一些应用默认被排除在外。你可以在这里了解更多安全最佳实践。

随时随地给 Claude 发消息

上周我们发布了 Dispatch：这是 Claude Cowork 中的一项新功能（现在也可在 Claude Code 中使用），让你可以在手机或电脑上与 Claude 保持一段连续的对话。你可以在手机上给 Claude 布置任务，转而去忙别的事，然后回到电脑前查看完成的工作。

借助 Dispatch，你可以让 Claude 每天早上自动查看你的邮件、每周拉取一些指标，或者为一份报告或一个 pull request 启动一个 Claude Cowork 或 Claude Code 会话。

Claude 新的 computer use 能力让 Dispatch 变得更加实用。现在，Claude 可以在你离开时替你使用电脑。例如：在你坐地铁通勤时生成一份早间简报；在你的 IDE 里修改代码、运行测试并提交 PR；或者让你的 3D 打印项目按照最初的计划持续推进。

开始使用

Claude 在 Claude Cowork 和 Claude Code 中的 computer use 能力目前处于 research preview 阶段。它不会总是完美运行：复杂任务有时需要再试一次，而且通过屏幕操作比使用直接集成要慢。我们之所以提前发布，是想了解它在哪里好用、在哪里还有不足——正如我们当初发布 Claude Cowork 时一样。

该功能现已面向 Claude Pro 和 Claude Max 订阅用户开放。Computer use 支持 macOS 和 Windows，你需要在桌面应用设置中启用它。你还需要确保桌面应用保持唤醒并处于运行状态。之后，你可以将其与移动应用配对，试着从手机上交接一个任务。

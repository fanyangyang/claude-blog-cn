灵活定价，成本可预期

Claude 席位包含的用量足以覆盖典型工作日的需要，而当你的团队需要更多智能处理和更多与 Claude 的对话时——管理员可以按标准 API 费率为个别用户开启额外用量。管理员可以控制单个用户在额外用量上的最高支出，既给用户灵活性，也让管理员的账单可预期。

这种方式提供了一条与 Claude 一起规模化扩展的简单路径，同时在每个环节都提供集中计费、管理以及企业级的管理控制。

管理员控制与管理

我们构建了全新的全方位控制能力，让组织获得帮助员工高效使用 Claude 所需的可见性与管理能力。

  • 自助席位管理：通过管理面板购买新席位、直接管理席位分配并为用户开通。
  • 细粒度支出控制：在组织和个人用户层面设置支出上限，在保持关键项目灵活性的同时守住预算。
  • 用量分析：在 Claude 中查看 Claude Code 分析数据，包括接受的代码行数、建议采纳率和使用模式等指标。
  • 托管策略设置：面向所有 Claude Code 用户部署并强制执行符合内部策略的设置，包括工具权限、文件访问限制和 MCP 服务器配置。

Compliance API

企业组织现在可以借助全新的 Compliance API 更好地满足监管要求。合规团队不再需要手动导出和定期审查，而是可以通过编程方式实时访问 Claude 的用量数据和客户内容，构建持续监控和自动化策略执行体系。

管理员可以将 Claude 数据集成到现有的合规仪表盘中，自动标记潜在问题，并通过选择性删除能力管理数据保留。这为组织在履行监管义务的同时规模化推进 AI 应用提供了所需的可见性与控制力。

从今天起，Claude Cowork 和聊天将合并为同一个 Claude。你可以抛来一个快速问题，或把中午前要交的报告交给它，剩下的交给 Claude——即使你合上了笔记本电脑，它也会继续推进。该功能将在未来几周内向 Pro 和 Max 套餐逐步推出，更多套餐随后跟进。

Claude 创作的内容也不需要单独的地方存放。Claude Docs 和 Claude Slides 今天全新上线，Claude Design 现在也可以在对话中使用了。要一份文档，你和 Claude 就一起把它写出来。要一份演示文稿，Claude 就会起草幻灯片。你可以直接编辑、直接从 Claude 演示，或下载为 PowerPoint 或 PDF。这三项功能在付费套餐上均处于 beta 阶段，Enterprise 管理员可以自行决定何时启用。如果你单独使用 Claude Design，它仍然照常工作。 

我们当初把 Cowork 建成了处理更大任务的独立空间，把 Design 建成了处理视觉工作的地方。两个都用过的人告诉我们，最让人抓狂的是决定一项任务该放在哪里。在一个里开始的东西，也无法带进另一个。所以我们不再让你做选择。Claude 现在能自行判断一项任务需要什么，因此 Cowork 和 Design 的能力可以从任何对话中调用，并带上你已有的上下文、技能和连接器。 

“我可以让 Claude 调出[我的法律研究数据库]，它会拉出所有案例、通读一遍、判断我可能还需要哪些其他案例、下载它们，并存入一个文件夹供我亲自审阅。”——Andrew Keller，高级经济学家

效果如何

一份周报中午要交。出门前，你问 Claude 上周管线里有什么变化，然后补一句：“按我们一贯的方式写，标出任何遗漏的地方，并把要点做成五张幻灯片，供领导层会议使用。”如果有什么不清楚，Claude 会提问。你可以在去办公室的路上用手机查看进度。等你坐到办公桌前，报告已经以文档形式备好，附有队友的批注，幻灯片也已就绪，可以直接打开、调整并下载为 PowerPoint。两者来自同一段对话，所以幻灯片已经和报告对上了。你亲手改一行，在幻灯片上给 Claude 留一条评论，然后分享出去。再把它设为每周一自动执行，Claude 就会无需吩咐地开始做报告。

你用 Claude Design、Slides 或 Docs 制作的任何内容，都会保存在一个可在手机上打开的共享链接里。你可以选中某个元素并移动它，或直接告诉 Claude 你想改什么。

你可以自行选择 Claude 如何向你征询。默认情况下，Claude 在采取行动前会先询问。如果你更希望它继续干活、只在需要仔细确认时才来找你，可以开启这一选项。最终决定权始终在你手中。 

开始使用

如果你主要使用聊天，无需任何改变。当你想要托付更重要的任务时，试试下一篇本来要自己做的报告或演示文稿。如果你一直在用 Cowork，一切都会留在原处：你的聊天、项目、artifacts、连接器和技能。打开应用，接着上次的进度继续即可。

该功能将首先向 Pro 和 Max 套餐推出，未来几周内，这些套餐的现有用户和新用户将在网页、桌面和移动端的 Claude 应用中陆续获得。无需手动开启。Team 和 Free 套餐很快就会跟进，Enterprise 管理员将在组织发生任何变化前至少 30 天收到通知。 

完整的功能列表见帮助中心。如果你一直攒着一个大而乱的项目没动手，现在正是时候。

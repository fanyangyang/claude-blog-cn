今天，我们开放 Claude Duet 的研究预览版。Claude Duet 是一款新应用，让 Claude 以主动式智能体（proactive agent）的方式工作。它会主动把需要你关注的事项带到你面前，完成你交办的任务，即使你暂时离开也会继续工作，并在代表你采取行动之前先征得你的同意。我们打造 Claude Duet，是为了那些手头事务多到难以一一跟进的职场人士和小企业主。

它可作为独立应用在 iOS 和 Android 上使用，也可以在 claude.ai 上使用。在此研究预览阶段，Claude Duet 包含在 Pro 和 Max 套餐中，并使用与 Claude 其他部分相同的用量限制。要获得访问权限，请 加入候补名单 （在新标签页中打开）。

把注意力放在最重要的事情上

我们把 Claude Duet 设计成一个值得信赖的伙伴。各类专业人士每天都要在众多决策之间周旋，我们认为他们会发现 Claude Duet 非常有用。它能帮你规划时间和精力的投入重点，也为那些过去让人觉得不可能或望而却步的宏大项目留出空间。

让 Claude Duet 如此有用的，是它的判断力。我们围绕 Claude Opus 5.5 （在新标签页中打开） 来设计它，让它足智多谋，能够判断什么需要你、什么可以等一等、什么时候应该先征求你的意见。

每天早晨，它会向你发送一份简短的简报，汇总你已连接应用中的最重要事项。全天它都会持续关注这些应用，只在有事情需要你注意时才给你发消息。你也可以把各种规模的任务交给它——从安排会议这样的简单行政事务，到更复杂的任务，例如用几十种工具构建仪表盘、制作财务或销售预测、搭建原型，以及构建 Web 应用。

安全与谨慎是内建的

Claude Duet 汲取了我们在智能体安全、防护和隐私方面多年积累的成果，既包括我们自己的经验，也包括企业用于运行其智能体的基础设施实践：

  • Claude Duet 借鉴了我们的 可信智能体框架 （在新标签页中打开），该框架同样指导着 Claude Code 和 Claude in Chrome 等智能体。
  • Claude Duet 处理凭据的方式遵循我们为 Claude Managed Agents （在新标签页中打开） 采用的设计，因此它永远不会直接看到你的密码或登录令牌。
  • 操作由我们的 auto mode 分类器 （在新标签页中打开） 审批，这与保护 Claude 和 Claude Code 免受你未曾要求之操作影响的是同一道防线。
  • Claude Duet 针对隐藏指令和提示注入的防御能力来自我们的 浏览器使用研究 （在新标签页中打开），我们的模型和安全机制也在更广泛的范围内覆盖这一点。
  • 我们对 Claude Duet 的安全基础设施进行了对抗性测试。红队和一家外部公司对 Claude Duet 进行了渗透测试，它还受我们公开的 漏洞赏金计划 （在新标签页中打开） 保护。

Duet 如何处理敏感信息。我们还为 Claude Duet 配备了一个新的专用分类器和安全系统提示词，它会检查每一条消息，防止敏感信息泄露。一个替你读邮件、替你发消息的智能体，需要时刻判断信息应该流向何处。这个新的分类器和提示词旨在拒绝分享最严格层级信息的请求，包括信用卡号码和政府身份证件。其他敏感信息，例如健康状况或个人财务信息，只有在你在明确指示 Claude Duet 发送时才会被放行。

我们将继续开发和强化这些保护措施，并将在未来几天分享更多关于 Claude Duet 如何为安全而设计的细节。

Claude Duet 如何运作

你在 Claude 中的上下文是基础。Claude Duet 会从你的 Claude 账户延续记忆、技能和已连接的应用，因此设置起来几乎不费功夫。发生变化的是你们的协作方式：Claude Duet 会主动来找你，你可以通过打字或语音在同一个持续对话线程中与它沟通，所以一条快速回复和一个长达一周的项目都可以从同一个地方开始。

你离开后工作仍会继续。Claude Duet 拥有一台带独立浏览器的虚拟机，因此不需要你的笔记本电脑或手机保持开机。用一条简短消息描述任务，它就会在后台自行判断要使用哪些应用、采取哪些步骤。任务完成或需要你审阅时，你会收到通知。

有需要你的事项时会收到消息。Claude Duet 每隔几小时检查一次你的已连接账户，因为不间断地检查会更快耗尽你套餐的用量额度。我们正在持续测试它在何时给你发消息上的判断力，也会根据测试者的反馈不断调优。你还可以告诉它你想关注什么、多久关注一次。

重要决定始终由你掌控。Claude Duet 会自行阅读、起草和准备工作。但在发送消息、付款、签署文件或删除任何内容之前，它会精确展示即将执行的操作并等待你的批准。即使经过你的批准，也有一些事情是禁区，例如买卖证券或在账户间转移资金。你也可以随时断开 Claude Duet 能访问的任何应用。

连接你的业务所依赖的工具。Claude Duet 可以使用 Claude Marketplace （在新标签页中打开） 中超过 6,000 个连接器和插件，例如：

  • 找出你错过的 Gmail 和 Slack 消息，并帮你回复。
  • 检查 Intuit QuickBooks 或 Stripe 中未支付的发票并起草提醒。
  • 在 Gusto 中准备并运行工资单，自动填好工时、奖金和报销。
  • 起草招聘启事，经你编辑并批准后发布到 LinkedIn。
  • 协助准备协议，并通过 Docusign 发送以供审阅和签署。
  • 利用 HubSpot 中的联系人和交易历史起草后续邮件。
  • 把你的产品发布变成 Canva 中的社交营销活动。
  • 设置、设计和管理你的 Shopify 商店。即将推出的更丰富的可视化编辑器将让你在设计好店面后、任何内容上线前先行预览。

你还可以使用 Claude Duet 通过 Link（Stripe 的数字钱包）为你的业务购物。Claude Duet 会先与你确认商品，Link 会要求你批准这笔支出，然后以虚拟卡付款，这样你的真实卡号不会被泄露。它还可以使用 Shopify 的 Shop Pay 在网店结账。即将推出的功能是，在你的许可下，它将能够使用你保存在 1Password 中的登录信息登录网站。

加入研究预览

这是 Claude Duet 的早期版本，它仍有可能误读某个对话线程或错误判断什么算紧急。我们围绕工作场景构建了它的核心功能，因此订票之类的个人事务还不是它的强项，而且它还无法向你展示它的浏览器。目前 Claude Duet 存在于独立应用中，与主 Claude 应用分开。我们从早期用户那里学到的东西将决定两者未来如何协同。

在研究预览期间，Claude Duet 与 Claude 的其他部分共享你套餐的用量额度，但使用方式与典型对话不同。它的后台检查会计入这些额度，而更大的任务（如构建财务模型或演示文稿）需要更多的模型轮次和后台工作。

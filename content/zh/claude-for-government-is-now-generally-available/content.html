今天，Claude for Government 面向联邦和各州机构正式全面可用。该平台通过 FedRAMP High 授权环境提供 Claude 的编码和智能体（agentic）工作能力，自 7 月起一直处于公开测试阶段。 

各机构获得的能力与 Anthropic 的商业客户相当，且无需在合规要求上妥协。新能力通常与商业版保持相同的发布节奏。 

Claude 直接在桌面端与文件交互，让机构员工可以使用技能（skills）、插件（plugins）和项目（projects）来完成备忘录撰写、RFP 审阅、个案处理等任务。借助 Claude Code，公共部门团队可以构建并现代化支撑公共服务运行的软件系统。 

Claude for Government 的治理控制专为公共部门机构设计。管理员可以设置配置默认值，并在各部门间分配和控制支出。安全团队和授权官员可以获得审计日志和文档，以支持机构的 ATO 流程。采购官员可以直接与 Anthropic 签约，并按全面可用条款授予合同。

Claude Code 命令行界面和 Claude for Microsoft 365 也正在通过同一环境、在相同的管理控制下推出早期访问。

计费、管理与监督

无席位费用。机构按固定增量为使用量付费，并设有硬性的不超过上限（not-to-exceed cap），因此支出不会超过机构已承诺的金额。管理员可以按组定义包含支出和模型限额的用户层级，按用户和按模型跟踪使用情况，并在余额不足前收到消耗预警。

与部门组织方式相匹配的管理。部门级管理员将预付使用量分配给下级机构，同时各机构自行管理自己的用户。机构可连接自己的身份提供商实现单点登录，并在管理门户中自助完成设置。  SCIM 组映射为每个席位层级设置速率限制、美元上限和允许使用的模型。分层配置为下级机构设置默认值，包括 Claude 可以连接的内容以及可用功能。

设计即监督。管理操作会记录在审计日志中，组织管理员可以查看。Anthropic 一侧的敏感操作需要双人批准。使用量导出仅为计量数据，因此机构可以在不移动敏感材料的情况下回应 ATO 和 IG 请求。对话历史保留在机构管理的设备本地。

开始使用

Claude for Government 今天起面向联邦和各州机构全面可用。机构无需单独的云提供商合作关系即可开始使用。现有客户可以迁移到桌面应用，并通过应用内导入将对话历史一并带过去。

我们的 FedRAMP 安全配置指南可通过 Anthropic 的 信任中心获取。该应用通过标准的机构 MDM 平台部署。

新机构可在 claude.com/solutions/government 申请访问。要加入 Claude Code CLI 或 Claude for Microsoft 365 的早期访问，请联系我们的公共部门团队。

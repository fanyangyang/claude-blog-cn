我们重新设计了 Anthropic Console，将其打造成一个与 Claude 和队友一起构建、测试和迭代 AI 部署的一站式平台。

开发者现在可以在 Anthropic Console 中直接分享提示词，与队友协作。我们还加入了对最新模型 Claude 3.7 Sonnet 的支持，以及控制扩展思考（extended thinking）预算的能力。

构建可靠的 AI 应用

提示词的质量在很大程度上决定模型在特定任务上回答的成败。Anthropic Console 已经通过更高效地编写、评估和优化提示词的工具，简化了 AI 开发流程。

编写提示词：使用 Workbench 有效地组织提示词结构、加入示例并集成外部工具，在一个交互式环境中测试 API 调用。

自动生成提示词：描述你想要实现的目标，Claude 会运用思维链（chain-of-thought）等提示词工程技术，创建一个高效、精准且可靠的提示词。

评估模型回复：通过自动生成测试用例和并排对比输出，在真实场景中评估你的提示词。轻松运行测试套件、为回复质量打分，并基于数据决定部署哪些提示词。

改进提示词：使用先进的提示词工程技术自动优化提示词。这非常适合改写最初为其他 AI 模型编写的提示词，也可用于优化手写提示词。

提示词定稿后，你可以点击"Get Code"获得一个可直接部署的生产级 API 调用。

借助可分享的提示词开展协作

开发者、领域专家、产品经理和 QA 专家常常需要就提示词展开协作，以获得最佳效果。以前，团队只能在文档或聊天应用之间复制粘贴提示词，导致版本管理混乱和知识孤岛。

Anthropic Console 中的可分享提示词提供了一个集中方式，在你的组织内开发、完善和标准化提示词。团队成员可以访问并协作维护一个共享的提示词库，更容易建立最佳实践，并确保所有由 Claude 驱动的应用保持一致的质量。

为扩展思考优化提示词

Claude 3.7 Sonnet 是我们迄今为止最新、最智能的模型，既可以给出近乎即时的回复，也可以进行对用户可见的、逐步展开的扩展思考。

虽然启用扩展思考后提示词的写法大体相同，但我们让优化提示词以充分发挥这一新能力变得非常简单。只需说明提示词将配合扩展思考使用，Claude 就会生成尽可能出色的回复。你还可以在 Anthropic Console 中通过设置思考 token 上限来控制思考的预算 。

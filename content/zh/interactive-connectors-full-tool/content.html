今年早些时候，我们推出了 交互式连接器 (opens in new tab)，把工具的一小块实时视图带进 Claude。从今天起，只要连接器支持，你就可以把工具打开在对话旁边或扩展到全屏，让 Claude 与你并肩工作并直接做出修改。

该功能正在网页版和 Claude 桌面应用中向所有方案逐步推出，属于把聊天与 Cowork 融为一体的全新 Claude 体验 (opens in new tab)的一部分。当你的账号更新到新版 Claude，或所在组织开启后，你就会看到这些功能。

新增内容：

  • Claude 可以在你已打开的工具中工作。你可以让 Claude 修改当前打开的页面、行或文件，像批准连接器操作那样批准它的动作。Claude 做出修改时，改动会实时出现在工具中，你可以紧接着在同一个地方继续工作。
  • 整个工具会在对话旁打开。你可以在工具中工作，同时隐藏聊天，或在需要空间时切换到全屏。对于 Confluence 或 Notion 这类工具，这意味着你会得到登录你自己账号的完整编辑器，而不是受限的预览。
  • 无需写 Claude 提示，直接打开已连接的工具。需要 Claude 帮忙时，可以在同一屏幕内直接提问。
  • 固定你最常用的工具。你可以把它们和 artifacts 排在一起，从侧边栏和 + 菜单一键访问。

在你使用的工具中与 Claude 协作

我们首先从目录中的一小批工具开始，包括 Asana、Canva、Carta、Dropbox、monday.com、Smartsheet、Vercel 和 Webflow。

以下是目前 Claude 中部分工具能做的事：

  • Adobe。让 Claude 修饰、编辑照片并添加效果；高亮、编辑和涂黑 PDF。
  • Atlassian。在聊天旁打开 Confluence 页面，让 Claude 撰写和编辑，并在页面上实时查看它的修改。
  • Box。在聊天旁打开 Box 文件，让 Claude 修订，并在保留改动前并排对比各版本。
  • HubSpot。确定销售管道任务和跟进的优先级，然后在 Claude 中直接执行。
  • Notion。让 Claude 创建 Notion 文档或数据库。边聊边搭建，或自己动手编辑，全程不用离开 Claude。

Figma、Harvey 和 Shopify 也在构建集成，我们也鼓励其他开发者加入。

面向开发者：基于 MCP Apps 构建

交互式连接器运行在 MCP Apps 之上，这是 Model Context Protocol (opens in new tab) 的开放扩展，让 MCP 服务器可以把自带界面引入 AI 应用。你构建的 MCP App 并不局限于 Claude，也能运行在任何支持该扩展 (opens in new tab)的 AI 应用中。

此前，Claude 中的 MCP Apps 主要以对话内的交互式视图形式出现。现在 Claude 支持该扩展的更多能力，例如 app tools 和内嵌站点，让开发者完整的应用可以在 Claude 内运行。

这些能力目前面向开发者处于公开预览阶段，开发者今天就可以开始构建。请阅读我们的文档 (opens in new tab)开始构建。

开始使用

你可以从目录 (opens in new tab)中连接上面提到的工具，然后在聊天中打开任意工具，或把它固定到侧边栏。

致管理员：如果你的组织已允许某个连接器的全部工具，其新功能会随推出逐步出现。管理员可以像现在一样限制连接器的工具。

今天我们推出 Claude for Manufacturing (opens in new tab)，这是一个包含多项技能的插件，覆盖从为新订单报价到诊断停机设备的工作。现在，估算员可以让 Claude 阅读客户需求、比较类似项目的成本，并起草报价。该插件通过连接 Autodesk Fusion、Infor、Microsoft 365 和 Oracle NetSuite 等连接器，直接基于制造商自己的记录工作。Claude for Manufacturing 的设计确保负责人能够在成果交付给客户或供应商之前进行审查和批准。

制造团队可能一天中大部分时间都花在收集信息上。在 2025 年 Manufacturing Leadership Council 的一项调查中，79% 的制造商表示他们手工录入数据 (opens in new tab)。有了 Claude 把每个流程推进到待审查的节点，估算员可以专注于价格，质量工程师可以专注于解决方案，技术员可以专注于先检查什么。

为制造商打造的技能

该插件的 17 项技能覆盖销售、质量、运营、供应链、设计和产线设置。有些只处理单一任务，有些则按顺序执行多个任务，因此 Claude 可以把一项工作推进多个步骤，直到需要人工审查。这些技能可以运行的流程包括：

  • 为新订单报价：估算员可以让 Claude 阅读客户需求、列出缺失信息、比较类似项目的成本，并起草待发布的报价。
  • 调查未通过的检验：质量工程师可以让 Claude 记录不合格情况、检索过往报告中的同类问题、对可能原因排序，并起草纠正措施报告。
  • 诊断故障：技术员可以让 Claude 阅读传感器导出数据、维修记录、照片和手册，然后对可能原因排序，供技术员检查并决定下一步。
  • 从其他供应商采购：采购员可以让 Claude 准备询价请求，然后比较返回的报价。
  • 使用 Autodesk Fusion 比较设计：工程师可以让 Claude 基于现有模型生成多种变体，按照工程师的目标打分，并起草决策备忘录。
  • 生产报告：工厂经理可以让 Claude 把生产数据汇总成一份报告，展示产量与目标的对比、设备停机时间，以及停机与产量损失带来的成本。

这些技能只是起点。组织可以在此基础上扩展，以适配自身的具体运营，我们也计划未来持续增加新的制造技能。

连接制造系统

Claude for Manufacturing 可与制造运营核心的软件协同工作，而这些软件仍然是团队经营业务的核心：

  • Autodesk Fusion：工程师可以在做出选择前比较更多设计方案，因为 Claude 会基于他们现有的模型生成变体。
  • Infor：采购员和计划员可以在行动前核对采购订单和库存，因为 Claude 会在 Infor 中查询这些信息。
  • Microsoft 365：质量工程师可以把规程、供应商邮件和导出的报告汇入同一项工作，因为 Claude 会在共享文件夹和收件箱中找到它们。
  • Oracle NetSuite：估算员可以基于实际订单、库存、生产步骤和工单成本为新工作定价，因为 Claude 在起草报价时会调取这些记录。

制造商也可以在没有连接器的系统中使用该插件。他们把这些系统的定期导出文件保存到 Microsoft 365，Claude 便基于这些文件起草报价或汇总生产报告。

用 Claude 在 Infor 中做出更改

为制造商提供核心软件的 Infor 也发布了自己的插件 (opens in new tab)。借助 Claude for Manufacturing 中的 Infor 连接器，团队可以查询记录；而借助 Infor 的插件，他们还可以在 Claude 中直接对 Infor 做出更改。

例如，如果一批钢材的交期推迟了两周，采购员可以询问 Claude 哪些客户订单会受影响，以及其他工厂还有多少钢材。采购员批准后，Claude 可以向另一家供应商下达采购订单，并在 Infor 中重新安排受影响的生产计划。Claude 的访问权限遵循该采购员在 Infor 中的权限。

制造团队始终掌握控制权

各项技能在设计上都以用户审查作为终点，因此估算员要核对并发布报价，质量工程师要核实纠正措施报告中的修复方案。为支持这种审查，Claude 可以把数字和结论链接回底层数据和文档。

Claude for Manufacturing 不操作设备。为此，Anthropic 正在开发 Model Hardware Standard (opens in new tab)，这是一个研究预览项目，为可编程设备提供一种标准方式，用来描述其测量值、设置和安全限值。

如何开始

在 Team 或 Enterprise 方案中，安装该插件 (opens in new tab)，然后对 Claude 说：“帮我们配置好”。Claude 会询问团队使用哪些系统，测试连接器，并报告哪些技能目前还无法完全运行。

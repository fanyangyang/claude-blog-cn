从今天起，你可以使用 Claude artifacts 来创建、运行和分享桌面应用。"Install as app"（安装为应用）功能正在 Claude for Mac 和 Windows 中以 beta 形式推出。

当 artifact 被安装为 Mac 或 Windows 应用后，它会拥有自己的图标，并在独立窗口中打开，而不是在 Claude 内部打开。你可以与他人分享它，而且在它与你的电脑交互之前需要获得你的许可。你能自行决定允许到什么程度。

每个应用都可以使用 Claude 和你的连接器（connectors），并且当底层 artifact 被编辑时，应用会自动更新。这简化了知识工作者和开发者构建与维护应用的流程。应用向 Claude 发出的请求会计入你方案的用量限制。

Artifacts 最初是一种可以分享的工作产出，比如图表或网页。如今人们把它们当作日常工作的工具，比如一个定期从日历和邮件中拉取信息的会议准备页面，或是一个跟踪当日需要发货订单的追踪器。

如果你在工作中依赖某个工具，它就应该像你的其他应用一样打开，并在有事情需要你关注时提醒你。

已安装应用能做什么

已安装的应用可以发送通知，或把项目添加到你的菜单栏或系统托盘。你可以为每个应用选择权限，Team 和 Enterprise 管理员可以为他们的组织开启或关闭应用权限和完全访问权限。

Anthropic 的员工已经用这些功能做出了：

  • Linnet (opens in new tab)，一款功能完整的图层图像编辑器
  • Phosphor (opens in new tab)，一款看起来像是为电影场景打造的文件管理器
  • Sift (opens in new tab)，它可以设置文件夹规则，并借助 Claude 保持你的文件井然有序
  • Tern (opens in new tab)，一款终端应用，Claude 随时在你身边提供帮助和解释
  • Vitals (opens in new tab)，一款菜单栏和托盘应用，用于查看你电脑的性能表现

权限（Permissions）

共有三个级别的权限：

  • 默认（Default）：已安装的应用只能做它们在浏览器中能做的事情。
  • 应用权限（App permissions）：应用可以申请使用 Claude 能严格控制的常见功能，比如创建始终置顶的窗口、监听全局快捷键或发送通知。
  • 完全电脑访问（Full computer access）：应用可以申请运行程序，以及读取、修改或删除你的文件，而无需每次询问。

你的权限只覆盖应用的当前版本，因此每次更新后 Claude 都会再次询问，即使是你自己的编辑也不例外。如果应用的某一部分来自其他网站，那部分可能会在 Claude 不再询问你的情况下发生变化。

你只能对你制作的应用（在 Team 和 Enterprise 中，还包括组织内其他人制作的应用）授予完全访问权限。Anthropic 不会在安装前审查应用，所以请只对你信任的应用授予完全访问权限。

开始使用

向 Claude 描述你的应用，先以 artifact 形式试用，然后点击"Install as app"。你无需打包或签名，它使用你的 Claude 账户，因此不需要 API 密钥或单独登录。

Install as app 正在所有方案中以 beta 形式推出。HIPAA 就绪组织和混合部署无法使用该功能。它在 Team 方案中默认开启，完全访问默认关闭。在 Enterprise 方案中，它默认关闭，直到管理员将其开启。你需要在线并登录 Claude 才能打开应用。部分 artifact 无法安装，包括 Claude Docs、Slides 和 Sheets。

更新 Claude for Mac 或 Windows，打开一个你日常使用的 artifact，然后从"分享"菜单中选择"Install as app"。

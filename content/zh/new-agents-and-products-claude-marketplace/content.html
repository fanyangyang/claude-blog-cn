我们在 Claude Marketplace 上新增了一批 agent 和产品。企业团队可以在这里找到合作伙伴的工具与服务，更充分地使用 Claude。此次新增覆盖安全、开发者基础设施、创意和生产力四个领域。

符合条件的企业客户可以将部分承诺的 Anthropic 消费额度用于这些解决方案。这样一来，无论他们是在采购新的方案，还是在已有的平台上扩容，都能用同一笔承诺额度同时覆盖 Claude 和合作伙伴产品。

目前 Marketplace 上已有超过 25 个合作伙伴 agent 和产品。以下是本次新增的内容，以及团队可以用它们做什么。

用于保障代码与系统安全的产品和 agent

Chainguard： Chainguard Harness 在隔离的 microVM 中从源码构建应用，并对运行中的应用进行探测，以发现可被利用的漏洞。它帮助团队修复 Claude 发现的问题，并针对可复现的漏洞提供定制化的修复建议。

Checkmarx： Checkmarx One 将基于规则的分析与 AI 推理相结合，在代码中查找漏洞。它帮助团队对发现的问题排定优先级，并在代码发布前完成修复。

Cyera： Cyera Agent Guardian 会清点 Claude 的部署情况，在 Claude 运行前治理权限，并对提示词、文件和工具调用执行策略管控。它帮助团队通过红队测试来验证这些控制措施。

Rubrik： Rubrik Code Guardian 使用 Anthropic 的前沿 AI 模型，检查 GitHub 或 Azure DevOps 仓库的安全副本，以发现多步攻击路径。它帮助安全团队和工程团队按严重程度对问题排序，并把确认的严重问题转为可跟踪的工单。

Tanium： Tanium Cloud 让团队对终端拥有实时的可见性和控制力。它帮助 IT 和安全团队发现并修复漏洞、错误配置和缺失的补丁。

面向工程团队的开发基础设施

Datadog： Datadog Agent Observability 追踪 agent 经由工具和服务执行的整个过程。它通过呈现生产环境中的模式并给出修复建议，帮助团队提升 agent 的质量、性能和成本效率。

Netlify： Netlify Enterprise 将应用、站点和 agent 部署到全球边缘网络，每次变更都会生成预览链接。它让团队无需配置任何基础设施，就能把用 Claude 构建的原型推向生产，并内置 SSO、基于角色的访问控制和审计日志。

面向营销与创意工作的工具

AirOps： AirOps 提供面向 AI 搜索策略、内容生产与多渠道执行的 agent 平台。它帮助营销团队分析品牌在 AI 搜索中的表现，并把结果与销售线索和营收挂钩。

Runway： Runway 可生成和编辑视频、图像与音频。它帮助创意团队和营销团队把一份简报变成成品素材，并用自然语言剪辑素材。

Webflow： Webflow 提供内置工具来构建、管理和优化网站。它让营销人员、设计师、开发者和 agent 都能进行改动，并内置管控与治理机制。

适用于各类团队的生产力应用

Asana：Asana AI Teammates 是预置的 agent，可使用 Asana Work Graph 中的上下文，每个 agent 都拥有独立的身份、限定的权限和审计记录。它们帮助团队处理多步骤工作，并把需要判断的决策交由负责人处理。

Glean： Glean 打通了跨系统的企业知识与工作流。它帮助员工在已连接的各个应用中找到答案并完成多步骤任务。

monday： monday 的 agent 在项目、看板、文档和会议中工作，以负责人和截止日期作为上下文。它们帮助 PMO、IT、营销、财务和运营团队管控 AI 可以访问什么、批准什么以及花费多少。

Zoom： Zoom Agentic Search 可以在 Claude 内部，基于最新的会议纪要、工作沟通记录、文档以及已连接的第三方来源回答问题。团队无需分析原始转录文本，也无需串联多个工具，就能获得符合权限要求的结果。

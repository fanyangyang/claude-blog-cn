Claude Managed Agents 解析

Claude Managed Agents 是一套可组合的 API，用于大规模构建和部署云端托管的 agent。它将 Anthropic 托管的 harness 与涵盖状态、记忆、权限和定时执行的生产级基础设施结合在一起。

在今天发布之前，构建 agent 意味着把开发周期耗费在安全基础设施、状态管理、权限控制上，并且每次模型升级都要重写 agent 循环。Managed Agents 将一个针对性能调优过的 agent harness 与生产级基础设施结合起来，让你从原型到上线只需数天而非数月。

无论你要构建单一任务的执行器，还是复杂的多 agent 流水线，你都可以专注于用户体验，而不必操心运维开销。

Managed Agents 现已在 Claude Platform 上开启公测。

以 10 倍速度构建和部署 agent

要交付一个生产级 agent，需要沙箱化的代码执行、检查点机制、凭证管理、细粒度权限以及端到端追踪。这些基础设施工作动辄数月，才能轮到用户看得见的东西上线。

Managed Agents 替你处理这些复杂性。你只需定义 agent 的任务、工具和护栏，我们在我们的基础设施上运行它。内建的编排 harness 会决定何时调用工具、如何管理上下文，以及如何从错误中恢复。

Managed Agents 包括：

  • 生产级 agent ，安全沙箱、身份验证和工具执行均由我们代管。
  • 长时间运行的会话，可自主运行数小时，即使连接中断，进度和产出也会持久保存。
  • 多 agent 协同，agent 可以启动并指挥其他 agent，并行推进复杂工作（处于研究预览阶段，可在此处申请访问）。‍
  • 可信赖的治理，通过内建的细粒度权限、身份管理和执行追踪，让 agent 在受控前提下访问真实系统。

专为充分发挥 Claude 的能力而设计

Claude 模型为 agentic 工作而生。Managed Agents 专为 Claude 度身打造，让你用更少的投入获得更好的 agent 成果。 

借助 Managed Agents，你只需定义目标和成功标准，Claude 会自我评估并持续迭代，直到达成目标（处于研究预览阶段，可在此处申请访问）。当你希望获得更紧密的控制时，它也支持传统的“提示—响应”式工作流。 

在围绕结构化文件生成的内部测试中，Managed Agents 相比标准提示循环将任务成功率最多提升了 10 个百分点，且在最困难的问题上提升幅度最大。

会话追踪、集成分析和故障排查指引直接内置于 Claude Console 之中，你可以审视每一次工具调用、每一个决策和每一种失败模式。

各团队正在构建什么

各团队已经在用 Managed Agents 覆盖各种生产级场景，交付速度提升 10 倍。编码 agent 阅读代码库、规划修复方案并发起 PR。效率型 agent 加入项目、认领任务，与团队其他成员一起交付成果。财务和法务 agent 处理文档并提炼关键信息。在每一个案例中，数天内上线意味着更快为用户创造价值。

  • Notion 让团队直接在工作区内把工作委派给 Claude（现已在 Notion Custom Agents 内开启私测 alpha）。工程师用它发布代码，知识工作者则用它制作网站和演示文稿。数十个任务可以并行运行，整个团队同时协作打磨产出。
  • Rakuten 在产品、销售、市场和财务部门上线了接入 Slack 和 Teams 的企业级 agent，员工可以直接分配任务并收到电子表格、幻灯片和应用等交付物。每一个专家 agent 都在一周内部署完成。
  • Asana 构建了 AI Teammates——在 Asana 项目中与人类并肩工作的协作式 AI agent，认领任务并起草交付物。借助 Managed Agents，该团队添加高级功能的速度远超以往。
  • Vibecode 以 Managed Agents 作为默认集成方案，帮助客户从提示词直达已部署的应用，驱动新一代 AI 原生应用。用户现在搭建同样的基础设施至少比以前快 10 倍。‍
  • Sentry 将他们的调试 agent Seer 与一个由 Claude 驱动的 agent 配对——后者负责编写补丁并发起 PR——开发者从发现 Bug 到可评审的修复一气呵成。这项集成基于 Managed Agents，用数周而非数月就完成了上线。

Claude Managed Agents 有哪些新能力

新能力会定期加入。Agent 现在可以通过内置记忆跨会话学习，并借助dreaming、outcomes 和多智能体编排自我改进。它们可以在凭证存于 vault 的定时部署中无人值守运行，也可以通过自托管沙箱和 MCP tunnels在你自己的边界内运转。

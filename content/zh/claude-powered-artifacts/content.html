今天，我们推出在 Claude 应用中直接构建、托管和分享交互式 AI 应用的能力。开发者现在可以更快地迭代自己的 AI 应用，而不必为日益增长的受众带来的扩展复杂性和成本而担忧。

构建并托管由 Claude 驱动的应用

以下是我们构建的能力：Claude 现在可以创建通过 API 与 Claude 交互的 artifacts——把这些 artifacts 变成 AI 驱动的应用，而且分享的经济账也算得过来。

当有人使用你构建的 Claude 驱动应用时：

  • 他们使用自己已有的 Claude 账户进行身份验证
  • 其 API 用量计入他们自己的订阅，而不是你的
  • 你无需为他们的使用支付任何费用
  • 没有人需要管理 API 密钥

Claude 编写的是真实的代码，可以编排复杂的 AI 功能。你可以查看它、修改它，并自由分享它。

社区创意

早期用户已经用交互式 artifacts 构建了：

  • AI 驱动的游戏，其中的 NPC 能记住对话并顺应玩家的选择
  • 学习工具，可根据个人水平动态调整并提供个性化辅导
  • 数据分析应用，用户上传 CSV 后用自然语言追问
  • 写作助手，从剧本到技术文档都能提供帮助
  • 智能体工作流，编排多次 Claude 调用来完成复杂任务

开始使用

在 Claude 应用中开启这项全新的交互能力即可开始构建。只需描述你想创建的内容，Claude 就会为你编写代码。

在协作过程中，Claude 可以根据你的反馈调试并改进自己的代码。应用就绪后，你可以通过链接即时分享——无需任何部署流程。Claude 会处理提示词工程、错误处理和编排逻辑等技术细节，让你可以心无旁骛地把想法变为现实。

你可以做什么：

  • 在 artifact 中使用 Claude API
  • 处理文件并用 React 创建富交互界面
  • 查看、复刻（fork）和自定义任何 artifact

当前限制：

  • （暂）不支持外部 API 调用
  • 无持久化存储
  • 仅限于基于文本的补全 API

该功能目前以测试版形式向 Free、Pro 和 Max 计划用户开放。

在接触 Claude Code 之前，Austin Lau 这辈子没写过一行代码。产品刚发布时，他甚至要在 Google 上搜“如何在自己的电脑上打开终端”。

“Claude Code 发布时，我的第一反应是：我完全不知道这产品是干嘛用的，”Anthropic 的增长营销人员 Austin 说。“作为营销人员，我当时就是没开窍——我看不到它的使用场景。”

但好奇心占了上风。 

一位 Anthropic 同事在公司 Slack 工作区发布了一份指南，教非技术员工如何安装 Claude Code。Austin 决定照着做。

一周之后，Austin 构建了两个从根本上改变他工作方式的工作流：一个是一键生成广告创意变体的 Figma 插件；另一个是 Google Ads 文案工作流，帮他头脑风暴并打磨广告文案，然后导出成可直接上传的 CSV 文件。以前每个广告要花 30 分钟，现在只需 30 秒。 

下面是他的做法，以及营销人员能从他使用 Claude Code 的经验中学到什么。

‍

问题：淹没在文案和创意变体里

大规模投放效果广告需要源源不断的新创意。仅 Google 的自适应搜索广告就要求 15 条互不重复的标题。每隔几周，这些文案就需要更新——同时还要保持品牌语调、传达价值主张。

“难点在于，在这个量级上运营，你必须非常、非常频繁地刷新文案，”Austin 解释说。“而且 Google 对文案的要求不太灵活，因为字符数限制很严格。”

过去的流程是这样的：打开 Google Sheets，头脑风暴标题和描述，手动核对字符数，复制粘贴到 Google Ads，然后周而复始。 

视觉广告的流程还要更繁琐。Austin 要打开 Figma，把一个现成的画框复制好几份，切到 Google Doc 拿标题文案，再切回 Figma 粘贴进去，如此往复——还要覆盖十多个变体和多种宽高比。

“这些时间累积起来非常、非常快。”Austin 说。

解决方案：两个消灭营销杂活的工作流

用 Claude，Austin 最终构建了两条改变日常工作的工作流。不过他的第一个项目其实是做一个简单的计算器应用。 

“我让 Claude 做的第一件事，是给我做一个非常简单的计算器应用，就为了看看它会怎么响应，”他回忆道。“Claude 基本上把后端搭好了，还给我做了一个简单的前端。然后它直接告诉我：‘你可以这样运行它。’”

这个小实验改变了他对自己工作任务的想象边界。

用于生成创意变体的 Figma 插件

制作广告变体意味着无尽的复制、粘贴，以及在 Figma 和 Google Docs 之间来回切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件。这个项目大约花了 45 分钟到一小时构建，但现在每次他要在多种宽高比下批量更新大量创意时，都能省下近 30 分钟。 

开始时，他打开 Claude Code，用提示词描述了自己的问题：“Claude，我在用 Figma。我真的想解决这个重复复制粘贴的难题。你能帮我做一个 Figma 插件来解决它吗？”

Claude 自己做了调研，评估如何最好地构建插件、有哪些限制，然后开始做原型。经过几次排错，Austin 的 Figma 里就装上了一个能用的插件。

“我只需要指定创意所在的画框，然后把想更新的所有变体和文案一次性复制粘贴进去，点一个按钮，Figma 插件就会为那张图生成所有不同的排列组合。”Austin 解释说。

Google Ads 文案生成

针对自适应搜索广告，Austin 构建了一个工作流，利用现有的广告系列和广告表现数据，帮他头脑风暴并产出可直接上传的广告文案，用数据判断哪类信息最能打动潜在客户。这个工作流每周在文案创作和字符校验上为他节省数小时。从机械任务中解放出来后，Austin 现在可以做更多文案实验，更快地迭代出真正效果最好的版本。

开始时，他在 Claude 中输入 /rsa——他为自适应搜索广告创建的自定义斜杠命令。Claude Code 会向他要广告系列数据、现有文案和关键词，然后将他输入的内容与他为 Anthropic 品牌语气、产品准确性以及 Google Ads RSA 最佳实践创建的 Agent Skills 进行交叉比对。 

但输出只是起点。

“Claude 是很棒的头脑风暴伙伴，但有时它第一遍并不能做对，”Austin 解释说。“我的很多工作就是来回碰撞，随着时间推移不断打磨文案。”

这种打磨很重要，因为 Austin 会根据自己对 Anthropic 受众的了解来评估每条标题：价值主张立得住吗？语气对吗？能在竞争对手中脱颖而出吗？等文案感觉对了，Claude Code 会把所有内容整合成一个可直接上传的 CSV 文件。

而这一切都建立在人的基础之上。“我们提供给 Claude 的所有文案和示例，都是与产品营销和文案团队共同撰写的。”Austin 说。有了这个扎实的起点，在 Claude 开始头脑风暴之前，人类判断就已经融入其中了。

构建自己工作流的最佳实践

Austin 的经验为营销人员——其实也是所有没有技术背景的人——提供了用 Claude Code 构建自定义工具的实用指引。

从细小、重复的步骤入手

“我的建议是：如果你想尝试 Claude Code 这样的工具，就先想清楚，你工作中哪些地方是重复性的、或者你觉得可以自动化，然后从一件非常、非常小而简单的事情开始。”Austin 解释说。

比如，Austin 的第一个项目就是先做一个计算器应用，看看 Claude 是怎么工作的。

让好奇心驱动你的工作 

Austin 这样形容自己：“我是那种一旦对某件事很好奇，就会执拗到非弄明白不可的人。”正是这股韧劲，把一个他都不知道怎么交互的空终端，变成了他每天都在用的、真正能干活的工作工具。

像给同事讲问题一样跟 Claude 沟通

“你不需要会写代码。你只需要能把你的难题、你想解决的问题讲得非常清晰、简洁。”Austin 说。

非技术员工本来就是自己领域里的专家。他们了解自己的工作流，感受得到摩擦点，也清楚需要什么样的产出。Claude Code 赋予他们自己动手解决一切反复出现的技术问题的能力。

善用已有的资源

做 Figma 插件时，Austin 让 Claude Code 去看现成的 Figma API 文档。借助这些文档，Claude 自行研究并为 Austin 搭了一个可以试验的原型。一个勉强能跑的原型就足以验证 Austin 脑子里的想法，最终演化成一个可用的产品。

更大的图景

在职业生涯的大部分时间里，Austin 都默认有些事情是自己够不着的。需要装个追踪像素，就得找工程师；需要搭个自定义工作流，就得给支持团队提工单。

“我要说，几年之前，如果你想构建这样的工作流，大概需要一队工程师来支持你，”Austin 说。“而现在，有了 Claude Code 这样的工具，我一个非技术出身的营销人员就能自己把这些东西做出来。所以，从‘真希望有这个东西’到‘我真能自己做出来’之间的距离，其实比人们以为的要小得多。”

他已经向同事和客户演示过自己的工作流，所有人的反应都一样：为什么我们没早点这么干？

营销人员的下一步

Austin 看到增长营销的角色正在快速演变。“我觉得增长营销正在朝产品经理的方向走，”Austin 说。“我们不仅能执行营销活动，还能真的构建产品来帮自己达成目标。”

Austin 并不是 Anthropic 唯一一个用 Claude 做构建的营销人员。在整个营销组织中，各团队都得到了类似的结果：

  • 影响者营销用 Claude 为影响者和播客撰写脚本，每月释放出 100 多个小时投入更高价值的工作
  • 客户营销起草案例研究的时间从 2.5 小时缩短到 30 分钟，每周节省 10 小时
  • 数字营销构建了网页开发工作流，团队生产力同比增长 5 倍
  • 产品营销用 Skills 和 Projects 制作发布简报，每次发布节省 5-10 小时
  • 合作伙伴营销为销售团队搭建了自助式活动支持工具，展会准备时间减少 40%

“大多数营销人员对 AI 的态度可能都差不多，只是把它当作帮助写文案、做头脑风暴的工具，”Austin 说。“但他们还没有认真想过，哪些地方可以真正把 Claude 这样的工具嵌入到自己的工作流里。”

对于采用 Claude Code 这类工具的团队来说，一个机会正在浮现：把更少的时间花在重复执行上，把更多的时间花在真正重要的工作上。

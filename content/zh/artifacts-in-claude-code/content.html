Claude Code 现在支持 artifacts，让你可以直接在终端中创建和查看丰富的可视化内容。Artifacts 是 Claude 生成的可视化内容，包括图表、流程图、交互式 UI 预览等，帮助你更好地理解和迭代代码。

在 Claude Code 中，artifacts 会直接在终端中渲染，无需离开命令行。你可以查看生成的图表、预览 HTML 页面，并与 Claude 一起迭代修改。

主要功能

  • 即时可视化：在终端中直接查看生成的图表、流程图和 UI 预览
  • 迭代修改：基于生成的 artifacts 继续对话，Claude 会根据反馈修改
  • 代码导出：可以将 artifacts 中的代码直接保存到项目文件中

开始使用

Artifacts 在最新版本的 Claude Code 中默认可用。只需在对话中请求 Claude 创建图表或可视化内容，它就会自动在终端中呈现。

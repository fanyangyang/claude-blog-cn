Claude Duet （在新标签页中打开） 是一款智能体，目前处于研究预览阶段，它利用基于云的计算机替你完成工作。它可以调用你已选择连接到 Claude 的所有应用和服务，并且即使在你关闭应用后也会持续运行。它可以阅读你的收件箱、起草回复、预订事务，并在你离开期间执行例行任务。我们的团队在自己的账户上运行 Claude Duet，每天都用它处理工作。

我们基于三条原则构建了 Claude Duet，以指导智能体的行为：

  1. 你的信息，以及他人通过你已连接的应用分享的信息，都会得到审慎处理——我们使用一个新的分类器，在 Claude Duet 草拟的消息发出之前对其进行检查。
  2. 你可以完全掌控它代表你所做的事情。
  3. Claude Duet 永远不会看到你的密码、浏览器 Cookie、登录令牌或其他凭据。

Claude Duet 是新产品，但背后的理念并非如此。2025 年，我们发布了关于开发安全可信智能体的框架 （在新标签页中打开），该框架让人掌握主动权，并将隐私和安全交互视为基本要求。此后，我们撰文阐述了为什么单一的防线远远不够 （在新标签页中打开），以及为什么模型内部的保护无法独立支撑 （在新标签页中打开）。我们还通过Claude Managed Agents （在新标签页中打开）构建并运营着企业用于在生产环境中运行智能体的基础设施，Claude Duet 以同样的方式将凭据与智能体分离开来。它建立在这些工作之上，并增添了代表你行动的智能体所需的保护。本文将介绍我们新增的保护措施，以及我们仍在推进的工作。

重要操作需经你批准

在你离开期间行动的智能体必须知道何时该停下来征得许可再继续，并以恰当的节奏这样做。在 Claude Duet 执行发送可能敏感的消息、为某物付款或删除任何内容等操作之前，它会向你展示该操作、目标对象和内容，包括每一位收件人。然后它会等待你批准该操作。

一项独立的自动化检查会与每个操作并行运行，它建立在Claude Code 的 auto mode 分类器 （在新标签页中打开）之上，并针对 Claude Duet 进行了扩展。它会评估该操作是否符合你的意图。这项检查在从事实际工作的模型之外运行，因此隐藏在页面中的指令无法影响检查结果。

有些操作即使获得你的批准也始终被禁止，例如证券交易、在账户之间转移资金等银行操作，以及访问他人的账户。另一些步骤则不受「不再询问我」规则的覆盖，无论你批准过多少次，例如付款或转账、删除订单或创建账户。在你离开期间运行的例行任务也享有同样的保护措施。

我们花了大量时间校准 Claude Duet 询问批准的频率。批准疲劳是一个严重的问题，因为过多的请求会让人习惯于随手点过，有时甚至未经充分考虑。我们将随着时间推移持续调整这一校准。

对于购买操作，Claude Duet 使用来自钱包（如 Stripe 的 Link）的一次性卡片付款，该卡片仅限用于该商家和该金额。你会看到商品和总价，并在 Link 应用中批准这笔购买。你的真实卡号不会分享给 Claude Duet 或商家。

你的信息会得到审慎处理

一个替你阅读电子邮件并发送消息的智能体，要不断决定不同类型的信息该流向何处。如果你让 Claude Duet 给团队发送每周总结，它应该只包含团队中每个人原本就能访问的内容，绝不包含私人细节，比如你的绩效评估谈话。

为解决这个问题，我们构建了一个新的安全分类器，它与主模型分开运行，检查 Claude Duet 即将发送的每条消息是否包含潜在敏感信息。我们将这些信息分为两个层级：

  • 绝不分享：对于登录凭据、完整卡号和银行账号、政府身份证号码等信息，我们给予最高级别的保护。Claude Duet 被指示绝不与任何人分享这些信息，即使你提出要求也不行。
  • 需经同意才能分享：对于健康或财务等其他私人信息，Claude Duet 只会在你明确批准后分享。你自己的请求即构成同意，因此「给我的牙医发一条消息说我牙疼」通常不需要额外批准。

如果 Claude Duet 因上述任一原因被拦截，它可以决定重写消息，去掉敏感信息，然后交给你批准。

Claude Duet 仍处于研究预览阶段，这些保护措施偶尔会漏掉某些内容，或将无害消息误判为敏感。正因如此，它们与上述批准机制协同工作，这些机制的设计宗旨是让你始终掌控 Claude Duet 代表你发送的内容。我们预计随着对人们如何使用 Claude Duet 的了解加深，会继续迭代我们的分类器。

你可以查看任务和已连接应用

你可以在任务列表中查看 Claude Duet 已完成和正在执行的工作，每个任务都有自己的页面，你也可以在任务进行中引导它。Claude Duet 会保留你的对话历史和它的记忆，以便在任务之间携带上下文，直到你删除历史记录或重置记忆。删除账户会清除 Claude Duet 存储的所有内容。

你已连接到 Claude 的应用会延续到 Claude Duet，在一个地方关闭某个应用，两个地方都会关闭。断开某个应用会从那一刻起阻止新的访问，但 Claude Duet 此前从中学到的内容会保留，直到你重置它的记忆——你随时可以从应用的设置中执行此操作。Claude Duet 还会使用你 Claude 账户中的记忆，因此 Claude 从你更早的聊天中记住的细节也会可见。

凭据和浏览器与模型相互隔离

Claude Duet 永远不会看到你的密码、浏览器 Cookie 或已连接应用的登录令牌，也无法将它们保存到记忆中。它们只会经过模型无法访问的独立机器，管理其行为的批准和安全检查也在那里运行。

密码

当某个网站要求输入密码时，你会在 Claude 应用内的表单中输入。该表单使用一次性密钥对密码进行加密，这个密钥只存在于我们安全的云浏览器机器上，且仅限这一次使用。它会把加密后的密码原封不动地传递给浏览器，由浏览器输入到网站中。模型看不到密码，也无法保存或复述它。很快你还将能够使用 1Password 登录；Claude Duet 会请求凭据，你在 1Password 中批准该请求，凭据将直达浏览器，不会经过模型。

替你登录的智能体会从两个方面改变钓鱼攻击的局面。一方面，Claude Duet 不替你保管凭据，因此它不可能被钓走密码，任何隐藏指令也无法让它泄露一个它本就不拥有的秘密。另一方面，登录表单本身会成为攻击目标，因为任何要求输入密码的东西都可能被仿冒。因此，Claude Duet 的登录表单只会在应用内、在你主动发起的登录过程中出现。它永远不会以链接、短信、电子邮件或 claude.ai 之外的网站形式出现。如果任何其他地方出现一个看起来像 Claude Duet 的东西向你索要密码，那都不是官方的。

登录令牌

当 Claude Duet 在已连接的应用中工作时，它会遵循我们的 Claude Managed Agents 设计 （在新标签页中打开），让凭据始终处于智能体工作范围之外。智能体代表你使用的凭据（例如已连接服务的登录令牌）永远不会进入智能体工作的机器。机器上取而代之的是一个凭据占位符，机器之外的一个代理只在发起请求时才放入真实值。

浏览器

Claude Duet 中的浏览器运行在云端专属的独立虚拟机中，与模型以及智能体工作的云计算机分开。智能体只能通过一组固定的命令驱动浏览器：打开这个页面、点击这里、输入这些内容。网站运行的任何内容都只停留在浏览器机器上 （在新标签页中打开）。网站的代码和 Cookie 不会进入 Claude Duet 的记忆或你的已连接应用，智能体的任何命令也都无法从浏览器中读取 Cookie。返回的只有页面的文本和下载内容，因为智能体必须读取它们才能完成工作。这正是其他检查存在的原因，也是 Claude Duet 采用我们的浏览器使用研究 （在新标签页中打开）中所述提示注入防护措施的原因。它通过浏览器上传的文件也会接受与消息相同的敏感信息检查。

Claude Duet 还被设计为会表明自己智能体的身份。如今，其浏览器发出的请求带有独特的 User-Agent 标头，我们还会公布它浏览所用的公共 IP 地址，以便网站能够识别它并决定如何对待它。在发布之前，我们还联系了多家大型网站，让它们可以选择阻止 Claude Duet 访问，其中一些网站选择了阻止。我们将随着研究预览阶段的推进，不断改进 Claude Duet 表明自身身份的方式。

我们如何测试 Claude Duet

测试早在研究预览之前就开始了，如今仍在继续。我们的 Safeguards 团队基于例行形态的任务构建了评估，每个任务有三个变体：一个无害版本、一个带有注入指令的版本，以及一个引诱智能体超出要求行动的版本。这些评估与来自真实使用的影子流量并行运行。

红队进一步测试了 Claude Duet 是否会泄露信息、未经批准采取行动，或遵循恶意提示。我们为整个系统构建了威胁模型，涵盖它所触及的代码仓库和信任边界。一家外部渗透测试公司带着我们源代码的访问权限测试了 Claude Duet，一项涵盖云浏览器和登录表单的后续测试正在进行中。每项新的凭据功能在向任何人发布之前，都会在隔离的实验环境中接受红队测试。

Claude Duet 也在 Anthropic 公开漏洞赏金计划的范围内，该计划根据我们的负责任披露政策，为有效报告提供奖励，并为善意的研究提供安全港。如果你发现安全漏洞，我们希望听到你的报告：请通过 Anthropic 在HackerOne （在新标签页中打开）上的漏洞赏金计划提交。

与你共同建设

我们以研究预览的形式发布 Claude Duet，是因为我们想了解你在个人智能体中看重什么，包括你希望接下来看到哪些保护措施和控制选项。这里描述的一些内容仍在变化之中：它询问批准的频率、你的登录方式，以及敏感信息检查在区分私人信息与无害内容方面的表现。用直白的语言告诉 Claude Duet 你希望看到什么或哪里出了问题，它会为我们的团队提交一份报告。

我们在 Anthropic API Console 中推出了 Workspaces，帮助开发者高效管理多个 Claude 部署。Workspaces 是独立的环境，让你能够组织资源、简化访问控制，并在更细的粒度上设置自定义支出和速率限制。

管理多个部署

对于在不同环境（如开发、预发布和生产）和不同用例中使用 Claude 的开发者来说，Workspaces 为整个组织和各个 API 密钥提供了一个抽象层。

借助 Workspaces，你可以：

  • 设置细粒度的支出限制：按 Workspace 设置月度支出限制，对 API 使用成本实现精细控制。
  • 对相关资源分组：将 API 密钥、使用数据和设置组织成与你的项目或环境相对应的逻辑分组。
  • 管理速率限制：在组织整体速率限制之内，为每个 Workspace 独立调整速率限制，更好地管理各部署之间的负载。
  • 简化访问控制：在 Workspace 级别分配用户权限，提升账号安全性。
  • 高效监控使用情况：按 Workspace 洞察 API 使用量和成本，更轻松地追踪和优化资源配置。

开始使用

Workspaces 现已向所有 Anthropic API 用户开放，可在我们的 Console 中使用。要开始使用，你可以在此处使用 Workspace 范围的 API 密钥创建一个 Workspace。想了解更多，请查阅我们的帮助中心中的详细指南。

聊天和 Cowork 最早在九月为 Pro 和 Max 套餐走到了一起。如今，同一个统一的 Claude 体验已面向 Claude Enterprise 套餐全面开放。

聊天和 Cowork 现在在网页、桌面和移动端上合二为一，你的团队可以在同一段对话中提出一个快速问题，或把整个项目交托出去。智能体工作运行在 Anthropic 托管的云环境中，Claude Enterprise 管理员可以按角色控制访问权限，并通过全新的 Efficient 模式管理用量。

一个 Claude 应对所有任务

团队成员在开始使用 Claude 之前，不再需要在聊天和 Cowork 之间做出选择。对话以聊天开始，简单的问题依然能快速得到回答。当任务需要运行代码或处理文件时，Claude 会在云端继续推进，并返回完成的文档、分析或演示文稿。由于工作在云端运行，即使有人合上笔记本电脑，任务也会继续进行，他们可以在网页、桌面或移动端接着处理。聊天、项目、连接器、技能和插件都会延续到新的统一体验中。

各组织已经看到统一的 Claude 体验为团队带来的价值：

保障安全

如果你的组织已经批准使用 Claude 聊天，这一新体验将建立在你们已在使用的企业控制措施之上，包括单点登录（SSO）和 Compliance API。Anthropic 依然对传输中和静态数据加密，且默认不会将其用于模型训练。

Claude 在云端会话中执行智能体工作，每个会话都运行在相互隔离的虚拟机中；对 Claude Enterprise，网络出口默认关闭，连接器凭据存放在沙箱之外。由于这些工作运行在 Anthropic 统一托管的单一环境中，你的安全团队可以对其进行集中可见和集中管控。安全最佳实践指南位于 Anthropic Trust Center，涵盖完整架构。

管理成本

Claude Enterprise 定价依然按用量计费。最新的 Claude 模型比前代更高效：按用量计费时，Claude Opus 5.5 在典型工作负载下的运行成本比 Claude Opus 5 低 40%，Claude Sonnet 5.5 在多数工作中的成本比 Claude Sonnet 5 最多低 30%。

取决于任务类型，智能体工作可能比快速聊天消耗更多 token。Claude Enterprise 管理员有四种控制方式来管理用量。Efficient 模式是一项新设置，让统一的 Claude 体验保持在 Sonnet 和 Haiku 模型上。模型权限（Model entitlements）决定每个角色可以使用哪些模型。支出上限适用于组织、群组和成员三个层级，而群组共享预算（pooled group budgets）为群组提供一个共用的月度额度。

开始使用

统一的 Claude 体验今天起面向 Claude Enterprise 套餐全面开放。管理员可以在组织设置中管理逐步上线。使用 Claude Code 零数据留存、HIPAA 就绪配置或客户托管加密密钥的组织将继续使用其现有配置。

详情请参阅管理员设置指南。如果你已是 Claude Enterprise 客户，你将收到关于你所在组织上线的邮件通知。

从今天起，Claude Managed Agents 可以在由你掌控的沙箱中运行，并连接你的私有 Model Context Protocol (MCP) 服务器。无论是智能体执行工具所在的沙箱，还是它能访问的服务，都运行在企业既有的边界之内，受你的安全与运行时管控。

沙箱可以跑在你自己的基础设施上，也可以交给 Cloudflare、Daytona、Modal 或 Vercel 这类托管服务商，由它们替你完成计算和隔离。

在 Claude Platform 上，自托管沙箱已进入公测，MCP tunnels 处于研究预览阶段（可申请访问）。

自托管沙箱：让智能体的执行留在你的边界之内

自托管沙箱让 Claude Managed Agent 能在你控制的基础设施上或通过托管沙箱服务商执行工具。代码执行、敏感文件、软件包、服务和数据都留在你的企业边界之内，受你的安全与运行时管控。

借助自托管沙箱，敏感文件、软件包和服务可以保留在你自己的基础设施或托管沙箱服务商那里。负责编排、上下文管理和错误恢复的智能体循环仍运行在 Anthropic 的基础设施上，而工具执行则转移到你配置好的环境中。

在你的边界之内，网络策略、审计日志和安全工具早已就位，文件和代码仓库不会外流。算力也由你掌控：资源规格和运行时镜像都在你这一侧设定，因此运行长时构建或图像生成等计算密集型工作的智能体，可以获得任务所需的 CPU、内存和容量。

选择你的沙箱客户端

可以自带任何沙箱客户端，也可以从我们支持的服务商中选一个起步：

  • Cloudflare 使用 microVM 和更轻量的隔离体（isolate）大规模运行沙箱。出站网络请求由你掌控：支持零信任密钥注入、可自定义的代理（用于审计、改道或修改出站流量），并能通过 Cloudflare 网络连接内部服务。Amplitude 正基于 Managed Agents 和 Cloudflare 构建 Design Agent——一个用于产出符合品牌规范的 UI 和营销设计的内部工具，以获得更强的可观测性与控制力。
  • Daytona 沙箱是完整、可组合的计算机，可长时间运行并保持状态。同一套原语既能跑一个快速任务，也能跑连续工作数小时的智能体。会话进行期间，你可以通过 SSH 或经过鉴权的预览 URL 随时访问沙箱，也可以将其暂停并在完整保留状态的情况下恢复。Clay 的 GTM 工程智能体 Sculptor 就构建在 Managed Agents 和 Daytona 之上，可自主完成工作流的构建、测试和监控。
  • Modal 是为 AI 工作负载打造的云平台，沙箱与 Modal 的函数、存储和网络原语共享同一套基础，构建生产级 AI 系统所需的能力一应俱全。Modal 的自研容器运行时可在任意镜像上实现亚秒级启动，可扩展到数十万个并发沙箱，并按需提供 CPU 和 GPU 资源。
  • Vercel 沙箱结合了虚拟机安全性、VPC 对等连接和自带云能力，启动时间以毫秒计。Managed Agents 负责模型、工具和会话状态，而 Vercel Sandbox 防火墙在网络边界注入凭据，凭据永远不会进入沙箱。面向机构金融领域的 AI 平台 Rogo 正基于 Managed Agents 和 Vercel Sandbox 构建分析师智能体，以安全地处理其专有数据。

MCP tunnels：连接私有网络内的服务

MCP tunnels 让 Claude Managed Agents 连接私有网络内的 Model Context Protocol (MCP) 服务器，而无需将其暴露到公网。内部数据库、私有 API、知识库和工单系统都成为智能体可以调用的工具。你只需部署一个轻量网关，发起单一出站连接即可——不需要入站防火墙规则，没有公网端点，流量端到端加密。

MCP tunnels 在 Managed Agents 和 Messages API 中均受支持，由组织管理员在 Claude Console 的工作区设置中管理。

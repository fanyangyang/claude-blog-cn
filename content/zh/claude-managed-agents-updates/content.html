从今天起，Claude Managed Agents 可以在你控制的沙箱中运行，并连接到你的私有 Model Context Protocol（MCP）server。agent 执行工具的沙箱，以及它到达的服务，都运行在企业既定边界之内，并处于你的安全和运行时控制之下。

沙箱运行在你自己的基础设施上，也可以交给 Cloudflare、Daytona、Modal 或 Vercel 等托管提供方来处理算力和隔离。

自托管沙箱：把 agent 执行留在你的边界内

自托管沙箱让 Claude Managed Agent 能在你控制的基础设施上，或在托管沙箱提供方上执行工具。代码执行、敏感文件、软件包、服务和数据都留在企业边界之内，并处于你的安全和运行时控制之下。

有了自托管沙箱，你可以把敏感文件、软件包和服务留在自己的基础设施或托管沙箱提供方上。负责编排、上下文管理和错误恢复的 agent loop 仍在 Anthropic 的基础设施上，而工具执行则移到你配置的环境中。

在你的边界内，网络策略、审计日志和安全工具已经就位，文件和仓库也不会离开。你还控制算力：资源规格和运行时镜像由你这边设定，因此运行长构建或图像生成这类计算密集型工作的 agent，能获得任务所需的 CPU、内存和容量。

选择你的沙箱客户端

你可以带上任意想用的沙箱客户端，或从我们支持的提供方开始：

  • Cloudflare 使用 microVM 和更轻量的 isolate 大规模运行沙箱。出站网络请求由你控制，包括零信任密钥注入、可定制代理以审计、改道或修改出口流量，以及通过 Cloudflare 网络连接内部服务的能力。Amplitude 正在 Managed Agents 和 Cloudflare 上构建 Design Agent，这是一个用于符合品牌的生产 UI 和营销设计的内部工具，以获得更紧密的可观测性和控制。
  • Daytona 沙箱是完整、可组合的计算机，可长时运行且有状态。同一种原语既能跑一次短促爆发，也能跑一个工作数小时的 agent。会话运行期间，沙箱可通过 SSH 或经过认证的预览 URL 保持可访问，也可以暂停并恢复，完整状态得以保留。Clay 的 GTM 工程 agent Sculptor，在 Managed Agents 和 Daytona 上自主构建、测试和监控工作流。
  • Modal 是为 AI 工作负载构建的云平台，沙箱与 Modal 的函数、存储和网络原语共享同一基础，为你构建生产 AI 系统提供所需的一切。Modal 的定制容器运行时能在任意镜像上实现亚秒级启动，扩展到数十万并发沙箱，并按需提供 CPU 和 GPU 资源。
  • Vercel 沙箱结合了 VM 安全、VPC peering 和自带云，并具备毫秒级启动时间。Managed Agents 负责模型、工具和会话状态，而 Vercel Sandbox 防火墙在网络边界注入凭证，因此凭证永远不会进入沙箱。Rogo 是面向机构金融的 AI 平台，正在 Managed Agents 和 Vercel Sandbox 上构建分析师 agent，以安全处理其专有数据。

MCP tunnels：连接到你私有网络内的服务

MCP tunnels 把 Claude Managed Agents 连接到你私有网络内的 Model Context Protocol（MCP）server，而无需把它们暴露到公网。内部数据库、私有 API、知识库和工单系统变成你的 agent 可以调用的工具。你部署的轻量网关只发起一条出站连接，无需入站防火墙规则，无需公共端点，流量端到端加密。

MCP tunnels 在 Managed Agents 和 Messages API 中受支持。MCP tunnels 由组织管理员在 Claude Console 的工作区设置中管理。

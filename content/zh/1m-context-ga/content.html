Claude Opus 4.6 和 Sonnet 4.6 现已在 Claude Platform 上以标准价格提供完整的 1M 上下文窗口。标准价格适用于整个窗口——Opus 4.6 为每百万 token $5/$25，Sonnet 4.6 为 $3/$15。没有任何加价系数：一个 900K token 的请求与一个 9K token 的请求按完全相同的单价计费。

正式发布（GA）后的新变化：

  • 一个价格，完整上下文窗口。没有长上下文溢价。
  • 所有上下文长度均享有完整速率限制。你账户的标准吞吐量适用于整个窗口。
  • 每次请求可处理的媒体数量提升 6 倍。最多支持 600 张图片或 PDF 页面，此前为 100。即日起在 Claude Platform（原生）、Microsoft Foundry 和 Google Cloud 的 Vertex AI 上可用。
  • ​​无需 beta header。超过 200K token 的请求自动生效。如果你已经在发送 beta header，它会被忽略，因此无需修改任何代码。

使用 Opus 4.6 的 Claude Code Max、Team 和 Enterprise 用户现在已包含 1M 上下文。Opus 4.6 会话可以自动使用完整的 1M 上下文窗口，这意味着更少的压缩（compaction）操作，以及更多得以完整保留的对话。此前 1M 上下文需要额外付费使用。

经得起考验的长上下文

一百万 token 的上下文只有在模型能够回忆起正确的细节并在其中进行推理时才有意义。Opus 4.6 在 MRCR v2 上取得 78.3% 的成绩，是该上下文长度下前沿模型中的最高水平。

这意味着你可以加载整个代码库、数千页的合同，或者一个长时间运行 agent 的完整轨迹——包括工具调用、观察结果和中间推理——并直接加以使用。长上下文工作以前所需的工程处理、有损摘要和上下文清理，现在都不再需要。完整的对话将原样保留。

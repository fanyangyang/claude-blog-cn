Claude Opus 4.6 和 Sonnet 4.6 现已在 Claude Platform 上以标准定价提供完整的 1M 上下文窗口。标准定价覆盖整个窗口——Opus 4.6 为每百万 token $5/$25，Sonnet 4.6 为 $3/$15。没有倍率：90 万 token 的请求与 9 千 token 的请求按相同的每 token 费率计费。

正式发布带来的变化：

  • 一个价格，完整上下文窗口。不再有长上下文溢价。 
  • 任意上下文长度都享受完整速率限制。你账户的标准吞吐适用于整个窗口。
  • 每次请求的媒体容量提升 6 倍。最多 600 张图片或 PDF 页，此前为 100。即日起可在 Claude Platform 原生环境、Microsoft Foundry 以及 Google Cloud 的 Vertex AI 上使用。
  • ​​无需 beta header。超过 200K token 的请求会自动生效。如果你已经在发送 beta header，它会被忽略，因此无需改代码。

1M 上下文现已包含在面向 Max、Team 和 Enterprise 用户、使用 Opus 4.6 的 Claude Code 中。Opus 4.6 会话会自动使用完整的 1M 上下文窗口，意味着更少的 compaction，对话也能保留得更完整。此前 1M 上下文需要额外用量。

经得起检验的长上下文

一百万 token 的上下文只有在模型能召回正确细节并跨内容推理时才有意义。Opus 4.6 在 MRCR v2 上拿到 78.3%，是该上下文长度下前沿模型中的最高分。

这意味着你可以加载整个代码库、数千页合同，或一个长时运行 agent 的完整轨迹——工具调用、观察、中间推理——并直接使用。此前长上下文工作所需的工程处理、有损摘要和上下文清理不再必要。完整对话可以保持原样。

开始使用

1M 上下文即日起可在 Claude Platform 原生环境使用，也可通过 Amazon Bedrock、Google Cloud 的 Vertex AI 和 Microsoft Foundry 使用。使用 Opus 4.6 的 Claude Code Max、Team 和 Enterprise 用户会自动默认使用 1M 上下文。

10 月，我们推出了 skills——一种把可重复工作流教给 Claude、并按你的工作方式定制的方法。今天我们让 skills 更易于部署、发现和构建：面向管理员的全组织管理；来自 Notion、Canva、Figma、Atlassian 及其他合作伙伴构建的 skill 目录；以及一项开放标准，让 skills 可以跨 AI 平台使用。

在组织内管理 skills

Claude Team 和 Enterprise 计划的管理员现在可以从管理设置中集中配置 skills。管理员配置的 skills 默认对所有用户启用。用户仍可自行关闭单个 skill。这让组织能在各团队间保持一致、经过批准的工作流，同时允许个人用户定制自己的体验。

发现、创建和编辑新的 skills

创建 skills 现在更简单。描述你想要什么，Claude 会帮你构建，你也可以直接写指令。对于复杂工作流，可以上传 skill 文件夹，或使用 skill-creator。Claude 也可以帮你编辑已有 skills；新的预览会展示完整内容，让你在启用前准确了解某个 skill 做什么。

Skills 目录

不断增长的合作伙伴构建 skill 集合现已发布在 claude.com/connectors。

管理员可以把这些合作伙伴 skills 配置到整个组织，让团队立即获得他们已经在用的工具的工作流，无需任何定制开发。

一项开放标准

我们还将 Agent Skills 作为开放标准发布。和 MCP 一样，我们相信 skills 应当可以跨工具、跨平台移植——同一个 skill，无论你在用 Claude 还是其他 AI 平台，都应该能正常工作。我们一直在与生态中的成员协作，也很高兴看到该标准的早期采用。

开始使用

  • Claude Apps：浏览 skills 目录，并在 Settings > Capabilities > Skills 中启用。
  • Claude Code：从 plugin 目录安装，或把 skills 检入你的仓库。
  • Claude Developer Platform (API)：通过 /v1/skills 端点使用 skills。见 文档。

管理员可以通过 Admin Settings 在全组织配置 skills。Skills 需要启用 Code Execution and File Creation。

今天我们推出 beta 版 Claude Whiteboards 和 Claude Sheets，同时 Claude Dashboards (opens in new tab) 以 Claude Data 之名正式全面可用。Whiteboards 是一块共享看板，供团队与 Claude 一起头脑风暴；Sheets 是 Claude 与你共同创建和编辑的电子表格；Claude Data 则新增了数据故事、认证查询（certified queries）和实时共享。这些功能在所有付费方案中均可使用。

以往与 Claude 一起做项目，往往意味着把产出搬到另一个工具或程序里，而 Claude 在那里无法实时跟进进展和变更。现在，你的文档、看板、表格和仪表盘都可以留在 Claude 里，团队也能一起继续编辑。准备就绪后，你可以把产出直接带入我们合作伙伴的工具中，在那里继续工作。

Claude Whiteboards

很多人把 Claude 当作思考伙伴，但与它头脑风暴通常意味着要把结果复制粘贴到别处，才能开始与同事协作。现在，你可以对着 Claude 把凌乱的计划讲出来，Claude 能把它变成一块带有时间线、负责人和日期的看板，让你和团队实时协作。比如在复盘会上，每个人都可以写下笔记，Claude 可以按主题归类，并为每个人起草行动项。你可以用鼠标框选看板的任意区域，向 Claude 提问，专注处理那部分内容。头脑风暴结束后，Claude 可以把看板转成文档或幻灯片，或带入 Lucid、Miro、Vani by Zoho 等工具，和团队继续推进。

Claude Sheets

Claude 现在能生成带标签页、公式、格式和下拉选项的电子表格，往往只需要一句提示，比如要一份营销活动跟踪表或招聘预算表。它可以在单元格中编辑，并逐条标出每处新改动，方便你跟踪变更。你可以把表格分享给团队，和 Claude 一起协作。

目前表格只有基础的电子表格功能，我们正在补充更多能力。当你需要 Excel 的完整功能时，可以把文件导出为 .xlsx 或 CSV，或使用 Claude for Excel (opens in new tab)。你也可以在 Airtable、Asana、monday.com 和 Smartsheet 等合作伙伴工具中继续工作。

Claude Data

Claude Dashboards (opens in new tab) 于 10 月以 beta 版发布，让团队可以就 Amazon Redshift、BigQuery、ClickHouse 等工具中的公司数据快速提问。从今天起，它以 Claude Data 之名正式全面可用。我们改名，是因为企业使用数据的方式远不止仪表盘，产品如今也覆盖了更广泛的工作方式。认证查询和实时共享目前处于 beta 阶段。以下是团队使用 Claude Data 的几种方式：

  • 创建认证的指标定义。你的数据团队可以认证大家应当使用的查询，避免出现彼此数据口径冲突的仪表盘。基于这些指标构建的图表会带有「已认证」徽章，表明其经过认证。
  • 从数据中提炼故事。你可以在 Claude Data 中与 Claude 协作，基于指标起草数据故事或旁白视频，分享前由你审核。
  • 把最新数字分享给所有人。通过实时共享，同事打开共享仪表盘时能看到最新数字，即使他们没有维护该数据更新的连接器访问权限。查看者看到的是你已批准的查询结果，无法借用你的权限运行其他查询。
  • 匹配你的视觉风格。Claude Data 现已支持设计系统。
  • 通过缓存加快加载。以前每次加载仪表盘都要重新拉取数据。现在仪表盘支持缓存，并可按仪表盘单独设置刷新频率。
  • 追踪历史变更。Claude Data 现已支持变更追踪，你可以看到谁做过编辑，并在需要时回滚到指定版本。

Claude Data 的合作伙伴包括 Amplitude、Mixpanel、Omni、PostHog 和 Sigma。

也可以在你的其他工具中工作

从今天起，交互式连接器 (opens in new tab) 可以在对话旁或全屏以完整应用的形式打开，让你自己直接在 Adobe、Atlassian、Box 和 Notion 等工具中工作，或让 Claude 与你一起修改。

开始使用

Claude Whiteboards、Sheets 和 Data 可在网页版、桌面端和移动端使用。Claude Data 需要数据连接器，例如数据仓库或 CRM。

致管理员：在 Team 方案中，这三项默认开启。在 Enterprise 方案中，Claude Whiteboards 和 Sheets 默认关闭，Claude Data 将于 2026 年 11 月 19 日默认开启。你可以随时在「组织设置 > Artifacts」中更改这些设置。

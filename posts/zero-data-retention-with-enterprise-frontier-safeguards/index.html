Zero data retention with Enterprise Frontier Safeguards is now in beta

Enterprise Frontier Safeguards is now in public beta, providing detection of sophisticated misuse while remaining compatible with zero data retention.

  • Category
    Product updates
  • Date
    November 23, 2026
  • Reading time
    2 min
  • Share

过去几个月，我们一直在为商业客户开发 Enterprise Frontier Safeguards（EFS）。EFS 提供最先进的复杂滥用检测能力，同时与零数据保留（ZDR）兼容：Anthropic 和任何云服务提供商都不会保留企业的数据。

自我们在 9 月宣布 EFS 以来，我们与 100 多家客户一起持续开发它——其中包括四分之一的《财富》100 强企业，以及许多来自对数据可见性有严格规定的行业（如医疗、金融服务和法律）的公司。Bridgewater、Salesforce 和 Stripe 等领先企业已在私有 beta 中评估 EFS。

现在，我们以公开 beta 形式开放 EFS。本文将进一步说明 EFS 的工作原理、它如何保持与 ZDR 兼容，以及企业如何加入 beta 计划。

EFS 如何在 ZDR 下提供自动化安全监控

依赖传统 ZDR 的客户，受到 Claude 分类器的保护：这些实时安全防护会筛查单个请求，评估其是否可能造成伤害。但复杂的攻击通常跨越多次查询——单独看任何一个请求，都可能显得无害。

例如，我们 9 月的威胁情报报告描述了一起针对约五十家组织的行动：其中一个 AI 智能体把攻击工作拆分给许多并行运行的其他智能体。它把收集到的凭据保存在会话之间，便于攻击者随时恢复行动。若逐条查看请求，这次攻击会显得像一系列彼此独立、更为无害的任务。

为了捕获这类攻击，我们使用了第二层防御，称为自动化安全监控。这一层会在大量请求中寻找滥用模式。通过 EFS，Anthropic 可以在不存储任何客户数据的前提下提供自动化安全监控。我们的自动化安全监控系统分析的数据，完全存储在由客户自己控制的基础设施上。

当自动化安全监控发现风险时，会创建一个 Safety Case 供你审阅。这些案例可以从你的云存储或通过 API 读取，并能与安全信息和事件管理（SIEM）系统集成。它们不包含输入和输出内容。

设置完成后，自动化安全监控可以帮助你的团队发现可能导致严重伤害的故意滥用（例如攻击性网络行动）。它还可以帮助发现智能体采取了超出用户意图的行动，例如在极端情况下，利用软件漏洞访问内部数据库或外部系统。

零数据保留与 EFS

使用 EFS 时，你自带存储来保存输入和输出。一旦数据交付到你控制的存储中，Anthropic 和你的云服务提供商都不会保留其副本。这为你提供以下保证：

  • 零数据保留。Anthropic 和你的云服务提供商都不会保留你的数据。你自带存储并保存自己的数据。输入和输出在写入你自己的存储后会被及时删除。你可以自行配置访问策略和审计日志，并用你自己的密钥加密安全数据。
  • 没有运营方人工审阅。Anthropic 和你的云服务提供商的人员都不会访问你的输入和输出。只有自动化安全监控可以访问这些数据。
  • 我们绝不使用你的数据训练模型。输入和输出仅用于自动化安全监控，绝不用于模型或分类器训练。

你可以通过 Claude Platform、AWS 上的 Claude Platform、Amazon Bedrock 或 Google Cloud 上的 Claude 使用 EFS。当你通过 Amazon Bedrock 或 Google Cloud 上的 Claude（Google 托管）使用 EFS 时，它由你的云服务提供商运营，端到端的数据流始终停留在该云的边界之内。

你可以在自己的账户中使用 Amazon S3 或 Google Cloud Storage 作为存储，具体取决于你在哪里使用 Claude。云服务提供商照常对该存储计费，包括读取、写入和密钥操作（以及任何适用的网络传输费用）。

开始使用

EFS 已在 Claude Platform、AWS 上的 Claude Platform、Amazon Bedrock 和 Google Cloud 上的 Claude 上提供。Microsoft Foundry 对 EFS 的支持即将推出。

符合条件的客户将收到通知及上手说明。阅读我们的开发者文档了解如何设置，阅读我们的安全白皮书 （在新标签页中打开）了解架构如何运作，或通过 Accenture、Deloitte、KPMG 和 PwC 等咨询合作伙伴进行部署。

Claude Enterprise

Claude Enterprise 让你的整个组织都能使用 Claude、Claude Code 和 Cowork——同时提供企业级安全能力，并支持处理大型代码库、海量文档集和广泛的组织上下文。 

你的团队可以与 Claude 头脑风暴，从网页端和终端委派编程任务，或者把复杂的多步骤项目交给 Claude，坐等成品交付。借助使用插件的 Cowork，你还可以把 Claude 打造成销售、财务、法务、营销等领域的专家。

Claude 也能与你团队已在使用的工具协同工作。通过连接器接入 Microsoft 365、Slack 等平台，或通过内置的聊天侧边栏直接在 Excel 和 PowerPoint 中与 Claude 协作。

Claude Enterprise 内置组织大规模部署 AI 所需的安全与管理控制：

  • 通过单点登录（SSO）和域名捕获管理用户访问，并通过 SCIM 自动化开通流程。 
  • 审计日志和 Compliance API 让你的安全与合规团队清楚掌握 Claude 的使用情况，管理员可以在整个组织范围内管理权限。
  • 管理员可以设置自定义数据保留策略，并通过用量分析跟踪团队活动、功能采用情况和支出
  • 默认情况下，Anthropic 不会使用 Claude Enterprise 的内容训练模型。

组织如何使用 Claude Enterprise

定价

Claude Enterprise 采用简单的“席位 + 用量”计费模式。用量按 API 费率计费，你的组织只为实际使用的部分付费。管理员可以在组织和个人用户两个层面设置支出上限，可靠地管理成本。

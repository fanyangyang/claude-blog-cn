Google Cloud 上的 Claude 模型（Anthropic 托管）正式发布

Claude Models on Google Cloud（Anthropic 托管）现已正式全面推出，为 Google Cloud 客户提供完整的 Claude Platform 功能集，支持 Google Cloud IAM 凭据、账单和承诺消费额抵扣。

Claude Models on Google Cloud（Anthropic 托管）现已正式全面推出，为 Google Cloud 客户提供完整的 Claude Platform 功能集，支持 Google Cloud IAM 凭据、账单和承诺消费额抵扣。Claude 也仍可通过 Google 托管服务使用，该服务中 Google 作为数据处理方。

在 Google Cloud 上使用完整的 Claude Platform

通过 Anthropic 托管服务，Google Cloud 客户现在可以获得完整的 Claude API 功能，新功能和测试版与原生 Claude Platform 上线的同一天发布。

Anthropic 托管服务兼容现有的 Google Cloud IAM 凭据，因此团队可以继续使用他们已管理的工具和权限。账单通过一张 Google Cloud 发票统一结算，Claude 用量会计入你现有的 Google Cloud 承诺消费额。

Claude Models on Google Cloud（Anthropic 托管）目前支持美国和全球端点。

包含哪些功能

使用 Anthropic 托管服务的 Google Cloud 客户可以获得完整的 Claude Platform 功能集，因此他们可以：

使用以下功能构建和部署智能体：

  • Claude Managed Agents（测试版） （在新标签页中打开），用于支撑长时间运行的智能体，无需管理基础设施
  • 代码执行（Code execution） （在新标签页中打开），在 API 调用中运行 Python 代码、创建可视化和分析数据
  • 计算机使用（Computer use） （在新标签页中打开），让 Claude 操作浏览器或桌面来完成各项任务
  • 智能体技能（Agent skills） （在新标签页中打开），教会 Claude 可重复的工作流程，从而产出稳定的结果
  • 顾问策略（测试版） （在新标签页中打开），通过咨询顾问模型为智能体带来智能提升

使用以下功能连接系统与知识：

  • Files API （在新标签页中打开），用于跨对话上传和引用文档
  • 引用（Citations） （在新标签页中打开），将回答锚定在来源文档上
  • 网络搜索 （在新标签页中打开）和网络抓取（web fetch） （在新标签页中打开），用来自全网的最新真实世界数据扩充 Claude 的知识
  • MCP 连接器（测试版） （在新标签页中打开），无需编写客户端代码即可将 Claude 连接到其他工具

使用以下功能管理成本与性能：

  • 提示缓存（Prompt caching） （在新标签页中打开），在重复上下文上降低成本与延迟
  • 批处理（Batch processing） （在新标签页中打开），用于高吞吐量的异步工作负载

使用 Claude Models on Google Cloud（Anthropic 托管）的客户现在也可以全面使用 Claude Opus 5.5 的 Fast Mode。Fast 模式优先追求速度，输出 token 生成速度最高提升 2.5 倍，适用于快速迭代、实时调试和交互式智能体——在这些场景中，输出速度意味着更好的用户体验。输入和输出 token 分别为每百万个 8 美元和 40 美元。

查看我们的文档 （在新标签页中打开），了解 Claude Models on Google Cloud 上可用的完整功能列表。

使用 Anthropic 托管服务的客户还可以访问 Claude Console——Anthropic 用于观察和管理 Claude 智能体的开发环境。Console 包含编写提示词和配置智能体、在托管环境中运行、监控用量与成本，以及按工作区管理访问权限和安全的工具。

现已提供 Claude Fable 5.1、Opus 5.5、Sonnet 5.5 和 Haiku 5.5，新模型一经发布即可在 Anthropic 托管服务上使用。

构建 Claude 应用的两种路径

在 Google Cloud 上有两种方式构建 Claude 应用。

Claude Models on Google Cloud（Anthropic 托管）面向希望第一时间获得全部测试版和正式版 Claude Platform 功能的客户。它最适合希望通过 Google Cloud 访问并获得完整 Claude Platform 功能对等的客户。Anthropic 负责运营该服务并充当数据处理方。

Claude Models on Google Cloud（Google 托管）仍然是需要 Google Cloud 作为数据处理方、有严格区域数据驻留要求，或希望使用 Model Armor、Agent Engine 等原生 Google Cloud 集成的客户的最佳选择。

开始使用

Anthropic 托管服务今天起全面推出。要开始使用，请打开Claude Models on Google Cloud（Anthropic 托管） （在新标签页中打开）或浏览文档 （在新标签页中打开）。

如果你已有折扣，请在开始使用 Anthropic 托管服务前联系你的 Anthropic 或 Google Cloud 客户经理，确保你的折扣得到正确应用。折扣不能追溯应用于已产生的用量。

MCP 服务器现在可以随 Claude 发布 skills、运行 tasks 等更多功能

Skills over MCP 已在 Claude 中进入公开 beta，MCP 服务器可以在工具之外发布 skills。Tasks 和 Elicitation 现已全面可用，File Uploads 即将推出。

Skills over MCP 现在已在 Claude 中进入公开 beta，MCP 服务器可以在提供工具的同时附带 skills。我们还为服务器提供了处理与 Claude 进行更长时间、更交互式工作的方式：Tasks 和 Elicitation 现已全面可用（GA），File Uploads 也即将推出。

两年前，Anthropic 推出了模型上下文协议（Model Context Protocol，MCP），作为将 AI 代理连接到数据所在系统的新标准。该规范一直在持续演进，以满足生产环境中代理的连接需求，并正在成为代理消息传递和编排的基础。

借助今天的更新，Claude 可以像与另一个代理协作一样与服务器协作：向它学习、向它委派任务，并在过程中交换输入和文件。

通过 Skills over MCP 随工具一起提供专业知识

工具名称和描述能告诉 Claude 服务器能做什么，但无法涵盖如何处理特定的用例。借助 Skills over MCP，服务器可以在工具之外发布 skills，帮助 Claude 承接更长期、多步骤的工作。Claude 只在需要时加载 skill，从而保持较低的上文使用量。Skills 会随服务器一起更新，因此开发者可以同时发布工具和指导，用户无需单独安装任何东西。

Skills 可以涵盖最佳实践、分步工作流，甚至针对用户账户或组织量身定制的行动手册。使用 Skills over MCP 的示例：

  • Shopify 帮助 Claude 端到端地设计和更新商家的在线商店。
  • HubSpot 在 Claude 中引导客户完成接入和设置。
  • Atlassian 帮助 Claude 利用深度的组织上下文进行洞察和工作分析。
  • Carta 将帮助 Claude 根据上传的文档起草和发放股权（即将推出）。

Skills over MCP 在 Claude 和 Claude Code 中处于公开 beta 阶段，在 Pro、Max 和 Ultra 方案中默认开启，管理员启用后 Team 方案也可使用。即将在 Enterprise 中推出。

MCP 服务器现在可以承接与 Claude 的长期、交互式工作

生产环境中的代理正在承担更长期、更重要的任务。服务器现在可以通过在后台运行、与用户确认进度以及接收来自 Claude 的文件来支持这类工作。

用 Tasks 移交长期运行的工作。以前，工具调用必须在 Claude 继续推进之前完成。借助 Tasks，服务器可以运行需要耗时的操作，甚至是完整的代理循环，而 Claude 可以继续工作，并在结果就绪时取回。通过 Tasks，ZoomInfo 可以开展更深入的账户和联系人研究，而这些以往需要多次提示才能完成。

用 Elicitation 在调用过程中请求输入。有些操作需要用户批准，比如花钱或删除数据。借助 Elicitation，服务器可以暂停，通过表单或链接向用户请求输入，然后从暂停处继续。使用 Elicitation 的示例：

  • Supabase 在创建付费项目和运行破坏性 SQL 之前确认费用。
  • Railway 在做出可能具有破坏性的更改（如移除服务）之前征询意见。
  • GitHub 要求用户先输入仓库名称，代理才会删除它。

Tasks 和 Elicitation 现已在 Claude 和 Claude Code 中对 Pro、Max 和 Ultra 方案全面可用，并正在向 Team 和 Enterprise 组织推出。

用 File Uploads 收发文件。Claude 将能够向 MCP 服务器传递文件，而不仅仅是文本。File Uploads 扩展可以直接将 PDF、电子表格和图片发送给服务器，而无需经过上下文窗口。

File Uploads 即将在 Claude 和 Claude Code 中向 Pro、Max、Ultra 以及符合条件的 Team 和 Enterprise 方案推出。

今天就为你的插件添加支持

这些功能是开放 MCP 规范及其扩展的一部分，因此支持这些功能的服务器可以在任何兼容的客户端中使用，而不仅是 Claude。要添加支持，请参阅 Skills over MCP、Tasks、Elicitation 和 File Uploads 的文档。

建立在更强大的生产环境代理连接基础之上

得益于整个 AI 生态系统的贡献，MCP 现在每月 SDK 下载量超过 7 亿次，Claude 拥有超过 10,000 个 MCP 连接器。我们与 MCP 社区合作改进了 MCP 在 Claude 中的工作方式。在过去一年中，它已经变得：

  • 更节省 token：工具搜索只在需要时加载工具定义，在多服务器配置中可以将它们使用的上下文减少 85% 以上。
  • 更容易扩展：最新的 MCP 规范是无状态的，并得到 Claude 各产品的支持，使构建服务器并随着规模增长保持其可靠性变得更加容易。
  • 更简单的授权：Enterprise Managed Auth 扩展允许管理员一次性授权受支持的服务器，用户即可自动连接。
  • 更具交互性：MCP Apps 扩展将完整界面带入 Claude，可并排显示在对话旁或全屏显示。

这些改进共同使 MCP 更容易构建和采用，也为该标准提供了坚实的基础，使其能够继续为生产环境中代理的需求而演进。

感谢 MCP 社区

MCP 是一个开放标准，由 Agentic AI Foundation 托管，并由在其上构建的人们共同塑造。两年的进展来自撰写规范、构建 SDK、发布服务器和添加客户端支持的管理者、贡献者和开发者。感谢你们让 MCP 成为今天的模样。

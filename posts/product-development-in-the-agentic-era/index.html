智能体时代的产品开发

Jess Yan, Claude Managed Agents product manager, shares how she uses the product to unblock herself and free up time to hone her craft.

在 AI 时代做产品经理，一个有趣的反差是：我的工作比以往任何时候都更有"人味儿"。

产品管理这项工作一直是手艺与对齐的结合。在职业生涯的大部分时间里，我的一周都被后者占据：与跨职能干系人和团队成员开会、写状态报告、和工程团队一起清理工单积压。我习惯了凭直觉快速做决定，然后经历一场艰难的上坡仗——争取支持、说服他人、申请资源；发布有影响力的产品常常更像是一场交易，而非创造。 

有了 Claude，我可以对想法进行压力测试、自动化工作流、摆脱卡壳的困境。我终于能把真正的时间花在用户和团队身上，投入到这份工作中一直最重要的部分：手艺本身。虽然这些新的工作流改变了我的日常，但最有意义的转变发生在我们开始开发 Claude Managed Agents（目前处于 beta 阶段）的时候——这是一套可组合的 API，用于大规模构建和部署云端托管的 agent。

在这篇文章中，我将分享 Managed Agents 如何改变了我作为产品经理的工作方式，以及一些你可以借鉴到自己工作流中的模式。

产品开发的今昔对比

过去，API 设计存在于文档和评论串中；而在 AI 指数级增长曲线上，我们用什么发布就构建什么。一份在文档里读起来优雅的规格说明，等你真正照着构建时可能就土崩瓦解了。借助 Claude Code，我可以基于 API 规格的预发布版本勾勒出一个 agent，一个下午之内就能端到端地跑起一个真正的原型。 

基于用自家原语构建时学到的东西，我们多次重塑了 API 抽象和 Claude Console 的用户体验——这些改动是哪怕数周的文档评审也发现不了的，若靠用户反馈则必然为时已晚。我们仍然会反复推敲接口形态、直接跑原始的 curl 请求，以确保我们对裸金属层面的体验足够满意，但 Claude Code 能让我在同一时段内就从基本的"hello world"测试走到一个可运行的 agent。在构建这些 agent 的过程中，我得以更具体地预判我们的 harness 和 API 该如何弹性演进，以适应下一波模型和任务的进化。

起初这些原型只是用来打磨产品，但如今它们也在改变我的日常工作。作为 PM，我的工作流如今清晰地分布在我们各个产品之间：我用 Claude 和 Claude Cowork 做开放式的研究与探索——那种我希望持续对话的、混沌的早期阶段探索；一旦对要完成的任务有了更清晰的认识，我就用 Claude Code 基于之上 Managed Agents 编写并交付一个定制的 agent。 

这种双重收益是最大的解锁。一方面，能够轻松地基于自己的产品进行构建，抬高了我想象下一个发布物的上限；另一方面，产品上线后，同一种开发能力让我能够自动化那些过去一直卡在待办清单里的长尾运营工作。

面向产品经理的 Managed Agents 使用案例

现在，我可以为任何"待完成的任务"快速搭起定制的 agent。构建过程很简单：我在 Claude Code 中加载 Managed Agents skill，勾勒出我想要的东西的简要草图。开发者也可以使用最新版 Claude Code 和内置的 claude-api skill 来基于 Managed Agents 构建——只需向 Claude 输入“start onboarding for managed agents in Claude API”即可开始。调用这个 skill 后，Claude 会构建 agent，并沿途讲解各个集成步骤，这样我就能随时按需调整方向。 

这类 agent 的例子包括：

  • 采用情况分析。一个能持续访问内部数据库、并具备理解我们数据模式技能的 agent，会运行查询以发现有意义的异常值和规律。借助对既往运行的记忆，它可以在以往发现的基础上继续推进，不断深化自己的视角。
  • 开发者情绪监测。一个配备预构建网页搜索工具和重点关注领域指引的 agent，会扫描一份特定域名列表以获取最新的开发者反馈，并汇报共同主题。由于需要分析的内容太多，它会把研究工作分发给多个 agent 并行处理，等待结果返回后再综合成结论。 
  • 演示构建。一个能访问演示 GitHub 仓库、品牌素材和活动演示文稿的 agent，会把预置模板转化为针对特定受众（如某场大会或某次客户会议）量身定制的精致演示。

Managed Agents 会话在云端运行，所以我可以先离开，回来时发现工作已经完成。那些过去因为每次发布都有各自的特点而永远无法规模化的流程，现在用 Managed Agents 都能轻松自动化，而且每一次 agent 运行都让人干劲十足，而不是索然无味。

腾出空间打磨手艺

一年前，所有这类工作都会在跨职能的人员申请、乱七八糟的电子表格，或那些我一直没机会尝试的半成品想法中缓慢爬行。而现在，借助 Claude 和 Managed Agents，我可以放大自己的能力，把时间用来与团队一起开发最具影响力的产品。我如今的日常包括：与客户一起碰撞创新想法、与工程伙伴深挖混沌而模糊的问题，以及在前沿产品工作中投入真正的创造力。

如果你是一名产品经理，还没有构建过 agent，我建议你这周就从这里开始。那些你一直希望存在的实验和工具，只隔着一条提示词和几次 API 调用。

Claude Cowork 内置浏览器：无需安装

Claude opens its own browser to navigate sites, read pages, and fill forms, inside the desktop app.

Claude 桌面版现在内置了浏览器功能。当任务需要使用网站时，浏览器会在侧边栏中打开，Claude 可以浏览网页、读取内容、点击和输入。现在你可以把涉及网页操作的部分交给 Claude，自己继续手头的工作：Claude 可以帮你填写表单、从仪表盘提取数据、或在没有连接器的门户中操作。无需安装扩展、无需配置，除非你主动选择，否则不会共享你个人浏览器的任何信息。

在此之前，要让 Claude 在 Cowork 中使用网页，只能通过 Claude in Chrome 扩展把浏览器权限交给它。如果你要处理的工作正好是你已经打开的页面，那仍然是更好的选择。但很多网页任务并不需要你的浏览器，只需要一个浏览器，现在 Claude 有了自己的浏览器。

本周起，桌面版 Claude 的 Pro、Max 和 Team 套餐将逐步开放此功能。企业管理员从今天起即可为组织启用。

什么时候用哪个浏览器

这是 Claude 的浏览器，不是你的。内置浏览器与你的个人浏览器完全隔离。Claude 永远看不到你的标签页、书签或密码。如果你希望在特定网站上保持登录状态，可以逐个站点从 macOS 的 Chrome、Edge、Firefox 或 Windows/Linux 的 Firefox 导入登录信息。银行、邮箱和单点登录网站默认排除，除非你选择加入。

这也是 Claude 两种上网方式的区别所在。内置浏览器适合把网页任务交给 Claude 后你继续工作：比如为报告收集资料，或从供应商门户下载本月发票。而 Claude in Chrome 适合你已经在打开的页面上工作，使用你已登录的账号，比如更新 CRM、处理收件箱、或编辑文档。

如果你已经在使用 Claude in Chrome，它会继续正常工作并保持默认；否则 Claude 会使用内置浏览器。随时可以在 设置 → Cowork → 首选浏览器 中切换。

保持控制

内置浏览器与任何在浏览器中操作的 AI 代理一样，面临 提示注入 风险，即页面中隐藏的指令试图引导 Claude 作出非预期行为。它使用了与 Claude in Chrome 相同的安全防护措施，包括审查 Claude 行为是否匹配你要求的检查机制。我们在 Claude in Chrome 的博文 中对此有详细说明。这些措施能显著降低风险但无法完全消除，因此我们建议从你信任的网站开始使用。更多信息请阅读我们的安全指南。

开始使用

内置浏览器将在未来一周内向 macOS、Windows 和 Linux（Beta 版）的 Claude 桌面版 Pro、Max 和 Team 套餐逐步推送。推送后默认开启：给 Claude 一个涉及网站的任务，浏览器会自动打开。企业版现已可用，管理员可以在 组织设置 → Cowork → 内置浏览器 中进行管理。

内置浏览器存在于桌面版中。即使你通过网页或手机使用 Claude，只要桌面版保持打开和在线状态，Claude 仍然可以驱动它。在网页端没有桌面版的情况下，Claude in Chrome 仍然是让 Claude 使用浏览器的途径。

Google Cloud Vertex AI 上的 Claude：获得 FedRAMP High 与 IL2 授权

阅读英文原文 →

今天我们宣布，Claude 模型现已在 Google Cloud 的 Vertex AI 平台上获得 FedRAMP High 和 IL-2 工作负载授权。

凭借这些授权，联邦文职机构和国防组织可以在满足严格监管合规要求的同时使用 Claude，在创新与安全之间取得平衡。

扩大政府对 Claude 的访问

联邦风险与授权管理计划（FedRAMP）为联邦云服务提供了一套标准化的安全评估方法。借助 Vertex AI，联邦机构可以在最高达到 FedRAMP High 授权等级的环境中，在医疗、执法、金融和应急服务等领域使用 Claude，同时满足对敏感非机密数据的合规要求。

同样，国防承包商和机构在处理非受控非机密信息（non-controlled unclassified information）时，可以在最高达到 DoD Impact Level 2（IL2）授权等级的环境中使用 Claude，从而覆盖更广泛的国防用例。

借助 Claude，联邦机构现在可以：

  • 构建满足严格安全标准合规要求的 AI 应用和工作流
  • 使用完整的 Claude 模型家族，包括迄今为止最智能的模型 Claude 3.7 Sonnet
  • 以前沿 AI 能力支撑数字化转型计划

为政府 AI 创新扫清道路

Vertex AI 上的 Claude 以全托管、无服务器的 API 形式提供模型，机构在实施满足自身技术和安全需求的 AI 解决方案时，无需配置或管理基础设施。

Claude 通过 FedRAMP High 和 IL2 授权，对政府客户而言是重要进展，也为未来兼容 IL5 奠定了基础——届时将可支持更敏感的国防部工作负载。

开始使用

联邦政府雇员和承包商可以通过 Google Cloud 的 Assured Workloads 访问 Vertex AI 上的 Claude 模型。Assured Workloads 为政府工作负载提供了增强的安全与合规控制。

要在 FedRAMP High 或 IL2 环境中开始使用 Claude：

  1. 搭建一个配置了 FedRAMP High 或 IL2 的 Assured Workloads Google Cloud 环境
  2. 通过 Vertex AI Model Garden 访问 Claude 模型
  3. 使用 Vertex AI API 端点开始用 Claude 构建

联系我们，获取将 Claude 集成到联邦客户应用中的专业指导，同时确保完全符合 FedRAMP 和 DoD 安全要求。

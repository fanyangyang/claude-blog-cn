Claude Code on the web

阅读英文原文 →

更新： Claude Code on the web 现已作为研究预览版，面向拥有高级席位（premium seats）的 Team 和 Enterprise 用户开放，Pro 和 Max 用户同样可以使用。对于这些用户，Claude Code on the web 默认开启，账户管理员可以在 Claude 设置中开关此功能。2025 年 11 月 12 日

今天，我们推出 Claude Code on the web，这是一种直接在浏览器中委派编码任务的新方式。

目前以研究预览版的形式进行 beta 测试，你可以将多个编码任务交给 Claude，在 Anthropic 管理的云基础设施上运行，非常适合处理积压的 Bug、例行修复或并行开发工作。

并行运行编码任务

Claude Code on the web 让你无需打开终端就能启动编码会话。连接你的 GitHub 仓库，描述你的需求，剩下的实现工作由 Claude 完成。

每个会话都在相互隔离的独立环境中运行，并提供实时进度跟踪；在 Claude 处理任务的过程中，你也可以随时引导它调整方向。

由于 Claude Code 运行在云端，你现在可以通过单一界面在不同仓库间并行运行多个任务，并借助自动创建 PR 和清晰的变更摘要更快地交付。

灵活适配各种工作流

Web 界面与你现有的 Claude Code 工作流形成互补。在云端运行任务尤其适合：

  • 解答关于项目运作方式和仓库结构的问题
  • Bug 修复以及边界清晰的例行任务
  • 后端变更，Claude Code 可以采用测试驱动开发来验证修改

你也可以在移动端使用 Claude Code。作为本次研究预览的一部分，我们在 iOS 应用中提供了 Claude Code，让开发者可以随时随地用 Claude 进行编码。这还是一个早期预览版本，我们希望根据你的反馈快速完善移动端体验。

安全优先的云端执行

每个 Claude Code 任务都运行在带有网络和文件系统限制的隔离沙箱环境中。Git 交互通过安全的代理服务处理，确保 Claude 只能访问经过授权的仓库——在整个工作流中保护你的代码和凭据安全。

你还可以添加自定义网络配置，指定 Claude Code 可以从沙箱中连接哪些域名。例如，你可以允许 Claude 从互联网下载 npm 包，以便它运行测试并验证更改。

欢迎阅读我们的工程博客和文档，深入了解 Claude Code 的沙箱机制。

开始使用

Claude Code on the web 现已作为研究预览版面向 Pro 和 Max 用户开放。访问 claude.com/code，连接你的第一个仓库，开始委派任务。

云端会话与其他所有 Claude Code 用途共享速率限制。查阅我们的文档了解更多信息。

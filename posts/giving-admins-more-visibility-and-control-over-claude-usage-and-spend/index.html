让管理员对 Claude 的用量与支出拥有更多可见性和控制力

New analytics and cost controls are available for Claude Enterprise.

  • Category
    Product announcements
  • Product
    Claude Enterprise
  • Date
    July 2, 2026
  • Reading time
    5 min
  • Share

我们为 Claude Enterprise 引入了更丰富的管理员分析、模型级权限以及支出告警。随着 Claude 在组织内承担越来越难、越来越复杂的 agentic 工作，用量和成本模式已不同于普通聊天工具。这些控制让管理员既能看清 Claude 如何被使用，也有工具来管理成本。 

今天的新增能力建立在 Anthropic 已有的控制之上：各层级支出上限、访问与模型路由、带导出和 Analytics API 的用量分析仪表盘，以及 effort 控制。更丰富的分析和更细粒度的成本控制，是我们过去几个月持续搭建的控制面的最新一层。

追踪采用情况与成本

面向管理员的分析仪表盘现在按组和按用户展示用量与成本，并把 artifacts 创建、文件编辑、skills 和 connector 使用等产出直接显示在对应成本旁边。管理员可以按 IT 团队已经在管理的 SCIM 组过滤，因此拆分会跟随现有组织架构。

Claude Code 在管理控制台中新增了两个聚焦价值和用量的标签页，洞察更丰富。Usage 展示活跃开发者、会话数和组织内的热门命令，每日更新。Value 标签页汇总用量和成本数据，帮助管理员一眼看清 Claude Code 的价值，估算生产力提升、每次 commit 成本和年度价值。每个公式都在标签页中可见，输入也可调整。 

Analytics chat 现在能回答更广的问题，并产出可以继续深入的更丰富 artifacts。管理员可以用自然语言提问——“哪些团队这个月的 Claude 用量翻倍了？”或“我们在哪些席位上获得了最高的每席价值？”——Claude 会返回可以导出并分享给相关方的图表。

用量和成本数据可通过 Analytics API 以编程方式获取，因此财务和 IT 可以把 Claude 的用量与成本带进他们已经在用的工具——比如 Datadog Cloud Cost Management 和 CloudZero——并与其余云和 AI 支出放在一起看。结果可以按日期范围、团队、产品或模型过滤。Skills 会报告自己的用量和成本，新的端点还可追踪 plugin 采用情况和 artifact 创建。

管理员可以把用量可见性扩展到单个用户——成本、产品和模型拆分，以及相对支出上限的进度——这样就不会有人突然被切断。用户也可以看到自己随时间变化的用量趋势，包括最依赖哪些产品、模型和 skill，以及这些活动如何累积成支出。

管理支出的控制

模型默认值与权限让管理员可以设定 chat、Cowork 和 Claude Code 中新对话默认使用的 Claude 模型，这样日常工作不必默认落到最贵的选项。管理员可以控制哪些模型对特定角色或整个组织可用。 

支出阈值告警会在组织级支出上限达到 75% 和 90% 时通知管理员，让他们有时间在有人任务做到一半被拦住之前提高上限。用户会在 75% 和 95% 阈值收到应用内通知，并可以直接在 Claude 里向管理员申请提高限额，无需离开产品。 

对于要在许多组之间管理限额的组织，Admin API 把成本控制工作流放进脚本，让控制随组织规模扩展。自动化处理提额申请、识别接近支出上限的成员，以及大规模标记快速变化的用量。

开始使用

面向在组织内管理 Claude 的管理员：在管理控制台中查看用量和成本拆分，按组设置模型默认值和支出上限，并配置支出阈值告警，以免超额。用量数据可在管理仪表盘中查看，Analytics API 让财务和 IT 把同样的指标拉进现有报表系统，了解更多请见 这里。

AWS Trainium2 上的 Claude 3.5 Haiku 与 Amazon Bedrock 中的模型蒸馏

阅读英文原文 →

作为我们与 AWS 扩大合作的一部分，我们已开始优化 Claude 模型，使其运行在 AWS Trainium2——他们最先进的 AI 芯片上。

为了预览 Trainium2 的潜力，Claude 3.5 Haiku 现已在 Amazon Bedrock 中支持延迟优化推理，在保持精度的前提下让模型速度显著提升。

我们还在 Amazon Bedrock 中新增模型蒸馏（model distillation）支持，把更大 Claude 模型的智能带给速度更快、更具成本优势的模型。

Trainium2 上的新一代模型

我们正与 AWS 合作构建 Project Rainier——一个由 Trn2 UltraServer 组成的 EC2 UltraCluster 集群，包含数十万颗 Trainium2 芯片。该集群将提供超过当前一代领先 AI 模型训练所用算力（以 exaflops 计）五倍以上的计算能力。

Trainium2 让我们能够在 Amazon Bedrock 中提供更快的模型，首先是现已支持延迟优化推理公开预览的 Claude 3.5 Haiku。启用延迟优化后，Claude 3.5 Haiku 的推理速度最多可提升 60%——这使它成为从代码补全到实时内容审核和聊天机器人等各类用例的理想选择。

这一由 Trainium2 驱动的更快版本 Claude 3.5 Haiku，已在美国东部（俄亥俄）区域通过跨区域推理提供，定价为每百万输入 token $1、每百万输出 token $5。

Amazon Bedrock 模型蒸馏

我们还在帮助客户从 Claude 3 Haiku——上一代中最具成本效益的模型——获得前沿性能。通过蒸馏，Claude 3 Haiku 现在可以获得显著的性能提升，在特定任务上达到接近 Claude 3.5 Sonnet 的准确率——而价格和速度仍是我们最具成本效益模型的水平。

这项技术将知识从"教师"模型（Claude 3.5 Sonnet）迁移到"学生"模型（Claude 3 Haiku），让客户能够以极低的成本运行检索增强生成（RAG）和数据分析等复杂任务。

与需要开发者手工构造训练样本并不断调整参数的传统微调不同，Amazon Bedrock 模型蒸馏将整个流程自动化：

  1. 从 Claude 3.5 Sonnet 生成合成训练数据
  2. 训练并评估 Claude 3 Haiku
  3. 托管最终的蒸馏模型用于推理

Amazon Bedrock 模型蒸馏会自动应用不同的数据合成方法——从生成相似的提示词，到基于你提供的提示词-回答示例对创建新的高质量回答。

Amazon Bedrock 中面向 Claude 3 Haiku 的蒸馏现已开启预览。详情请参阅 AWS 的发布博客和文档。

Claude 3.5 Haiku 降价

除了在 Trainium2 上提供更快版本之外，客户仍可通过 Anthropic API、Amazon Bedrock 和 Google Cloud 的 Vertex AI 使用 Claude 3.5 Haiku。

为了让这一模型惠及更广泛的用例，我们将在所有平台上把 Claude 3.5 Haiku 的价格降至每百万输入 token $0.80、每百万输出 token $4。

开始使用

从今天起，模型蒸馏和更快的 Claude 3.5 Haiku 已在 Amazon Bedrock 中开启预览。对于追求价格、性能与速度最佳平衡的开发者，你现在有了更丰富的 Claude 模型选择：

  • 由 Trainium2 驱动、支持延迟优化的 Claude 3.5 Haiku，适合通用场景
  • 经蒸馏获得前沿性能的 Claude 3 Haiku，适合高流量、重复性场景

要开始使用，请访问 Amazon Bedrock 控制台。我们迫不及待想看到你将构建出什么。

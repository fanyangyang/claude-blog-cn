Claude for Enterprise

The Claude for Enterprise plan helps organizations drive cross-functional collaboration with AI at scale.

  • Category
    Product announcements
  • Product
    Claude Enterprise
  • Date
    September 10, 2024
  • Reading time
    5 min
  • Share

今天，我们发布 Claude Enterprise 计划，帮助组织安全地与 Claude 协作，并充分利用内部知识。

拥有更多上下文的团队能把工作做得更好。Claude Enterprise 计划提供扩展至 500K 的上下文窗口、更多的用量额度，以及原生 GitHub 集成，让你可以与 Claude 一同处理整个代码库。它还包含企业级安全功能——如 SSO、基于角色的权限和管理工具——帮助保护你的数据和团队。

借助 Claude，你组织的知识更易于共享和复用，让团队中的每个人都能快速、稳定地产出最佳成果。与此同时，你的数据也会得到保护：我们不会使用你的对话和内容来训练 Claude。要开始使用 Enterprise 计划，请联系我们的销售团队。

企业级管控

Enterprise 计划引入了关键的安全与管理控制手段，优先考虑管理和保护公司的敏感数据，包括：

  • 单点登录（SSO）与域名捕获（domain capture）：安全管理用户访问，集中管控账号配置权限。
  • 基于角色的访问控制与细粒度权限：为工作区指定唯一的主要所有者，增强安全性和信息管理。
  • 审计日志：追踪系统活动，用于安全与合规监控。审计日志将在未来几周内推出。
  • 跨域身份管理系统（SCIM）：自动化用户配置和访问控制。SCIM 也将在未来几周内推出。

企业级功能

通过将 Claude 与你组织的知识相结合，你可以把专业能力扩展到比以往更多的项目、决策和团队中。

借助 Enterprise 计划，你可以与 Claude 协作，并使用扩展的 500K 上下文窗口——相当于数百份销售访谈记录、数十份 100 页以上的文档，或中等规模的代码库。导入知识后，Claude 能够提供深入的、针对具体职能的指导。

我们还为工程团队推出了原生 GitHub 集成，可将 GitHub 仓库与 Claude 同步。现在，你可以在自己的代码库旁工作，迭代新功能、调试问题或帮助新工程师上手。GitHub 是我们正在构建的一系列原生集成中的第一个，旨在将 Claude 连接到你最重要的数据源，让 Claude 提供更相关、更有洞察力的帮助。该功能今天以测试版形式向早期 Enterprise 计划用户开放，我们计划在今年晚些时候扩大开放范围。

当扩展的上下文窗口与 Projects 和 Artifacts 结合使用时，Claude 就成为一套端到端解决方案，帮助你的团队将任何构想从想法推进到高质量的工作成果。例如，营销人员可以将市场趋势转化为引人注目的营销活动；产品经理可以上传产品规格说明，让 Claude 构建交互式原型；工程师可以接入代码库，获得错误排查和性能优化方面的帮助。

客户聚焦

GitLab 和 Midjourney 等早期客户已在各类任务和工作阶段使用 Claude for Work——从头脑风暴，到简化内部流程，再到创建和翻译内容、编写代码。Claude 与团队成员协作，产出富有意图的成果，激发创造力、提升生产力，并拓展可能的边界。

Claude 为我们的团队成员提供了一款仿佛是其工作和专业能力延伸的工具，让我们能够承担更复杂的任务、创造更大的影响力，同时确保 GitLab 的知识产权始终处于私密和受保护的状态。

—— Taylor McCaslin，GitLab AI 与机器学习技术产品负责人

Claude 一直是 Midjourney 不可思议的虚拟协作者。我们把 Claude 用于方方面面：从总结研究论文，到对用户反馈笔记进行问答，再到迭代我们的审核政策。我们很高兴在成长和探索新领域的过程中继续与 Claude 携手前行。

—— Caleb Kruse，Midjourney 总裁办公室主任（Chief of Staff）

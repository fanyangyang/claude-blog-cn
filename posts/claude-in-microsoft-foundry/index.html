Claude 在 Microsoft Foundry 上正式全面可用

阅读英文原文 →

从今天起，Claude 模型在 Microsoft Foundry 上正式全面可用，由 Azure 托管。Claude 运行在你的 Azure 环境中，沿用你的团队已在使用的身份验证、计费和治理控制。你可以选择推理的处理位置，包括面向有数据驻留需求的团队的美国数据区域。Anthropic 负责推理的运营，并担任数据处理者。

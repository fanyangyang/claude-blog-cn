Claude 在 Microsoft Foundry 上正式全面可用

Starting today, Claude models are generally available in Microsoft Foundry, hosted on Azure.

    Product announcements
  • Product
    Claude Platform
  • Date
    June 29, 2026
  • Reading time
    5 min
  • Share

从今天起，Claude 模型在 Microsoft Foundry 上正式全面可用，由 Azure 托管。Claude 运行在你的 Azure 环境中，沿用你的团队已在使用的身份验证、计费和治理控制。你可以选择推理的处理位置，包括面向有数据驻留需求的团队的美国数据区域。Anthropic 负责推理的运营，并担任数据处理者。

通过你的 Azure 账户使用 Claude 构建

目前，Claude Opus 4.8 和 Claude Haiku 4.5 已在 Messages API 中提供，并具备 prompt caching 和 extended thinking 等核心能力，覆盖从编程、agentic 工作到复杂推理的各类用例。我们会持续扩展 Foundry 上的可用能力。

Microsoft Foundry 上的 Claude 是 Azure 原生的，可与你现有的 Azure 身份、网络和治理控制协同工作。你会收到一张合并账单；对于符合条件、签有 Microsoft Enterprise Agreement 的客户，Claude 用量可以从 Microsoft Azure 承诺额度中抵扣。 

在 Azure 中运行 Claude，由 Anthropic 运营

在 Microsoft Foundry 中运行 Claude 有两种方式。当你需要在自己的 Azure 环境中运行时，选择 hosted on Azure ，即可使用 Azure 身份验证、计费、治理以及美国数据区域。当你需要完整的 API 功能集，或某个尚未在 Azure 上提供的模型时，选择 hosted on Anthropic（此前的 Foundry Preview）。长期来看，我们希望 hosted on Azure 与 Anthropic 托管方案在功能和模型上实现对齐。

开始使用

Claude in Microsoft Foundry 即日起全面可用。要开始使用，请打开 Claude in Microsoft Foundry，或查阅 文档。

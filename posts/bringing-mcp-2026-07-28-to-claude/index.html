将 MCP 2026-07-28 带入 Claude

The MCP 2026-07-28 spec is live, moving the Model Context Protocol to a stateless core with standardized extensions and hardened auth. Support is rolling out across Claude products soon. See what's new and how MCP is advancing in Claude.

Model Context Protocol 的第五个规范版本 MCP 2026-07-28，于今日正式发布。最新规范将 MCP 迁移到无状态核心，同时强化了授权机制，并正式转正了官方扩展。相关支持正在各 Claude 产品中陆续推出。

MCP 有哪些新内容‍

MCP 的月度 SDK 下载量近期突破 4 亿次，今年增长了 4 倍，已成为连接 AI 智能体与应用的行业标准。MCP 2026-07-28 是迄今为止最重要的规范版本之一：
无状态核心。MCP 从双向有状态协议转向请求/响应模型。服务器现在可以部署在 serverless 和边缘基础设施上。这简化了为 Claude 构建 MCP 服务器的体验，也便于在采用规模增长时进行扩展。 

标准化扩展。MCP Apps 和 Tasks 现在通过带版本管理的扩展框架发布，为开发者提供了一条正式途径来添加交互式 UI、长时间运行任务等能力，而无需改动核心协议。
授权强化。授权机制现在与生产环境的 OAuth 2.0 和 OIDC 部署保持一致，MCP 服务器可以无需变通方案即可接入 Entra 或 Okta 等企业身份系统。

‍在 Claude 中推进 MCP‍

Claude 现在在 connectors 目录中列出了超过 950 个 MCP 服务器，每天有数百万人使用。今年我们发布了对新协议扩展的支持，以及让 MCP 更易于构建和部署的功能：
MCP Apps 让服务器直接在对话中渲染交互式 UI。用户可以看到 connector 在做什么，并在对话内操作，无需切换标签页。
Enterprise-managed auth 让管理员通过身份提供商为整个组织开通 MCP connectors。管理员授权一次 connector，用户通过现有的 IdP 组继承访问权限，首次登录即完成连接：终端用户无需任何操作。

面向构建 connectors 的开发者的可观测性，为目录中已发布的 connectors 提供仪表盘，展示它们在各 Claude 产品表面上的表现。开发者可以用它跟踪采用情况、诊断错误和延迟，并按产品拆分用量。

MCP tunnels（研究预览） 把 Claude 连接到私有网络内的 MCP 服务器，而无需将它们暴露到公网。团队可以把内部工具带到 Claude，无需入站防火墙规则、无需公网端点、也无需在源站做 IP 白名单。
2026-07-28 中的无状态核心、标准化扩展和强化授权，将帮助开发者把更多应用带到 Claude，并带来更低摩擦、更一致的终端用户体验。我们将继续与社区一起投资 MCP 这一开放标准，也投资那些让 MCP 在生产环境中更易用、更有效的 Claude 功能。

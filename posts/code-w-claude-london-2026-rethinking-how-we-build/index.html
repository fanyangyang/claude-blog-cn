本周，我们在伦敦将 Code w/ Claude 带到了欧洲。这场活动汇聚了构建者、开发者和创始人，与打造 Claude 的团队一起，进行了为期两天的主题演讲、分论坛和 workshop。

Claude Code 负责人 Boris Cherny 在主题演讲的开头，讲述了他第一次感受到编程“魔力”的时刻。中学时，他编写 TI-83 计算器程序来解数学作业和考试题，还自学 HTML 来让自己的宝可梦卡牌 eBay 商品页面卖得更好。他通过动手折腾来学习，每当程序跑起来，那种感觉都令人兴奋。

他谈到，在之后的某个阶段，编程变得复杂了。编译器、类型检查器、构建系统——每一层都让“我有一个想法”和“它跑起来了”之间的距离又远了一点。而有了 agent，这段距离正在重新缩短：你描述一个问题，程序就出现了。这就像当年用计算器的感觉，只不过这台“计算器”能写出一个分布式系统。

从展示如何用 Claude Code 超越基础用法的 workshop，到如何在我们各模型之间优化思考预算和 effort 级别，我们展示了 Anthropic 以及 Spotify、Base44、Legora 等客户，如何已经在重新找回这种体验。  

发布了什么

在本次大会上我们宣布：Claude Managed Agents 现在可以在你自主控制的沙箱中运行，并连接你的私有 Model Context Protocol（MCP）服务器。如此一来，agent 执行工具的环境及其能访问的服务，都在你企业既定的边界之内运行。这两项新能力现已在 Claude Platform 上提供：

  • 自托管沙箱（公开测试版）。工具执行转移到你自行配置的环境中——你自己的基础设施，或 Cloudflare、Daytona、Modal、Vercel 等托管服务商——而负责编排、上下文管理和错误恢复的 agent 循环仍在 Anthropic 的基础设施上运行。你的网络策略、审计日志和安全工具照常生效，文件和代码仓库不会离开你的边界，你还可以为计算密集型工作自行决定计算规格和运行时镜像。
  • MCP 隧道（research preview）。你的 agent 可以访问私有网络内的 MCP 服务器，而无需将其暴露到公网。你只需部署一个轻量级网关，建立一条出站连接：无需入站防火墙规则，没有公网端点，流量端到端加密。MCP 隧道在 Managed Agents 和 Messages API 中均受支持，由组织管理员在 Claude Console 中统一管理。

包括 Amplitude、Clay 和 Rogo 在内的团队已经在基于自托管沙箱的 Managed Agents 上进行构建。想上手的话，可以查阅文档，跟随我们的 cookbook，或申请 MCP 隧道的访问权限。

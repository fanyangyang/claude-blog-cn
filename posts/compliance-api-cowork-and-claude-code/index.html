Compliance API 覆盖范围扩展至 Claude Cowork 和 Claude Code

阅读英文原文 →

更新：合规 API（Compliance API）对 Cowork（桌面端、网页端和移动端）以及 Claude Code（CLI 和桌面端）的覆盖现已正式发布；Microsoft 365 加载项（Excel、Word、PowerPoint 和 Outlook）以及 Claude Science 的覆盖处于测试阶段（2026 年 8 月 26 日）

Claude 的合规 API 现已覆盖桌面应用、网页端和移动端的 Cowork，以及 CLI 和桌面应用中的 Claude Code。该覆盖功能目前以测试版形式向 Claude Enterprise 客户提供。合规与安全团队可以通过他们已经在用于 Claude 聊天的同一套合规 API 接口，从这两个产品中提取会话内容和元数据。

新的端点是增量式的：你现在从合规 API 提取的数据不会有任何变化。

安全与合规团队依赖合规 API 来了解 Claude 在整个组织中的使用情况——用于审计和电子取证（eDiscovery）——而无需为每个产品界面单独部署日志基础设施。将覆盖范围扩展到 Cowork 和 Claude Code 弥补了一块空白：这些会话现在会与 Claude 聊天记录一同呈现。 

工作原理

新的会话端点会为每个 Cowork 和 Claude Code 会话返回一份整合的、由服务器托管的完整记录，因此提示词、响应和工具活动都会归集在同一条会话记录中。

每条会话记录包含两类数据：

  • 会话内容：提示词与响应、工具调用内容（网页和 MCP），以及以记录文本形式捕获的 Skills 和 Artifacts 内容。
  • 会话元数据：经核实的用户 ID 和电子邮箱地址、组织 ID、会话 ID 和逐条消息 ID，以及时间戳。

本次测试版不包含网页版 Claude Code、通过 Claude Platform 使用的 Claude Code，以及在 Amazon Bedrock、Google Cloud 的 Vertex AI 或 Microsoft Foundry 上运行的会话。

已经在导出 OpenTelemetry 数据的组织可以继续沿用：合规 API 可以与之并行工作，你这边无需任何额外基础设施。

开始使用

Cowork 和 Claude Code 的覆盖功能现已上线，并包含在合规 API 中，使用你现有的合规访问密钥（Compliance Access Key）即可——无需构建单独的集成。如果你的组织已经启用了该功能，可直接查询新的会话端点。如果尚未启用，请查阅合规 API 文档以完成启用。

Product announcements December 18, 2025

面向组织、合作伙伴与生态的 Skills

阅读英文原文 →

今年十月，我们发布了Skills——一种让 Claude 学会可复用工作流、并贴合你工作方式的方法。今天，我们让 Skills 更容易部署、发现和构建：面向管理员的组织级管理能力；一个汇集了来自 Notion、Canva、Figma、Atlassian 等合作伙伴所构建 Skills 的目录；以及一个让 Skills 可以跨 AI 平台运行的开放标准。

在整个组织内管理 Skills

Claude Team 和 Enterprise 计划的管理员现在可以在管理设置中集中配置 Skills。由管理员配置的 Skills 默认对所有用户启用。用户仍然可以按需自行关闭单个 Skill。这让组织能够在各团队间保持一致、经过审批的工作流，同时允许个人用户自定义自己的体验。

发现、创建和编辑新 Skills

创建 Skills 现在更简单了。描述你的需求，Claude 会帮你搭建；你也可以直接编写指令。对于复杂的工作流，可以上传 Skill 文件夹或使用 skill-creator。Claude 还可以帮你编辑已有的 Skills，新的预览功能会展示完整内容，让你在启用之前就能准确了解一个 Skill 的作用。

Skills 目录

一个不断扩充的合作伙伴 Skills 合集现已上线 claude.com/connectors。

管理员可以在整个组织内配置这些合作伙伴 Skills，让团队即刻获得适用于他们已在使用的工具的工作流，无需任何定制开发。

Claude in Chrome 侧边栏现已升级为 Claude Cowork

阅读英文原文 →

Claude in Chrome 侧边栏现在就是一个 Claude Cowork 会话。对话会保存到你的历史记录中，你的 Skills 和连接器（connectors）都可以在浏览器中使用，在某个标签页里开始的任务可以继续在 Claude 桌面端、网页端和移动端应用中完成。该功能目前已在 Max 和 Team 计划中可用，并将在未来几周内逐步推送至 Pro 用户。 

Claude in Chrome 是一款浏览器扩展，它让 Claude 能够看到你当前所在的页面并在页面中执行操作，包括点击链接、输入文字、在页面之间导航和填写表单，且使用你已有的登录状态。

你日常使用的许多工具都可以直接连接到 Claude，但另一些则不行，例如内部仪表盘、遗留系统和供应商门户。借助 Claude in Chrome，Claude 可以通过浏览器在这些应用中工作。  

在此之前，侧边栏中的会话与 Claude 应用中的会话是相互独立的，上下文和对话无法在两者之间延续。现在，侧边栏运行的就是你在桌面端、网页端和移动端使用的同一个 Claude Cowork 会话，适合更长、多步骤的工作。由于会话归属于你的账户而非某台设备，你可以在浏览器中开始工作，稍后在别处继续。

举个例子，假设你正在编制一份预算电子表格，需要从多个供应商门户拉取发票。现在，你可以让 Claude in Chrome 去收集金额和日期，它会打开各个标签页、读取每张发票并生成电子表格。然后，你可以在桌面应用中继续这个会话，添加电脑上的文件，或导入上个月的预算并询问有哪些变化，让你在工作时跨设备保持上下文。  

了解风险 

Claude in Chrome 与任何在浏览器中行动的 AI 智能体一样存在风险，主要是提示词注入（prompt injection）。恶意行为者会把指令隐藏在网络内容中，比如网页、邮件或文档。这些指令可能对你不可见，但它们可能会诱导 Claude 执行你从未打算进行的操作。 

自试点以来，我们为 Claude 自身的行动增加了检查机制。使用“自动批准”（automatically approve），Claude 就可以在执行任务时不必在每一步都停下来请求权限。但在执行任何有实质后果的操作之前——比如提交表单、发送消息或下载文件——都会有一个独立的检查将该操作与你最初的要求进行比对，并拦截任何不相符的操作。这在保持监督的同时减少了打断。  

对于某些不可逆或代价高昂的操作，比如购物或分享个人数据，Claude 仍然会先征询你的意见。虽然这些措施能显著降低风险，但无法完全消除。提示词注入是一个不断演变的目标，因此我们持续搜寻新的攻击手法，并将所学融入我们发布的每一个模型。我们建议先从你信任的网站开始使用，我们的安全指南中有更多最佳实践。 

开始使用

要开始使用 Claude in Chrome，请从 Chrome Web Store 安装它，登录并打开侧边栏。全新侧边栏目前已在 Max 和 Team 计划中可用，并将在未来几周内逐步推送至 Pro 用户。在 Enterprise 计划中，Claude in Chrome 默认关闭。管理员可以将其开启，并限制仅用于经批准的域名。请参阅管理员设置指南。

处理电脑上的文件或使用其他应用时，你仍需使用 Claude 桌面应用。Claude in Chrome 目前尚不能在其他 Chromium 内核浏览器或移动端上运行。

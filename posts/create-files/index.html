Claude 现在可以创建和编辑文件

阅读英文原文 →

更新： 现已面向付费计划正式发布，并支持网络与出口流量管控（2025 年 10 月 21 日）。

Claude 现在可以在 Claude.ai 和桌面应用中直接创建和编辑 Excel 电子表格、文档、PowerPoint 幻灯片和 PDF。这改变了你与 Claude 协作的方式——不再只能收到文字回复或应用内 Artifacts，你可以描述自己的需求、上传相关数据，然后拿到可直接使用的文件。

文件创建功能目前作为预览版向 Max、Team 和 Enterprise 计划用户开放。Pro 用户将在未来几周内获得访问权限。

你能做什么

Claude 会根据你的指示创建真实的文件——无论是基于上传的数据、通过研究获取信息，还是从零开始构建。以下是几个例子：

  • 把数据变成洞见：给 Claude 原始数据，拿回包含清洗后数据、统计分析、图表以及文字洞见的精美成果，并解释哪些内容重要。
  • 构建电子表格：描述你的需求——带情景分析的财务模型、带自动仪表盘的项目跟踪表，或带差异计算的预算模板。Claude 会用可用的公式和多个工作表把它做出来。
  • 跨格式处理：上传一份 PDF 报告，得到 PowerPoint 幻灯片；分享会议纪要，得到排版好的文档；上传发票，得到带计算功能的规整电子表格。Claude 承担繁琐工作，并按你需要的样式呈现信息。

‍

无论你需要客户细分分析、销售预测还是预算跟踪，Claude 都能搞定技术活，交出你需要的文件。文件创建功能把过去需要编程技能、统计知识和数小时投入的项目，变成几分钟的对话。

工作原理：Claude 的计算机

过去一年里，我们看到 Claude 从回答问题进化到完成整个项目，现在我们正让这种能力触手可及。我们为 Claude 提供了一个私有的计算机环境，它可以在其中编写代码、运行程序，产出你需要的文件和分析。

这让 Claude 从一个顾问转变为主动的协作者。你提供背景和策略；Claude 在幕后完成技术实现。这昭示了我们的方向：让复杂的多步骤工作可以通过对话完成。随着这些能力的扩展，从想法到落地之间的鸿沟将持续缩小。

开始使用

要开始创建文件：

  1. 在 Settings > Features > Experimental 下开启 "Upgraded file creation and analysis"
  2. 上传相关文件或描述你的需求
  3. 通过聊天引导 Claude 完成工作
  4. 下载完成的文件，或直接保存到 Google Drive

可以先从数据清洗或简单报告这类直白的任务入手，等你熟悉了 Claude 处理文件的方式，再逐步过渡到财务模型等复杂项目。

此功能让 Claude 可以访问互联网来创建和分析文件，这可能带来数据风险。使用此功能时请密切关注对话内容。了解更多。

推出 Claude Platform on AWS

阅读英文原文 →

Claude Platform on AWS 现已正式发布（GA），为 AWS 客户提供了一种全新的方式：通过 AWS 的身份验证、计费和承诺额度抵扣，使用 Claude Platform 的完整功能。Claude 仍然可以通过 Amazon Bedrock 使用，在 Bedrock 上 AWS 扮演数据处理者的角色。

从今天起，Claude Platform on AWS 的客户可以通过 Claude Managed Agents 大规模部署智能体，并使用代码执行、Skills、advisor 策略等工具进行构建。

通过 AWS 访问完整的 Claude Platform

Claude Platform on AWS 首次将 Claude API 的全部功能带给 AWS 客户，所有新功能和 beta 版本都会在原生 Claude API 上线的当天同步提供。 

身份验证通过 AWS IAM 完成，审计日志通过 CloudTrail 记录，计费则并入一张 AWS 账单，并可直接抵扣已有的承诺额度。客户可以使用现有的 AWS 凭证和 IAM 策略，团队无需离开他们已在管理和使用的工具与权限体系。

Claude Platform on AWS 将覆盖大多数 AWS 商业区域，并支持全球及美国境内的推理地域选择。

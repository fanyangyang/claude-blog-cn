推出 Claude Platform on AWS

The Claude Platform on AWS is now generally available, offering a new way for AWS customers to access the full set of Claude platform features with AWS authentication, billing, and commitment retirement.

Claude Platform on AWS 现已正式全面可用，为 AWS 客户提供一种新的方式，以 AWS 身份验证、计费和承诺额度抵扣来访问完整的 Claude Platform 功能。Claude 也继续可在 Amazon Bedrock 上使用，此时 AWS 是数据处理者。

从今天起，Claude Platform on AWS 的客户可以用 Claude Managed Agents 大规模部署 agent，并用 code execution、skills、顾问策略等工具进行构建。

通过 AWS 访问完整的 Claude Platform

Claude Platform on AWS 首次把完整的 Claude API 功能集带给 AWS 客户，所有新功能和 beta 都会在原生 Claude API 上线当天同步提供。 

身份验证走 AWS IAM，审计日志走 CloudTrail，计费走一张可完全抵扣现有承诺额度的 AWS 账单。客户使用已有的 AWS 凭证和 IAM 策略，因此团队继续待在他们已经在管理的工具和权限之内。

Claude Platform on AWS 将在大多数 AWS 商业区域提供，并支持全球和美国推理地理范围。

包含哪些能力

Claude Platform on AWS 包含原生平台功能，例如：

  • Claude Managed Agents (beta) ，用于大规模构建和部署 agent
  • Advisor strategy (beta) ，通过向顾问模型求教为 agent 提供智能提升
  • Web search 和 web fetch，用全网最新的真实世界数据增强 Claude 的知识
  • Code execution，在 API 调用内直接运行 Python 代码、创建可视化和分析数据
  • Files API (beta)，用于跨对话上传和引用文档
  • Skills (beta)，把最佳实践教给 Claude，让结果保持一致
  • MCP connector (beta)，无需编写客户端代码即可把 Claude 连接到任意远程 MCP server
  • Prompt caching，降低重复上下文的成本和延迟
  • Citations，让回答锚定到来源文档
  • Batch processing，面向高并发、异步工作负载

Claude Platform on AWS 的客户还可以使用 Claude Console，这是 Anthropic 用于构建和测试 Claude 的开发环境。Console 包含对 agent、skills、environments、vaults、可观测工具等的管理。

Claude Opus 4.7、Sonnet 4.6 和 Haiku 4.5 现已可用，新模型发布时也会同步登陆 Claude Platform on AWS。

为开发者选择合适的路径

Claude Platform on AWS 和 Claude on Amazon Bedrock 都能让 AWS 客户基于 Claude 模型构建。区别在于谁运营服务，以及有哪些功能可用。

Claude Platform on AWS 是 Anthropic 的首创产品，从第一天起就提供全部原生 Claude API 功能。Anthropic 运营该服务，数据在 AWS 边界之外处理。适合希望获得完整 Claude Platform 体验的公司。

Claude on Amazon Bedrock 让 AWS 担任数据处理者，并在 AWS 边界内运营。适合有严格区域数据驻留要求，或需要数据仅在 AWS 基础设施内处理的公司。

开始使用

Claude Platform on AWS 即日起可用。要开始使用，请访问 Claude Platform on AWS，或查阅 文档。

如果你已有 Bedrock private offer，请在开始使用 Claude Platform on AWS 之前联系你的 Anthropic 或 AWS 客户经理，以确保折扣正确生效。折扣无法追溯应用到接受 Claude Platform private offer 之前产生的用量。

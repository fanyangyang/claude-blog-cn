在你自己的算力上运行 Claude Code 会话

阅读英文原文 →

自托管环境现已进入公开测试阶段，它让你可以在自己的基础设施上运行 Claude Code 会话。你可以从网页端、移动端、桌面端或例行任务（Routines）发起一个会话，它会在你的网络内部、紧邻你的内部服务、工具链和安全管控措施运行，而不是在 Anthropic 托管的基础设施上。

对于大多数企业，我们强烈推荐我们的托管方案，因为它在运维上更简单，无需运行或维护任何基础设施。自托管环境适用于那些因网络、工具或合规要求而需要将智能体执行保留在自己可控基础设施上的团队。如果你选择这条路，请计划配置工程人员来负责环境搭建和持续维护。

为什么要自托管

在预览计划中，我们看到组织采用自托管环境有以下几个关键原因：

  • 网络访问：会话在你的网络内部运行，可以直接访问内部服务、数据库和制品仓库，而无需将它们暴露到公共互联网
  • 可定制性：在环境中预装编译器、SDK 和内部 CLI，让每个会话一开始就具备开箱即用的构建能力
  • 合规性：源代码和构建产物始终保留在你可控的基础设施上

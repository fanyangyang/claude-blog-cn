Claude Managed Agents 的内置记忆

阅读英文原文 →

Claude Managed Agents 的记忆功能今天起进入公开测试阶段。你的智能体现在可以从每一次会话中学习，它使用一个针对智能优化过的记忆层，在性能与灵活性之间取得平衡。由于记忆以文件形式存储，开发者可以导出它们、通过 API 管理它们，并完全掌控智能体保留哪些内容。

Claude Managed Agents 中的记忆如何运作

Claude Managed Agents 的记忆是一个内置的、针对智能优化过的记忆层，让智能体能够从每次会话中学习。这一记忆功能针对内部基准测试进行了优化，使长期运行的智能体能够跨会话持续改进，并彼此共享学到的东西。

我们发现，当记忆建立在智能体已有的工具之上时，效果最好。Claude Managed Agents 的记忆直接挂载到文件系统上，因此 Claude 可以依赖让它在智能体任务中表现出色的同款 bash 和代码执行能力。借助基于文件系统的记忆，我们最新的模型能保存更全面、组织更有序的记忆，并且更善于判断针对特定任务该记住什么。

面向生产级智能体的可迁移记忆 

记忆功能专为企业级部署而设计，具备细粒度权限、审计日志和完全的程序化控制。记忆存储可以由多个智能体共享，并各配不同的访问范围。例如，组织级存储可以是只读的，而每个用户的存储则允许读写。多个智能体可以并发访问同一个存储而不会相互覆盖。

记忆本质上是文件，可以导出并通过 API 独立管理，开发者因此拥有完全的控制权。所有变更都会记录在详细的审计日志中，你可以追溯某条记忆来自哪个智能体和哪次会话。你可以回滚到早期版本，或从历史记录中抹除某些内容。更新还会以会话事件的形式呈现在 Claude Console 中，开发者可以据此追踪智能体学到了什么、来自何处。

各团队正在构建什么

各团队已经在用记忆功能闭合反馈回路、加速验证，并替代自建的检索基础设施：

  • Netflix 的智能体可以跨会话携带上下文，包括那些经过多轮对话才挖掘出的洞见，以及对话中途来自人工的纠正，而无需手动更新提示词和 Skills。
  • Rakuten 的任务型长期运行智能体利用记忆从每次会话中学习、避免重蹈覆辙，将首轮错误率降低了 97%，且全程处于工作区范围内、可观测的边界之内。
  • Wisedocs 在 Managed Agents 之上构建了文档验证流水线，利用跨会话记忆发现并记住反复出现的文档问题，将验证速度提升了 30%。‍
  • Ando 正在基于 Managed Agents 构建其职场消息平台，记录每个组织的交互方式，而无需自行搭建记忆基础设施。

在开发者控制台中生成更好的提示词

阅读英文原文 →

你现在可以在 Anthropic Console 中生成可直接用于生产环境的提示词模板。只需描述你想实现的目标，Claude 就会运用思维链推理等提示词工程技术，创建一个有效、精确且可靠的提示词。

该功能既为提示词工程的新手而设计，也能为经验丰富的提示词工程师节省时间。如果你能为提示词生成器提供关于任务和期望输出格式的详细信息，将会获得最佳效果。

尽管生成的提示词并不总能产出完美的结果，但它们往往优于提示词工程新手手写的提示词。生成的提示词模板还可以编辑，你可以快速调整它们以获得最佳性能。

提示词最佳实践

这项新功能生成的提示词模板运用了我们的许多提示词工程最佳实践。其中之一是角色设定（role setting），即引导 Claude 扮演所选任务领域专家的角色。在我们的内容审核示例中，角色设定如下：

You will be acting as a content moderator to classify chat transcripts as either approved or rejected based on a provided content moderation policy.

另一项实践是思维链（chain of thought）推理，即给 Claude 时间和空间，让它在回答之前先整理思路。这能让它对复杂问题给出更全面、更有理有据的回答。当我们要求它根据客户的历史交易生成一个产品推荐提示词时，具体实现如下：

In a <scratchpad>, brainstorm 3 different product recommendations you could make to this customer based on their transaction history. For each potential recommendation, provide a brief rationale explaining why you think it would be a good fit for this customer.

此外，模板通常会把"变量"——即可插入自定义数据的输入字段——放在 XML 标签之间。这遵循了另一项关键最佳实践：通过清晰的结构来明确划分提示词的不同部分。当我们要求生成一个将代码翻译为 Python 的提示词时，可以看到较长且含义较模糊的 {{CODE}} 变量由 XML 标签标记，而简单的 {{LANGUAGE}} 变量则以行内形式嵌入。

Your task is to translate a piece of code from another programming language into Python.

Here is the code to translate:

<code>
{{CODE}}
</code>

The code is written in {{LANGUAGE}}.

在某些情况下，你会看到 Claude 编写示例输入和输出，为它自己明确方向，说明它认为你想要的答案类型。你可以编辑这些示例，使其符合你期望的输出格式。

幕后原理

提示词生成器基于一个很长的提示词，而这个提示词本身也运用了前面提到的许多技术。

  • 它包含大量任务描述和提示词模板的示例，向 Claude 展示如何从任务描述得到提示词模板。
  • 它鼓励 Claude 在编写模板之前先规划好将要生成的模板结构，给 Claude 时间整理思路。
  • 它有一条由 XML 标签构成的坚实"骨架"，标记每个部分的开始和结束，以增强可读性。

将提示词模板用作评估工具

你从提示词生成器得到的模板中，变量将采用 handlebars 表示法，正如前面内容审核示例所示：

Unknown block type "codeBlock", specify a component for it in the `components.types` option

在这个示例中，你可以随后上传你的内容策略和各种不同的聊天记录，观察 Claude 的表现。这一过程让你能够确保应用在各种情况下都能做出恰当响应。

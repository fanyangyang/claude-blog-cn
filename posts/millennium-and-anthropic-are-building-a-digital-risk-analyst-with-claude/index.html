Millennium 与 Anthropic 正在用 Claude 打造数字化风险分析师

阅读英文原文 →

Anthropic 正在与全球最大的另类投资管理公司之一 Millennium 合作，共同打造一位数字风险分析师：一个与该公司的风险经理并肩工作、并接受其监督的 AI 队友，用于发掘新的风险洞察，并就跨资产类别的风险敞口形成判断。

如今，Claude 和 Claude Code 已在 Millennium 得到广泛使用——从交易部门和工程团队到核心业务职能。Millennium 的数字风险分析师进一步拓展了他们对 Claude 的应用，帮助风险经理加速并深化对风险头寸的分析。

用 Claude 评估金融风险 

数十年来，投资公司一直在利用技术改进风险计量，从传统评估逐步走向更复杂的实时情景分析。Millennium 的数字风险分析师旨在攻克关键工作流，其动力来自 Millennium 的专有数据与 Claude 的前沿智能。 

这位数字风险分析师能够长期保留和调取信息，并运用新的推理能力来帮助解释每日的风险变化。随后，这些分析结果会由 Millennium 的人类风险经理进行验证和深化。 

“在 Millennium，我们相信 AI 能够为我们员工的成就设定一个新的标杆，”Millennium 首席信息官 Vlad Torgovnik 表示。“我们与 Anthropic 的合作正是这样一个范例，它展示了 AI 如何在业务的核心领域推动创新，同时让人类判断始终居于决策的中心。我们很高兴能与一家行业领导者继续合作，探索 AI 为我们的业务创造价值的新方式。”   

Millennium 员工如何使用 Claude

Millennium 是 Claude 和 Claude Code 的早期采用者。员工使用 Claude Code 编写软件、构建产品和改进工作流，覆盖 Millennium 340 多个投资团队中的许多团队。

这位数字风险分析师通过记录自身推理过程、在沙箱环境中测试其行动，并要求人类专家评估和批准其决策，从而提供安全、可审计的分析。Millennium 的风险专家正在与 Anthropic 的研究团队和应用 AI 团队并肩工作，在 Millennium 的 AI 实验室中共同构建它。 

Millennium 正在利用其内部 AI 实验室继续推进前沿探索，用雄心勃勃的使用场景对 Anthropic 最新的 Claude 模型进行压力测试，并让 Claude 在快节奏的环境中开展创新。 

“金融服务行业需要的是人们能够在复杂、严苛的环境中信赖的 AI，”Anthropic 金融服务董事总经理 Belinda Neal 表示。“Millennium 一直是 Claude 和 Claude Code 的早期采用者，我们与其风险团队的合作将展示 AI 如何为 Millennium 风险经理每天所做的分析提供参考。”

“Claude 能够对风险头寸进行推理、解释每日变化，并将所学带入下一个问题，”Anthropic 资产与财富管理负责人 Peter Nolan 表示。“Millennium 的风险经理将借助前沿智能产出自动化建议，目标是节省宝贵的时间。”

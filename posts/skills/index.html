Agent Skills 介绍

Claude can now use Skills to improve how it performs specific tasks. Skills are folders that include instructions, scripts, and resources that Claude can load when needed. Claude will only access a skill when it's relevant to the task at hand.

更新：我们已增加 面向 skills 的全组织管理、一个展示合作伙伴构建 skills 的 目录，并将 Agent Skills 作为开放标准发布，以实现跨平台移植。（2025 年 12 月 18 日）

Claude 现在可以使用 Skills 来改进它执行特定任务的方式。Skills 是包含指令、脚本和资源的文件夹，Claude 会在需要时加载它们。

Claude 只会在某个 skill 与手头任务相关时访问它。使用时，skills 能让 Claude 更擅长专门任务，比如处理 Excel，或遵循你组织的品牌规范。

你已经在 Claude apps 里见过 Skills 的作用，Claude 用它们创建电子表格和演示文稿等文件。现在，你可以构建自己的 skills，并在 Claude apps、Claude Code 和我们的 API 中使用它们。

Skills 如何工作

在处理任务时，Claude 会扫描可用的 skills，寻找相关匹配。一旦匹配，它只加载所需的最少信息和文件——让 Claude 保持快速，同时获得专门专长。

Skills 具有以下特点：

  • 可组合：Skills 可以叠加使用。Claude 会自动识别需要哪些 skills，并协调它们的使用。
  • 可移植：Skills 在各处使用相同格式。构建一次，即可在 Claude apps、Claude Code 和 API 中使用。
  • 高效：只在需要时加载需要的内容。
  • 强大：Skills 可以包含可执行代码，用于传统编程比生成 token 更可靠的任务。

可以把 Skills 想成定制的入职材料，让你把专长打包起来，使 Claude 成为对你最重要事项的专家。关于 Agent Skills 设计模式、架构和开发最佳实践的技术深入解读，请阅读我们的 engineering blog.

Skills 适用于每一款 Claude 产品

Claude apps

Skills 向 Pro、Max、Team 和 Enterprise 用户开放。我们提供文档创建等常见任务的 skills、可供定制的示例，以及创建你自己的自定义 skills 的能力。

Claude 会根据你的任务自动调用相关 skills——无需手动选择。你甚至会在 Claude 工作时的思维链中看到 skills。
创建 skills 很简单。“skill-creator” skill 提供交互式引导：Claude 询问你的工作流，生成文件夹结构，格式化 SKILL.md 文件，并打包你需要的资源。无需手动编辑文件。

在 Settings 中启用 Skills。对于 Team 和 Enterprise 用户，管理员必须先在全组织启用 Skills。

Claude Developer Platform (API)

我们常简称为 Skills 的 Agent Skills，现在可以加入 Messages API 请求；新的 /v1/skills 端点让开发者能以编程方式控制自定义 skill 的版本管理和维护。Skills 需要 Code Execution Tool beta，它提供 skills 运行所需的安全环境。

使用 Anthropic 创建的 skills，可以让 Claude 读取并生成带公式的专业 Excel 电子表格、PowerPoint 演示文稿、Word 文档和可填写 PDF。开发者也可以创建自定义 Skills，按自己的用例扩展 Claude 的能力。

开发者还可以在 Claude Console 中轻松创建、查看和升级 skill 版本。

了解更多请查阅 文档、我们的 skills cookbook，或 Anthropic Academy。

‍

Claude Code

Skills 用你团队的专长和工作流扩展 Claude Code。通过 anthropics/skills marketplace 的 plugins 安装 skills。Claude 会在相关时自动加载它们。通过版本控制与团队共享 skills。你也可以把 skills 加到 ~/.claude/skills 来手动安装。Claude Agent SDK 为构建自定义 agent 提供同样的 Agent Skills 支持。

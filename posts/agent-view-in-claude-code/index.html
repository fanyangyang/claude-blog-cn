Claude Code 中的 Agent View（智能体视图）

阅读英文原文 →

今天我们推出 Claude Code 中的 agent view（智能体视图）：一个统一管理所有 Claude Code 会话的地方。 

以前并行运行多个智能体时，你可能要同时打理多个终端标签页、一个 tmux 网格，还要在脑子里记着一长串接下来要处理的事项。

有了 Claude Code 的 agent view，你可以启动新的智能体、把它们转入后台，只在 Claude 需要你时才介入。一眼就能看到哪些智能体在等你回复、哪些还在工作、哪些已经完成，从而轻松地同时调度多个智能体。

工作原理

Agent view 改进了在 CLI 中可视化查看和操作 Claude Code 会话的体验。

一览全局

在任意会话中按左方向键，或在终端中运行 claude agents，即可打开 agent view。每一行都会显示该会话、它是否需要你的输入、最近一次回复的内容，以及你上次与它交互的时间。

不离开界面即可查看和回复

选中一个会话即可预览最近一轮对话。如果某个会话正在等待决策，你可以就地作答，会话随即继续运行。按回车键可以直接附到某个会话上，查看完整的对话记录。

一切皆可转入后台

最后，你可以用 /bg 把任意现有会话加入 agent view，或者用 claude --bg [task] 直接在后台启动一个全新会话，完全跳过前台。

开发者如何使用 agent view

我们从早期用户那里观察到几种典型用法：

  • 扩展并发会话数量：同时派发多个想法，每个都可以搭配一个 skill，回来时看到的就是一列待审阅的 pull request。
  • 管理长时间运行的智能体：PR 看护、仪表盘更新等循环任务会直接在列表中显示下一次运行时间。
  • 在不同会话之间穿梭：当你在某个会话中途，按左方向键，发起一个相关任务或快速查询一下代码库，再按右方向键回到原来的工作。答案出来时，预览界面会直接显示。
  • 查看成果：每行的状态指示加上预览中的标题，让你一眼扫出哪些会话产出了 PR。

开始使用

Agent view 现以 Research Preview 形式在 Pro、Max、Team、Enterprise 和 Claude API 计划中提供。运行 claude agents 即可选择启用。常规速率限制适用。更多信息请参阅文档。

Claude for Excel 与 PowerPoint 能力再升级

阅读英文原文 →

更新：Claude for Word beta 现已面向 Team 和 Enterprise 计划开放。（2026 年 4 月 10 日）

从今天起，Claude for Excel 和 Claude for PowerPoint 将在所有打开的文件之间共享完整的对话上下文，因此 Claude 在其中一个应用中执行的每个操作，都会参考另一个应用中正在发生的一切。

Skills 现在也可在 Excel 和 PowerPoint 加载项中使用，同时 Claude for Excel 和 PowerPoint 已可通过三大主流云平台使用：Amazon Bedrock、Google Cloud 的 Vertex AI 以及 Microsoft Foundry。

这些更新让 Claude 能够在任务、电子表格和幻灯片之间自由流转，让你以更高的效率和质量工作，而不必在每一步都重新解释。

在 Excel 和 PowerPoint 之间共享同一段对话

Claude 可以在一段连续的对话中跨多个 Excel 和 PowerPoint 文件传递上下文——读取单元格数值、编写公式、合并数据集、编辑幻灯片，并把用户的对话内容贯穿于所有打开的 Excel 和 PowerPoint 文件中。

一位金融分析师可以从打开的工作簿和其他数据源中提取可比公司的财务数据，接着在 Excel 中搭建一张交易可比公司（trading comps）表格，把估值摘要放进路演材料，再起草一封发给董事总经理（MD）的邮件——无需切换标签页，也无需在每一步重新解释数据集。减少工具之间的来回切换，正是更快产出最终交付物的关键。

用 skills 把最佳实践变成一键操作

Skills 可以把完整的工作流变成一键操作。当团队里有人摸索出了做差异分析（variance analysis）的正确方法，或者用公司模板撰写客户演示文稿的流程，把它保存为 skill 之后，这套流程在今后即可即刻复用。

我们预置了一套入门 skills，覆盖最常见的 Excel 和 PowerPoint 使用场景。在 Excel 方面，入门 skills 覆盖金融分析中最常出现的工作流：

  • 审计模型，检查公式错误和资产负债表的完整性
  • 构建并填充 LBO、DCF 和三表联动模型模板
  • 运行可比公司分析
  • 清理杂乱的电子表格数据——某个区域、当前工作表或整个文件

在 PowerPoint 方面，入门 skills 覆盖分析完成之后的呈现层工作：

  • 构建竞争格局演示文稿，包括市场定位和同行深度剖析
  • 用新信息或额外数据更新现有演示文稿
  • 审查投行演示文稿的数字一致性、数据与叙事的契合度，以及语言的润色

任何已通过桌面端或网页版 Claude 配置好的 skill——无论个人还是组织范围——都可以在加载项中开箱即用，就像 MCP 连接器一样。Excel 和 PowerPoint 的入门 skills 也可以通过 Financial Analysis 插件获取，该插件会在两个加载项中自动安装。插件中新增的 skills 无需任何额外配置即可使用。

最后，指令（instructions）用于处理应当始终生效的持久性应用级偏好。比如：在 Excel 中始终使用公司的数字格式、PowerPoint 的项目符号保持一行以内，或者标记引用了硬编码假设的单元格。指令只需设置一次，之后无需额外提示即可自动应用。Claude 还可以帮助你编写和修改指令。

部署灵活性

Claude for Excel 和 PowerPoint 现在可以适配客户现有的合规架构。组织可以使用 Claude 账户访问这两个加载项，也可以通过现有的 LLM 网关，将流量路由至运行在 Amazon Bedrock、Google Cloud 的 Vertex AI 或 Microsoft Foundry 上的 Claude 模型。请参阅指南，了解如何通过 LLM 网关使用 Claude for Excel 和 PowerPoint。

Claude 还为 Excel 内的原生 Agent Mode 提供支持，因此 Microsoft 365 Copilot 客户可以让 Copilot 与 Claude 并肩工作，一起构建、编辑和分析工作簿。

开始使用

所有付费计划的 Mac 和 Windows 用户都可以在 beta 中使用 Claude for Excel（见指南）和 Claude for PowerPoint（见指南）之间改进后的互通能力。Excel 和 PowerPoint 中的 skills 同样面向所有付费计划开放。想要了解充分利用这些新工具的最佳实践，请注册我们的网络研讨会。

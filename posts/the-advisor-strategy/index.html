顾问策略：为 agent 提供一次智能升级

Pair Opus as an advisor with Sonnet or Haiku as an executor, and get near Opus-level intelligence in your agents at a fraction of the cost.

希望在智能与成本之间取得更好平衡的开发者，逐渐汇聚到一种我们称之为“顾问策略”（advisor strategy）的做法上：让 Opus 担任顾问（advisor），搭配 Sonnet 或 Haiku 担任执行者（executor）。这样既能为你的 agent 带来接近 Opus 级别的智能，又能把成本控制在接近 Sonnet 的水平。

今天我们在 Claude Platform 上推出 advisor 工具，让顾问策略只需在你的 API 调用中改动一行即可落地。

用顾问策略构建高性价比的 agent 

在顾问策略中，Sonnet 或 Haiku 作为执行者端到端地运行任务——调用工具、读取结果、不断迭代逼近解决方案。当执行者遇到自己难以合理解决的决策点时，会向作为顾问的 Opus 求教。Opus 访问共享上下文后返回一个计划、一处修正或一个停止信号，执行者随即继续。顾问从不调用工具，也不产出面向用户的输出，只为执行者提供指导。

这颠覆了一种常见的子 agent 模式——由更大的编排模型分解工作并委派给更小的工人模型。在顾问策略中，由更小、更具成本优势的模型驱动执行，并在需要时向上升级求助，无需任务分解、工人池或编排逻辑。前沿级别的推理只在执行者真正需要时才介入，其余运行过程都保持在执行者级别的成本上。

在我们的评测中，配备 Opus 顾问的 Sonnet 在 SWE-bench Multilingual1 上比单独使用 Sonnet 提高了 2.7 个百分点，同时每个 agentic 任务的成本降低了 11.9%。

advisor 工具 

我们通过 advisor 工具将顾问策略引入我们的 API。这是一项服务端工具，Sonnet 和 Haiku 在需要针对特定任务获得指导或帮助时会自动调用它。

在我们的评测中，配备 Opus 顾问的 Sonnet 在 BrowseComp2 和 Terminal-Bench 2.03 基准测试中的得分均有提升，且每个任务的成本低于单独使用 Sonnet。

顾问策略同样适用于以 Haiku 作为执行者的场景。在 BrowseComp 上，配备 Opus 顾问的 Haiku 拿到了 41.2% 的得分，是其单打独斗成绩（19.7%）的两倍多。配备 Opus 顾问的 Haiku 得分比单独使用的 Sonnet 低 29%，但每个任务的成本低 85%。顾问会增加相对 Haiku 单独使用的成本，但两者合计的价格仍然只是 Sonnet 的一小部分，这使它成为那些需要兼顾智能与成本的高并发任务的强力选项。


在 Messages API 请求中声明 advisor_20260301，模型交接就发生在一次 /v1/messages 请求内部——无需额外往返，也无需额外管理上下文。由执行者模型自行决定何时调用它。一旦调用，我们会把精心筛选的上下文路由给顾问模型，返回计划后执行者在同一请求内继续运行。

response = client.messages.create(
    model="claude-sonnet-4-6",  # executor
    tools=[
        {
            "type": "advisor_20260301",
            "name": "advisor",
            "model": "claude-opus-4-6",
            "max_uses": 3,
        },
    10|        # ... your other tools
    ],
    messages=[...]
)

# Advisor tokens reported separately
# in the usage block.

计费方式。顾问 token 按顾问模型的费率计费；执行者 token 按执行者模型的费率计费。由于顾问只生成一份简短的计划（通常 400-700 个文本 token），而全部输出由执行者以更低的费率完成，因此总成本远低于端到端运行顾问模型。
内建成本控制。设置 max_uses 即可限制每次请求中顾问的调用次数。顾问 token 会在 usage 块中单独上报，方便你按层级追踪开销。

与现有工具协同工作。advisor 工具只是 Messages API 请求中的又一个条目。你的 agent 可以在同一个循环里搜索网页、执行代码，并向 Opus 求教。

开始使用

advisor 工具 现已在 Claude Platform 原生环境中以 beta 形式提供。上手步骤：

  1. 添加 beta 功能请求头：anthropic-beta: advisor-tool-2026-03-01
  2. 在 Messages API 请求中加入 advisor_20260301
  3. 根据你的用例调整 system prompt

我们建议用你现有的评测套件分别跑一遍单独的 Sonnet、以 Sonnet 为执行者搭配 Opus 顾问，以及单独的 Opus。更多信息见 文档。

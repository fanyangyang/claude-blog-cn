在开发者控制台中改进你的提示词

阅读英文原文 →

今天，我们推出了一项新功能，让你可以直接在 Anthropic Console 中改进提示词并管理示例。这些功能让运用提示词工程最佳实践、构建更可靠的 AI 应用变得更加轻松。

更好的提示词带来更好的输出结果

提示词的质量在很大程度上决定了模型在特定任务上的回答效果。然而，落实提示词最佳实践需要时间，而且不同模型提供商之间的最佳实践往往各不相同。

提示词改进器（prompt improver）允许开发者拿现有提示词，借助 Claude 利用高级提示词工程技术自动进行优化。它既适合适配原本为其他 AI 模型编写的提示词，也适合优化手写提示词。

提示词改进器通过以下方法强化现有提示词：

  1. 思维链推理（Chain-of-thought reasoning）：添加一个专门区域，让 Claude 在回答前系统地思考问题，从而提升准确性和可靠性。
  2. 示例标准化：将示例转换为统一的 XML 格式，提升清晰度和处理效果。
  3. 示例增强：为现有示例补充与重新结构化后的提示词相契合的思维链推理。
  4. 重写：重写提示词以理清结构，并修正细微的语法或拼写问题。
  5. 预填充（Prefill）：预填充 Assistant 消息，以引导 Claude 的行为并强制约束输出格式。

新提示词生成之后，你可以向 Claude 反馈哪些地方有效、哪些地方无效，从而进一步改进提示词。

我们的测试表明，在一个多标签分类测试中，提示词改进器将准确率提高了 30%1；在一项摘要任务中，将字数要求的遵守率提升到了 100%。2

管理多轮示例（multi-shot examples）

在提示词中加入示例是提升模型回答质量最有效的方法之一，尤其是当你需要 Claude 在输出中严格遵循特定格式时。你现在可以直接在 Workbench 中以结构化格式管理示例，更方便地添加具有清晰输入/输出对的新示例，或编辑现有示例来优化回答质量。

如果你的提示词中没有示例，可以通过 Claude 驱动的示例生成功能来添加。Claude 可以自动创建合成示例输入并起草输出，帮你简化这一过程。

添加示例有助于提升：

  • 准确性：减少对指令的误解。
  • 一致性：确保输出符合期望的格式。
  • 性能：增强 Claude 处理复杂任务的能力。

用理想输出评估提示词

我们的提示词评估器允许你在各种场景下测试提示词。为了帮助评估和改进提示词性能，我们在 Evaluations 标签页中新增了一个可选的"理想输出"（ideal output）列。该列帮助用户以 5 分制对模型输出进行有效且一致的评分。

测试完新提示词之后，你可以在提示词改进器中向 Claude 进一步反馈仍存在的问题，反复迭代，直到对结果满意为止。提示词改进器还可以根据任意要求修改提示词和示例。例如，你可以让 Claude 把提示词和示例改成输出 JSON 格式，而不是 XML 格式。

客户聚焦：Kapa.ai

Kapa.ai 是一家将技术知识库转化为可直接投产的 AI 助手的技术公司，他们使用提示词改进器将多个关键 AI 工作流迁移到了 Claude。

"Anthropic 的提示词改进器让我们的 Claude 3.5 Sonnet 迁移变得顺畅，帮助我们更快地上线，"Kapa.ai 联合创始人 Finn Bauer 表示。

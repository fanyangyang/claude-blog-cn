Claude 现已支持 Google Docs、Sheets 和 Slides

使用 Google Workspace 的团队现在可以把 Claude 带入他们的文件，或直接从 Claude 中处理文件——全新的插件以及 Google Docs、Sheets 和 Slides 连接器（测试版）现已推出。

适用于 Google Workspace 的 Claude for Google Workspace™ 现已在所有付费 Claude 套餐中公开测试。它把 Claude 带到了 Google Docs、Sheets 和 Slides 中，让你可以直接在打开的文件里与 Claude 协作。此外，我们还发布了全新的 Google Docs、Sheets 和 Slides 连接器（测试版），让 Claude 可以直接从 Claude 中创建和编辑 Google 文件。

Claude 在你工作的地方工作

安装插件后，Claude 会打开在你文件旁的侧边栏中，工作时无需在应用或浏览器标签页之间来回切换。Claude 可以读取你打开的文档、表格或演示文稿，看到你选中的文本、单元格或幻灯片，并直接在文件中进行修改。

在 Docs 中，例如，Claude 可以直接修改某个句子或重排标题样式，而不影响周围的格式。对于较大的改写，它可以以侧边栏中的建议卡片形式提出修改。每张卡片都会高亮显示将要修改的段落，你可以选择应用或忽略。你可以让 Claude 精简产品需求文档的执行摘要，并把后续步骤转为表格，Claude 会在文档中直接完成这两项工作。

在 Sheets 中，Claude 可以编写公式、构建数据透视表和原生 Sheets 图表，并添加新的标签页。对于数据合并或清洗，它可以把某个区域的数据拉入 Python 处理，再把结果写回表格。你可以从一张空白表格开始，附上源文件，要求生成一份按团队分页并带汇总图表的 Q3 预算与实际对比报告，Claude 还能标记出任何超预算的项目。

在 Slides 中，Claude 可以根据你演示文稿的版式和主题构建新幻灯片，使其与其余页面保持一致。随后它可以检查自己的工作，标记出重叠或超出幻灯片边界的元素，以及难以阅读的文本。

由你决定 Claude 在多大程度上自主完成工作。在默认的“编辑前询问”（Ask before edits）模式下，每次修改都会以带有摘要的批准卡片形式出现，Claude 会等待你批准后再执行编辑。在“接受所有编辑”（Accept all edits）模式下，Claude 会一气呵成地完成任务并应用所有更改，不会中途停顿。

你的连接器、技能和企业管控随你同行

当你登录 Claude 账号后，侧边栏会带有你在 Claude 中使用的相同模型、连接器 （在新标签页中打开）和技能 （在新标签页中打开）。例如，如果你要为客户制作季度业务回顾（QBR）演示文稿，Claude 可以通过你的 Google Drive 连接器调取 Salesforce 中的账户历史和最近的通话记录。如果你把 QBR 模板保存为技能，你的团队就能按照相同的格式和步骤制作下一份演示文稿。

在 Enterprise 套餐中，Compliance API、客户管理加密密钥（CMEK）和 OpenTelemetry 审计导出等管控同样适用于该插件。

从 Claude 中编辑 Google 文件

借助同样处于测试版的Google Docs、Sheets 和 Slides 连接器 （在新标签页中打开），你可以从 Claude 开始，直接在对话中创建和编辑你的 Google 文件。粘贴一个 Google 文件链接，或要求生成一个 Google 文档、表格或演示文稿，在支持的配置下，它会打开在对话旁的窗格中。当你需要新文件或工作涉及多个文件时，从 Claude 开始最合适。Claude 的访问权限与你现有的 Google 共享权限保持一致。

快速上手

Claude for Google Workspace （在新标签页中打开） 在所有付费套餐中处于测试阶段。

你可以从Google Workspace Marketplace （在新标签页中打开）安装它，然后打开一个文件，进入“扩展程序（Extensions）> Claude > 打开 Claude（Open Claude）”。管理员可以从 Google Admin 控制台把它部署到整个域或特定用户组。帮助中心指南涵盖了安装配置步骤 （在新标签页中打开）。

要从 Claude 中编辑 Google 文件，请开启Google Docs、Sheets 和 Slides 连接器 （在新标签页中打开）。在 Team 和 Enterprise 套餐中，需要所有者或主要所有者先启用连接器。

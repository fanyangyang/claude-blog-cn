Claude 现已支持更多安全与合规工具

阅读英文原文 →

更新：我们的安全与合规合作伙伴集成已扩展到 60 多家，完整名单请见 帮助中心。

‍

今天我们推出 28 项与知名安全与合规工具的集成。IT 和安全团队现在可以像治理技术栈中的其他应用一样，在我们的平台和产品套件中对 Claude 进行统一治理。

工作原理

这些新集成均由 Claude Compliance API 驱动，它为企业的安全与合规团队提供两类数据的编程化访问能力：

  • 来自 Claude Enterprise 的对话内容——包括聊天、上传的文件和项目——管理团队可以对 Claude 施加与其他办公应用相同的安全、监控和 DLP 策略。
  • 覆盖 Claude Enterprise 和 Claude Platform 的活动事件——用户登录、管理员操作和配置变更——安全团队得以统一掌握 Claude 在整个组织内的使用情况。

Claude Compliance API 集成

目前已有 60 多家头部安全与合规厂商提供集成，覆盖企业赖以依托的各大品类——包括 DLP、SASE、数据安全、SIEM 与安全运营、身份管理、eDiscovery、AI 安全态势管理，以及 AI 可观测性与遥测基础设施。

新增集成包括：Air、Akto、Artemis Security、Axonius、Bay、Beacon Security、Bloom Security、Bold Security、Brava Security、C1.ai、Check Point、Cloudflare、Cribl、CrowdStrike、Cyera、Dash Security、Datadog、Daylight、Elastic、Exaforce、ForceAI Security、Forcepoint、Fortinet、Geordie AI、Grip Security、Harmonic Security、IBM Guardium、Island、Linx Security、Microsoft Purview、Mimecast、Mint Security、Netskope、Nightfall AI、Okta、Onyx Security、Opsin、Palo Alto Networks、Pluto Security、Proofpoint、Reco、Relativity、ReliaQuest、Rubrik、Safeguard、SailPoint、Saviynt、SentinelOne、Sentra、Smarsh、Snyk、Sumo Logic、Sysdig、Tenable、Theta Lake、Token Security、Torch Security、Trellix、TrendAI、Varonis、Wiz（现为 Google Cloud 旗下）、Zenity 和 Zscaler。

对于已经在使用这些安全与合规平台的组织，为 Claude 的使用开启覆盖非常简单：连接并配置你的 Claude 实例，数据就会流入你为其他所有应用使用的同一套仪表盘和告警工作流。

如何开始

Claude 客户：要将你的 Claude 实例接入受支持的合作伙伴平台，请访问我们的帮助中心，查阅 Claude Enterprise 和 Claude Platform 的 Compliance API 文档。

安全合作伙伴：如果你是已构建 Compliance API 集成的安全、合规或 IT 平台，在此申请加入该网络。

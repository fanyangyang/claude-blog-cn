在 Foundation Models 框架中使用 Claude，为 Apple 平台构建智能应用

阅读英文原文 →

今天我们发布了 Claude 对 Foundation Models 框架的支持：一个新的 Swift 软件包，让 Apple 开发者能够通过 Apple 的 Foundation Models 框架调用 Claude，完成更复杂的工作流。

Apple 的 Foundation Models 框架让开发者可以直接从 Swift 原生调用模型。它非常易用，借助引导式生成，最少只需三行代码就能返回带类型的 Swift 值。开发者可以借此使用 Apple 的端侧模型来完成摘要、信息提取等快速的本地任务。

现在，当请求需要多步推理、代码生成等能力时，开发者可以通过 Apple 的 Foundation Models 框架把任务交给 Claude。Claude 还可以搜索网络获取最新信息、执行代码做数据分析，然后把响应流式返回到同一个视图中。

由于 Apple 的框架会通过 @Generable 注解返回带类型的 Swift 值，开发者在调用 Claude API 时拿到的已经是干净的输入，而不是原始的用户文本。

这能带来什么

Foundation Models 框架已经支撑起大量智能化的端侧功能——能给出个性化提示的日记应用、可以概括合同条款的文档应用、按学生水平讲解概念的学习应用。接入 Claude 之后，这些模式每一种都能更进一步。

日记应用可以在端侧生成每日提示，然后让 Claude 从几个月的日记里找出其中的脉络。学习应用可以在端侧解释一个术语，而当学生追问"为什么这个概念和我们学过的其他内容有关"时，再把任务交给 Claude。

对用户来说这是一个完整的体验，而每一步背后都是最合适的那个模型。

开始使用

Claude 对 Foundation Models 框架的支持将于明天上线，通过 Apple 的 Foundation Models 框架在 iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27 上运行。将它添加到你的项目中，使用 Anthropic API 密钥登录，然后把 Apple 端侧模型的带类型输出传入 Claude 请求——这个软件包会处理流式传输、工具调用和结构化响应，并把结果送回你的 SwiftUI 视图。

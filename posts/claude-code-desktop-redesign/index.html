桌面版 Claude Code 重新设计：支持并行代理

阅读英文原文 →

桌面版 Claude Code 进行了重大重新设计，引入了并行代理支持。新版本提供了更强大的多任务处理能力，让开发者可以同时运行多个 Claude 代理处理不同的任务。

新特性

  • 并行代理：同时运行多个 Claude 代理，每个代理处理不同的任务
  • 全新界面：重新设计的 UI 让多代理管理更加直观
  • 任务仪表盘：实时查看所有代理的执行状态和进度
  • 资源监控：跟踪每个代理的 CPU、内存和 token 使用情况

使用场景

并行代理特别适合以下场景：同时进行代码审查和重构、并行处理多个模块的测试编写、同时进行文档生成和代码优化等。

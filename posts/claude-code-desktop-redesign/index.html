桌面版 Claude Code 重新设计：支持并行代理

Today, we're releasing a redesign of the Claude Code desktop app, built to help you run more Claude Code tasks at once.

新版本带来了用于管理多个会话的全新侧边栏、可拖拽自由布局的工作区、集成的终端和文件编辑器，以及一系列性能和使用体验上的改进。

全新的桌面体验

对许多开发者来说，智能体式工作的形态已经变了。你不再是一次敲入一个提示词然后干等。你可能在一个仓库里发起重构，在另一个仓库里修 bug，还在第三个仓库里跑一轮补测试，结果出来就逐个查看，方向偏了就及时纠偏，上线前再审查一遍 diff。

新应用正是为如今智能体编程的真实体验而设计：多线并行，而你坐在编排者的位置上。

并行运行会话

全新侧边栏把所有进行中和最近的会话集中在一处。你可以在多个仓库里同时开工，结果一到就随时切换。

你可以按状态、项目或环境过滤，也可以让侧边栏按项目分组，更快找到并恢复会话。当一个会话对应的 PR 合并或关闭后，它会自动归档，让侧边栏始终聚焦在活跃的工作上。

任务进行到一半想问个问题时，可以打开侧边对话（⌘ + ; 或 Ctrl + ;）来分出一个支线会话。侧边对话会从主线程获取上下文，但不会往主线程里回写任何内容，避免干扰你的任务。

不离开应用就能审查和交付

这次改版把更多常用工具搬进了应用，你无需在编辑器之间来回切换，就能审查、微调并交付 Claude 的工作成果：

  • 集成终端：与会话并行运行测试或构建。
  • 应用内文件编辑器：打开文件，直接就地修改并保存。
  • 更快的 diff 查看器：针对大型变更集的性能重新打造。
  • 增强的预览：除了在预览面板中运行本地应用服务器，还可以在应用内打开 HTML 文件或 PDF。

每个面板都支持拖拽。终端、预览、diff 查看器和对话，随你怎么排布成适合你工作方式的网格。

适配你的技术栈

桌面应用现在与 CLI 插件完全对齐。无论你的组织统一管理 Claude Code 插件，还是你在本地自行安装，它们在桌面应用中的表现与在终端中完全一致。

你仍然可以选择在本地或云端运行会话。SSH 支持现已从 Linux 扩展到 Mac，两种平台都可以把会话指向远程机器。

按你的工作方式定制

三种视图模式——Verbose、Normal 和 Summary——让你可以在界面中自由调节详略：从完整透明地展示 Claude 的每一次工具调用，到只看最终结果。新增的键盘快捷键覆盖会话切换、新建和导航；按 ⌘ + /（或 Ctrl + /）即可查看完整列表。新的用量按钮可以一目了然地显示上下文窗口和会话用量。

在底层，应用为可靠性和速度做了重构，现在能够在 Claude 生成的同时流式输出响应。

开始使用

重新设计的桌面应用现已面向所有 Pro、Max、Team 和 Enterprise 方案的 Claude Code 用户开放，也可通过 Claude API 使用。

下载应用，如果你已安装，更新并重启即可。欢迎查阅文档了解更多。

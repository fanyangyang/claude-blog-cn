HCLTech 加入 Claude 合作伙伴网络，成为全球首要合作伙伴

HCLTech 将与 Anthropic 合作，把 Claude 和 Claude Code 引入其为银行、医院、电信公司和制造商运行的 IT 系统

  • Category
    Product announcements
  • Date
    October 21, 2026
  • Reading time
    4 min
  • Share

Anthropic 正在与 HCLTech （在新标签页中打开） 合作，这是一家业务遍布 60 个国家、拥有超过 23 万名员工的全球性科技公司。HCLTech 将通过专门的 Anthropic 业务单元和卓越中心（Center of Excellence）为其客户在 Claude 上构建智能体解决方案，将 Claude 嵌入 HCLSoftware 产品，并把 Claude 和 Claude Code 集成到 AI Force——其用于为客户提供 IT 服务的平台中。HCLTech 由此成为 Claude 合作伙伴网络中的 全球首要合作伙伴（Global Premier Partner） （在新标签页中打开）。

HCLTech 为金融服务、制造业、生命科学与医疗健康、科技、半导体、电信与媒体、零售与快消品，以及出行和公共服务等行业提供解决方案。在这些环境中，一次失误代价高昂，每一项变更都需要经过审查、记录和批准。此次合作旨在将 Claude 带入这类工作，并配备专为这些环境设计的管控措施。

HCLTech 将如何把 Claude 投入实际工作

HCLTech 将在三个层面把 Claude 引入其业务，并为每一层都设计了防护措施和人工审查机制。

  • 专门的 Anthropic 业务单元和卓越中心。HCLTech 的前瞻部署工程师将搭建安全的沙箱环境，让客户在正式部署前，可以先针对自己的系统和数据测试 Claude。该中心将培训客户员工队伍、帮助工程团队采纳 AI 原生实践，并构建以安全方式大规模运行智能体所需的企业级管控体系。
  • HCLSoftware 产品中的 Claude。HCLSoftware 将成为 Anthropic 的独立软件供应商（ISV）合作伙伴，并将在网络安全、自动化、业务流程应用和应用开发领域的精选产品中嵌入 Claude。首批产品包括用于终端管理的 HCL BigFix、用于应用安全测试的 HCL AppScan，以及用于数据与分析领域的 Actian AI 分析师。
  • AI Force 中的 Claude 与 Claude Code。AI Force 是 HCLTech 为其服务的企业客户提供 IT 支持、代码修复和数字化员工服务的平台。Claude 和 Claude Code 将带着策略护栏、异常处理机制以及对高风险变更的人工监督进入该平台。智能体负责常规工作，而凡是涉及中小客户生产系统的操作，均由 HCLTech 工程师审查并批准。

"很少有科技公司能同时具备全球系统集成商的规模与 ISV 的产品深度，"HCLTech 首席执行官兼董事总经理 C Vijayakumar 表示，"这赋予我们罕见的优势，能够以安全的方式大规模工程化部署 Agentic AI，并为客户交付最重要的业务成果。我们与 Anthropic 的合作将进一步加强我们实现这一目标的能力。"

"AI 的价值有多大，取决于它有多值得信赖，而我们打造 Claude 正是为了给企业信心，让他们放心把 Claude 引入最敏感、最有价值的工作中，"Anthropic 联合创始人兼总裁 Daniela Amodei 表示，"HCLTech 为银行、医院、电信公司和制造商管理着这类系统，我们非常高兴能与他们合作，共同集成 Claude 和 Claude Code。这次合作——以及我们共同推动能力与安全协同发展的更广泛承诺——正是 AI 将如何推动整个行业变得更好的方式。"

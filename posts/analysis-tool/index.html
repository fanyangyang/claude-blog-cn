Claude.ai 分析工具介绍

阅读英文原文 →

更新：分析工具正被更强大的代码执行能力所取代。（2025 年 11 月 5 日）

代码执行可以完成同样的所有分析，还能生成可下载的文件（电子表格、CSV、报告）、创建可视化并处理复杂的多步骤工作流。了解更多。

‍

我们推出分析工具（analysis tool）——Claude.ai 的一项全新内置功能，让 Claude 能够编写并运行 JavaScript 代码。Claude 现在可以处理数据、执行分析并生成实时洞察。分析工具已在功能预览中面向所有 Claude.ai 用户开放。

你可以把分析工具理解为一个内置的代码沙盒，Claude 可以在里面进行复杂的数学计算、分析数据，并在给出答案前反复尝试不同的思路。信息处理和代码运行能力意味着你会得到更准确的答案——它建立在 Claude 3.5 Sonnet 业界领先的编码和数据技能之上。

分析并可视化 CSV 文件中的数据

当你需要从数据中获得精确、可验证的答案时，Claude 现在的工作方式更像一位真正的数据分析师。它不再仅依赖抽象分析，而是可以系统化地处理你的数据——清洗、探索、逐步分析，直到得出正确的结果。

虽然 Claude 一直以来都会写代码，但它现在可以在 Claude.ai 中直接运行这些代码，以支持各类分析任务。借助分析工具，你得到的答案不仅推理严密，而且在数学上精确、可复现。

Claude.ai 中的分析工具可以扩展各个团队的能力。例如：

  • 营销人员可以上传覆盖完整漏斗的客户互动数据，Claude 会找出提升转化率的机会。
  • 销售 团队可以上传全球销售数据，Claude 会提供按国家细分的业绩分析。
  • 产品 经理可以上传客户参与度数据，Claude 会为 sprint 规划和开发优先级提供依据。
  • 工程师可以上传各服务器的性能日志，Claude 会指出资源利用率可以改进的方向。
  • 财务 团队可以上传月度财务数据，Claude 会创建一个财务仪表盘，呈现关键趋势并辅助决策。

开始使用

登录 Claude.ai 即可开启分析工具的功能预览。要管理所有功能预览，请点击左下角你的名字。

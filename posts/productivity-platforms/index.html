Claude 与你的生产力平台

阅读英文原文 →

Claude 现已与 Microsoft 365 集成，并提供跨已连接工具的企业搜索功能。

Claude 与你每天都在使用的生产力工具协同工作，将文档、邮件和日历中的上下文直接带入你的对话。让你把更少的时间花在收集信息上，把更多的时间用在真正产生影响力的决策和工作上。

Claude 的 Microsoft 365 连接器

通过我们的 MCP 连接器，将 Claude 与 Microsoft 365 连接起来。借助对你文档、通信和日历的访问能力，Claude 能获得更充分的上下文，从而更高效地与你协作——帮助你深入推理复杂问题、做出明智决策，并更快地采取行动。

Claude 可以使用：

  • Microsoft SharePoint 和 OneDrive：跨站点和文档库搜索与分析文档，从项目规格说明到战略规划一应俱全，无需手动将文件上传给 Claude。
  • Microsoft Outlook：访问邮件往来、分析沟通模式，并从你的通信中提炼洞察，了解项目进展、客户反馈或团队对齐情况。
  • Microsoft Teams： 搜索聊天对话、频道讨论和会议纪要，找出关键决策、跟进项目进展，并了解团队最近在讨论什么。

企业搜索

我们还通过一个专属的共享项目让访问公司知识变得更加容易，该项目会以你的公司名称进行个性化定制。其中包含自定义提示词，帮助 Claude 在公司的各类工具中进行高效搜索，还提供了连接核心工作应用的简单设置步骤。管理员完成设置并连接核心工具后，组织中的所有人都会自动获得该项目的访问权限。

当你向 Claude 提问时，它可以在一处统一搜索公司已连接的数据源，因此你得到的答案将建立在组织集体知识的基础之上，而不仅仅是你个人的文件。例如，询问 Claude 公司的远程办公政策，它会从 SharePoint 中的人力资源文档、Outlook 中的邮件讨论以及来自各种渠道的团队规范中提取信息，汇总成一份详细的报告。

企业搜索对新成员入职特别有价值，也适用于解答战略性问题（比如分析客户反馈中的规律），以及快速找到任何话题上值得咨询的内部专家。

开始使用

Microsoft 365 连接器现已面向所有 Claude Team 和 Enterprise 计划客户开放。管理员必须先为组织启用该连接器，之后个人用户才能使用自己的账户完成认证。

企业搜索已面向所有 Team 和 Enterprise 组织启用。管理员需要先为组织定制项目并筛选数据源，团队才能开始使用。

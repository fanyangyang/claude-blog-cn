Claude API skill 现已登陆 CodeRabbit、JetBrains、Resolve AI 和 Warp

Today, CodeRabbit, JetBrains, Resolve AI, and Warp are bundling the claude-api skill, giving developers production-ready Claude API code wherever they build. First introduced in Claude Code in March, the skill is now in more of the tools developers already use.

今天，CodeRabbit、JetBrains、Resolve AI 和 Warp 将内置 claude-api skill，让开发者无论在哪里构建，都能写出生产可用的 Claude API 代码。该 skill 于 3 月首次在 Claude Code 中推出，如今进入了更多开发者已经在用的工具。

用 Claude API skill 构建

claude-api skill 沉淀了让 Claude API 代码真正好用的细节，比如哪种 agent 模式适合某项工作、各代模型之间哪些参数会变，以及何时该用 prompt caching。结果是更少的错误、更好的缓存、更干净的 agent 模式，以及更顺畅的模型迁移。 

它会随着我们的 SDK 变化保持更新。当新模型发布或 API 新增功能时，Claude 已经知道。

在任何提供该 skill 的地方，都可以让 Claude：

  • “提高我的 cache hit rate。”该 skill 会应用许多开发者容易忽略的 prompt caching 规则。
  • “给我的 agent 加上 context compaction。”它会带你走一遍文档中的 compaction 原语和 agent 模式。
  • “帮我升级到最新的 Claude 模型。”Claude 会审查你的代码，并带你更新模型名称、提示词，以及像 Opus 4.7 这样的新模型所需的 effort 设置。在 Claude Code 中，你也可以直接运行 /claude-api migrate.‍
  • “为我所在行业构建一个深度研究 agent。”Claude 会带你配置 Claude Managed Agents，让长时研究变成几次提示，而不是一个定制项目。在 Claude Code 中，你也可以直接运行 /claude-api managed-agents-onboard。

面向由 Claude 驱动的编程 agent

任何编程 agent 都可以内置 claude-api skill，把围绕 Claude API 的专业知识交给用户。如果你正在构建一个让开发者编写 Claude API 代码的工具，该 skill 开源在 anthropics/skills。我们的内置指南用大约 20 行 CI 就能完成设置，之后 skill 会自动保持最新。

开始使用

该 skill 已经出现在 Claude Code、CodeRabbit、JetBrains、Junie、Resolve AI 和 Warp 中。了解更多，请参阅 claude-api skill 文档。

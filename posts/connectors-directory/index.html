发现可与 Claude 协同工作的工具

阅读英文原文 →

今天，我们推出一个新的工具目录（directory），收录了可以连接到 Claude 的各类工具，你可以浏览并一键试用。我们还展示了由合作伙伴构建的新连接器，涵盖 Notion、Canva、Stripe 等远程服务，以及 Figma、Socket、Prisma 等本地桌面应用。

现在，Claude 可以访问与你相同的工具、数据和上下文——这将把它从一个好用的助手，转变为一位消息灵通的 AI 协作者，为你提供更相关的回复，并能直接在你的工具中与你协作。

上下文改变一切

大多数 AI 交互都从你解释一切开始：你的项目细节、你的截止日期、你的工具——一遍又一遍。就像每次都从零开始一样。

你可能会让 Claude "为我们最新的功能撰写发布说明"，然后得到一个不错的模板。但如果将 Claude 连接到 Linear 之类的工具，你就可以让 Claude "根据 Linear 上我们最近一个 sprint 的内容撰写发布说明"，它会拉取你真实的 Linear 工单，并生成专业的、可直接发布的发布说明。

以下是一些将 Claude 与已连接工具结合使用的方式：

  • 更快交付：把与 Claude 的讨论整理成结构清晰的 Notion 路线图
  • 创建设计：把创意简报转化为 Canva 社交媒体帖子
  • 更优的设计到代码流程：把 Figma 文件变成可直接上线的代码
  • 管理支付：访问 Stripe 的客户数据和支付信息

开始使用

你可以在 claude.ai/directory 浏览我们推荐的工具目录。点击"Connect"完成身份验证（桌面扩展则点击"Install"），Claude 即可获取你的工作上下文。你也可以在 anthropic.com/partners/mcp 浏览精选工具。

该目录现已面向所有 Claude 网页端和桌面端用户开放。本地桌面扩展可通过 Claude Desktop 应用获取。远程应用和服务的连接器仅面向付费计划用户开放。

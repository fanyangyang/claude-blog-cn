Claude Managed Agents 新功能：定时运行智能体并在 Vault 中存储环境变量

Claude Managed Agents now supports scheduled deployments and vaults: run agents on a cron schedule and securely authenticate CLI tools and other services.

从今天起，Claude Managed Agents 可以按计划定时运行，并安全地访问 CLI 工具和其他需要认证的服务。这两项功能现已在 Claude Platform 上开启公测。

定时部署：让智能体按计划运行

智能体现在可以按计划定时运行，自动完成例行工作。定时部署（scheduled deployment）会按 cron 计划运行一个 Claude Managed Agent。每次计划触发时，智能体都会开启新会话并完成任务，你无需自己构建或托管任何调度器。 

它适合诸如每夜数据同步、每周合规扫描、每日摘要等周期性工作。部署上线后，你可以随时暂停、恢复或归档，也可以按需触发额外的运行。

已有团队在用定时部署自动化周期性工作：

  • Rakuten 使用定时部署来分析表格数据，并按周或按月生成报告和演示文稿。团队还用它监控生产日志和指标，让产品经理无需搭建仪表盘就能掌握应用健康状况。
  • Actively AI 使用 Managed Agents 为销售团队提供跨账户的智能体搜索。定时部署会定期刷新答案，替代了团队最初自建的调度基础设施，简化了技术栈。‍
  • Ando 使用定时部署保持招聘和销售团队的运转。智能体自主监控各个渠道中的待办后续事项，到期时自动跟进，并发送会议提醒。

Vaults：存储环境变量，为 CLI 和其他工具完成认证

Vaults 为 Claude Managed Agents 安全地存储环境变量和凭证。运行时，智能体会以环境变量的形式访问 API 密钥等敏感信息，从而完成对 CLI 工具和其他服务的认证，而无需把凭证硬编码进提示词或代码。

智能体可以通过直接 API 调用、CLI 和 MCP 连接外部系统。CLI 让智能体直接通过 shell 驱动现有的命令行工具，是一条快速、轻量的集成路径。只需注册一个 API 密钥，指定对应的环境变量名以及它可访问的域名，安装在智能体沙箱中的 CLI 就能用它发起经过认证的 API 调用。

智能体永远看不到你的密钥，因为沙箱里只保存一个占位符。真实密钥在网络边界处才会附加，而且只附加到发往你允许的域名的请求上，因此它只会去往你批准的地方。要更换密钥，只需在 vault 中更新，正在运行的会话会在下次调用时取到新值。大多数通过 HTTP 请求发送密钥的 CLI 都以这种方式工作，包括 Browserbase、KERNEL、Notion、Ramp 和 Sentry 的 CLI。Browserbase 和 KERNEL 首次为 Managed Agents 赋予了浏览器能力，让智能体可以像使用其他工具一样浏览网页并与之交互。

许多团队正在使用 vault 中的环境变量，让智能体安全地访问经过认证的工具：

  • Notion 使用 vault 中的环境变量，将自家 CLI 与 MCP 工具一同推出，在不向模型传递任何 API token 的情况下为智能体增加了文件上传能力。
  • Browserbase 使用通过 vault 完成认证的 browse CLI 构建了公开的浏览器技能目录。一个定时部署会周期性校验目录，保证其内容准确。
  • KERNEL 使用 vault 中的环境变量，将智能体安全地连接到其追踪用量和客户对话的数据库。智能体会在用量激增发生时即时标记，方便团队与客户确认活动是否有意为之。‍
  • Milana 使用 vault 中的环境变量，将其 AI 产品工程师安全地接入客户的代码库。智能体自动发现并修复 Bug，大规模数据分析的速度也比以前更快。

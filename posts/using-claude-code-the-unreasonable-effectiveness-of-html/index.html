使用 Claude Code：HTML 意外地好用

阅读英文原文 →

Markdown 已经成为 agent 与人类沟通时使用的主流文件格式。它简单、可移植、具备一定的富文本能力，而且易于编辑。Claude 甚至已经出人意料地擅长在 Markdown 文件中用 ASCII 画出图表。

但随着 agent 的能力越来越强，我发现 Markdown 变成了一种限制越来越多的格式。具体来说：超过一百行的 Markdown 文件我很难读得下去；我想用 Claude 生成更丰富的可视化、色彩和图表；我还希望能更方便地分享这些输出。

与此同时，我自己编辑这些文件的情况也越来越少，更多是把它们当作规格说明和参考文件。即使需要修改，通常也是让 Claude 来改，这让 Markdown 最大的优势之一不复存在。

因此，我开始更倾向于用 HTML 而不是 Markdown 作为输出格式，并且越来越多地看到 Claude Code 团队的其他人也在采用同样的做法。在这篇文章中，我将分享我们团队为什么以及如何使用 HTML 来产出更丰富、更易读的 Claude Code 输出。如果你想亲自尝试，也可以直接开始使用这些适用于常见场景的 HTML 文件模板。

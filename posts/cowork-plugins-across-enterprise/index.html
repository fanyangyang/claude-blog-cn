面向企业各部门团队的 Cowork 与 plugins

Admins can now create private plugin marketplaces, with better control over plugins, connectors, and skills. We've also added new plugins and connectors across more departments.

今天我们推出 Cowork 和 plugins 的更新 ，帮助企业按照自己的工作方式定制 Claude。Plugins 能把 Claude 变成服务于每个角色、每个部门的专门 agent。现在，你还可以构建私有市场（marketplace），在组织内部分发这些 plugins。

本次发布还让 plugins 更容易构建和定制，赋予管理员对市场和连接器更多的控制权，并针对更广泛的岗位职能新增了 plugins 和连接器。Claude 现在还可以跨 Excel 和 PowerPoint 协调工作，端到端地完成任务并在应用之间传递上下文。

‍
Silvern Capital 是一家虚构的公司。演示中的大多数团队在 Cowork 中工作，法务团队则在使用 Thomson Reuters CoCounsel Legal——一个基于 Claude Agent SDK 从零重新打造的专用法律 agent。

升级 plugin 体验

今天我们发布了一套更新，让在组织内创建、使用和管理 plugins 变得更加容易。

管理员现在可以基于入门模板设置 plugins，也可以从零构建，Claude 会通过提问引导你完成设置，让 skills、命令和连接器（MCP）贴合你公司的需求。这一切都收纳在一个名为"Customize"的全新统一菜单中，它把 plugins、skills 和连接器整合在一起，管理员可以在一处查看和管理所有内容。

连接器体验也经过全面改造：目录更完善、管理员控制更精简，把连接器打包进 plugins 的管理也更轻松。管理员还可以更好地控制团队能访问哪些 plugins，包括组织专属市场、以私有 GitHub 仓库作为插件来源（私有 beta）、按用户开通以及自动安装。

在用户一侧，斜杠命令现在以结构化表单的形式启动，像"生成报告"或"仪表盘"这样的工作流，用起来就像填写一份简报一样直观。Cowork 现在也全面支持公司品牌定制，包括专为你的组织重新设计的首页体验。

此外，我们正在加入 OpenTelemetry 支持，让管理员能够跟踪团队的使用情况、成本和工具活动。

新的连接器与 plugins

Cowork 在接入你已在使用的工具后，最能发挥处理复杂任务的实力。连接器让 Claude 更贴近你的工作所在地——帮你在工具之间跑得更快，而不是取代你依赖的专业能力或软件。

来自主流企业软件提供商的新连接器现已可用，包括 Google Workspace（日历、Drive、Gmail）、Docusign、Apollo、Clay、Outreach、Similarweb、MSCI、LegalZoom、FactSet、WordPress 和 Harvey。此外，Slack by Salesforce、LSEG、S&P Global、Apollo、Common Room 以及 Tribe AI（见下文）等公司也为联合客户构建了可供探索的 plugins。

我们还在扩充预构建插件模板库，让更多知识工作者能在 Cowork 中发现价值。每个模板都与相关领域的从业者共同设计，因此工作流、术语和产出都还原了这类工作实际的完成方式。新的 plugins 包括：

  • HR（人力资源）：支持覆盖员工全生命周期的人员运营，从起草录用通知、制定入职计划，到撰写绩效评估、开展薪酬分析。
  • Design（设计）：加速设计工作流，包括生成评审框架、撰写 UX 文案、执行无障碍审查、搭建用户研究计划。
  • Engineering（工程）：梳理日常工程工作流，如撰写站会摘要、协调事件响应、构建部署检查清单、起草复盘报告。
  • Operations（运营）：管理核心业务运营，包括流程文档、供应商评估、变更请求跟踪和操作手册（runbook）创建。
  • Brand voice（品牌语调）（由 Tribe AI 出品）：分析你现有的文档、营销材料和对话，把品牌的语调提炼成清晰、可执行的标准。
  • Financial analysis（金融分析）：支持每位金融分析师都需要的基础工作流，从市场与竞争研究到财务建模，再到 PowerPoint 模板创建和质量检查。
  • Investment banking（投资银行）：加速交易工作流，包括审阅交易文件、构建可比公司分析、准备路演材料。
  • Equity research（股票研究）：梳理研究工作流，如解析财报电话会议纪要、用新指引更新财务模型、起草研究简报。
  • Private equity（私募股权）：支持项目寻源和尽职调查，包括审阅大量文档集、提取标准化财务数据、对情景建模，并按投资标准为机会打分。
  • Wealth management（财富管理）：帮助理财顾问分析投资组合、识别偏离度和税务敞口，并大规模生成再平衡建议。

Plugins 是归你所有的、简单且可移植的文件系统。它们可以在 Cowork 和任何基于 Claude Agent SDK 构建的产品上运行，让跨团队、与行业专家共建私有插件市场变得轻而易举。

跨应用工作

Claude 现在还可以跨 Excel 和 PowerPoint 端到端地处理多步骤任务。Claude 可以在两个 Office 加载项之间使用并传递上下文，这让给 Claude 指派更大的项目成为可能，比如在 Excel 中完成一项分析，再把它变成 PowerPoint 里的演示文稿。这是一项早期 research preview，指向的是让 Claude 像我们一样跨应用工作。

开始使用

所有面向用户体验的 plugin 更新已对所有 Cowork 用户开放。Team 和 Enterprise 管理员可以使用公司品牌定制、按用户开通和 MCP 控制功能。

Claude 跨 Excel 和 PowerPoint 工作的能力现以 research preview 形式，面向 Mac 和 Windows 的所有付费计划开放。下载 Claude in Excel 和 Claude in PowerPoint 加载项即可开始。

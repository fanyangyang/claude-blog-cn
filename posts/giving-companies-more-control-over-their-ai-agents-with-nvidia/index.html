与 NVIDIA 合作，让企业对其 AI 智能体拥有更多控制权

Anthropic 与 NVIDIA 合作，为 Open Agent Safety Platform 的智能体栈带来额外的安全与控制层。

NVIDIA 今日发布了 Open Agent Safety Platform——一个用于强化 AI 安全性的开放软件平台与参考系统设计。Anthropic 与 NVIDIA 合作，为智能体栈带来额外的安全与控制层。 

Claude Managed Agents 是一套可组合的 API，用于大规模构建和部署生产级智能体。它将智能体所需的凭据保管在保险库（vault）中，因此智能体永远无法直接看到这些凭据。开源的 NVIDIA OpenShell 软件则用于控制智能体在工作过程中可以执行和访问的内容。同时使用 Managed Agents 与 OpenShell 的客户可以限制智能体的能力范围，审查智能体做过什么，并确认这些限制确实已经生效。 

企业正在从用 AI 回答问题，迈向部署智能体——让智能体跨业务部门处理复杂工作、使用专有数据、并代表用户采取行动。随着模型不断进步，智能体的用途越来越广，获得的访问权限也越来越多。智能体的权限越大，企业就越需要控制和审核它的行为。 

层层设防 

防护始于模型内部的安全机制。Managed Agents 与 NVIDIA OpenShell 则在模型之外添加限制，作用于智能体的实际行为。每一层都独立执行其限制，因此防护不依赖于任何单一层次。这些层级是模块化的，企业可以按自身架构选用合适的层级。 

Claude Managed Agents 负责干活，并保管凭据 

使用 Managed Agents 时，智能体循环（agent loop）运行在与沙箱相互独立的服务器上——沙箱是实际执行工作的隔离环境。凭据（即密码和访问密钥）则保存在单独的保险库中，智能体永远接触不到它们。 

Managed Agents 还提供审计跟踪，记录每个智能体的操作，并可与公司现有的访问控制系统集成。企业可以自带沙箱环境，自主选择其运行位置和运行方式。 

NVIDIA OpenShell 划定智能体的可访问范围 

OpenShell 是 NVIDIA 的开源安全运行时软件。它治理并监控 AI 智能体的所有行为，并为每一项操作执行策略。OpenShell 默认阻止一切操作，除非有规则明确允许。它会检查智能体尝试使用的每个工具，并对智能体访问的文件、网络连接和数据应用规则。规则在智能体之外执行，OpenShell 还会记录它允许或阻止的每一次决策。 

团队可以从较窄的权限开始，查看日志，并借助 Claude 将规则收紧到任务所需的最小访问权限。随后，OpenShell 的策略证明器（policy prover）会使用数学证明来确认：在团队编写的规则下，智能体究竟能访问到什么。 

Claude Managed Agents 包含哪些能力 

  • 生产级智能体：安全沙箱、身份认证与工具执行都由系统代为处理。 
  • 长时间运行的会话：可以自主运行数小时，即使连接中断，进度和输出也能保留下来。 
  • 多智能体编排：智能体可以拉起并指挥其他智能体，以并行处理复杂工作。 
  • 可信治理：让智能体访问真实系统，内置受限权限、身份管理和执行追踪。 

团队如何使用 Managed Agents 

  • Notion 让团队在自己的工作空间里把工作交给 Claude。工程师用它交付代码，其他员工用它制作网站和演示文稿。数十个任务可以并行运行，团队成员基于结果协同工作。 
  • Rakuten 在工程、产品、销售、市场营销和财务部门运行专业智能体，每个智能体都在一周内部署完成。 
  • Asana 打造了 AI Teammates——在 Asana 项目中与人们并肩工作的智能体，负责承接任务、起草交付物。借助 Managed Agents，团队以远超以往的速度添加了高级功能。 

可用性 

Managed Agents 现已可用。它可以运行在由你控制的沙箱中——既可以部署在你自己的基础设施上，也可以使用托管服务商。NVIDIA OpenShell 采用 Apache 2.0 许可证开源，可在 GitHub 和 NVIDIA 的开发者资源页面获取。

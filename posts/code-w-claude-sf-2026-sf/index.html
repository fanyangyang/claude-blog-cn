Code w/ Claude SF 2026 回顾：在 AI 指数级增长之上构建

阅读英文原文 →

本周，我们在旧金山举办了年度开发者大会 Code w/ Claude。来自各地的开发者、工程师和创业者齐聚一堂，与打造 Claude 的团队一起，进行了为期两天的主题演讲、分论坛和动手工作坊。 

从提示词技巧和模型选择，到 Skills 架构设计与AI 原生工程团队的规模化，每一场session都指向同一个转变：从想法到生产软件的距离正在缩短，而杠杆最大的团队正在为 AI 的指数级增长做设计——而不是被动应对。 

我们通过现场编程、客户深度分享和动手教程，展示了这一切今天的真实模样。

我们发布了什么

大会现场宣布，我们将 Claude Code 的速率限制翻倍，并上调了 Claude Opus 的 API 限额，让开发者、初创公司和企业能够更可靠地规模化构建。两项变更均已生效。

我们还为 Claude Platform 上的 Claude Managed Agents 推出了新能力，帮助团队大规模构建和部署云端托管的智能体。以下四项新功能现已向所有开发者开放：

  • Dreaming（做梦）。一个定时运行的过程，会回顾智能体过往的会话、提炼模式并整理记忆，让智能体在每次运行之间不断进步。反复出现的错误、共享的工作流和团队偏好都会被纳入一个更实用的记忆存储中。
  • 多智能体编排。一个主智能体可以把任务委派给多个并行工作的专家子智能体，它们共享同一个文件系统，各自拥有独立的模型、提示词和工具。整个流程都可以在 Claude Console 中追踪。
  • Outcomes（成果评估）。开发者定义"好的输出"的评分标准，一个独立的评分器会在自己的上下文窗口中评估每次结果，并让智能体反复修订，直到达标。在我们的内部基准测试中，Outcomes 在最难的问题上将任务成功率最多提升了 10 个百分点。
  • Webhooks：定义好 outcome 之后，你就可以放手让智能体运行，完成时通过 webhook 通知你。

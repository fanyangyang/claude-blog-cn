使用 Compliance API 审计 Claude Platform 活动

Compliance API 现已在 Claude Platform 上线，为管理员提供以编程方式访问组织审计日志的能力。安全与合规团队可以跟踪用户活动、监控配置变更，并将 Claude 使用数据接入其现有的合规基础设施。

面向整个组织的审计日志

受监管行业（如金融服务、医疗、法律）的组织需要详细的记录：谁在什么时间访问了什么、发生了哪些变更。如果无法通过编程方式获取这些数据，合规团队就只能依赖手动导出和定期审查，这种方式难以规模化。

Compliance API 提供一个活动流（activity feed），记录组织内与安全相关的事件。管理员可以按时间范围、特定用户或 API key 过滤并拉取活动日志。

该 API 目前追踪两类活动：

  • 管理与系统活动：修改资源访问权限或配置的操作，例如向工作区添加成员、创建 API key、更新账户设置或修改实体访问权限。
  • 资源活动：由用户发起、创建或修改资源数据的操作，例如创建文件、下载文件或删除 skill。这类活动涵盖可能影响数据或允许资源访问敏感信息的操作，但不包括与模型的直接交互。

两类活动合起来覆盖了用户登录与登出事件、账户设置更新、工作区变更以及其他组织审计事件。该 API 不会记录推理活动，例如用户与模型的交互或模型自身的活动。

开始使用

请联系你的客户团队，为组织开通 Compliance API。开通后，创建一个管理员 API key 并用它查询活动流端点。请注意，日志记录从 API 开通之时开始——在此之前的历史活动无法获取。

已为 Claude Enterprise 使用 Compliance API 的组织，可以将其 Claude API 组织加入同一个父组织之下，从而通过单一活动流同时过滤两者的活动。

请阅读 Anthropic Trust Center 上的文档了解更多信息。

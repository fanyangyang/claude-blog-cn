你喜爱的工作工具现已成为 Claude 内的交互式连接器

Open Asana, Slack, Figma, and more in chat with MCP Apps

    Product announcements

    Claude apps
  • Date

从今天起，我们通过 MCP Apps 为 Claude 带来交互式连接器。你可以在 Claude 中打开并直接操作各种工具：在 Asana 中构建和更新项目时间线；以格式化预览的方式起草、编辑和发送 Slack 消息；在 Figma 中把想法变成图表——这一切都无需切换标签页。

Claude 早已能连接你的工具并代你执行操作。现在，有了 MCP Apps，这些工具会以交互式连接器的形式直接出现在对话中，你可以实时看到正在发生什么并与之协作。
以下是你现在可以直接在 Claude 中完成的事情：

  • Amplitude——构建分析图表，然后交互式地探索趋势、调整参数，挖掘隐藏洞察。
  • ‍Asana——把聊天内容变成团队可以在 Asana 中查看和执行的项目、任务和时间线。
  • Box——搜索文件、行内预览文档，然后提取洞察并就内容提问。
  • Canva ——创建演示文稿大纲，然后实时定制品牌与设计，产出可直接交付客户的幻灯片。
  • Clay——调研公司、查找带邮箱和电话的联系人、提取公司规模和融资等数据，然后直接在对话中起草个性化的外联信息。
  • Figma——通过提示词在 FigJam 中把文字和图片变成流程图、甘特图或其他可视化图表。
  • Hex——提出数据问题，获得附带交互式图表、表格和引用来源的回答。
  • monday.com——管理你的工作、运行项目、更新看板、智能分配任务，并通过洞察可视化进度。
  • Slack（来自 Salesforce）——检索 Slack 对话获取上下文，生成消息草稿，按你的方式排版，发布前先审阅。

即将推出：Salesforce——通过 Agentforce 360 把企业上下文引入 Claude，让团队在一个统一的互联界面中推理、协作和行动。

MCP Apps：基于开放标准构建‍

其底层技术建立在 Model Context Protocol（MCP）之上——这是连接工具与 AI 应用的开放标准。MCP Apps 是 MCP 的一项全新扩展，让任何 MCP 服务器都能在任何支持它的 AI 产品（而不仅是 Claude）中提供带丰富用户界面的交互式连接器。

我们开源 MCP，是为了给整个生态一种将工具接入 AI 的通用方式。现在我们进一步扩展 MCP，让开发者能够在它之上构建交互式 UI，无论用户身在何处。 

了解更多，请阅读 MCP Apps——首个官方 MCP 扩展的发布公告。

开始使用

今天就可以在 Claude 中使用交互式连接器（MCP Apps）。前往 claude.ai/directory，在"featured"（精选）分区连接应用即可开始。适用于 Free、Pro、Max、Team、Enterprise 计划的 Claude 移动端、网页端和桌面端。现在也可在 Claude Cowork 中使用。‍

Claude in Chrome 现已全面可用

Give Claude a task in your browser, work across tabs, and continue the conversation in the desktop, mobile, and web apps.

Claude in Chrome 现在在所有付费 Claude 计划中全面可用。Claude 现在还可以在浏览器中自主执行操作，而无需每步都请求批准。一个安全分类器会在每个操作执行前进行验证，确保操作安全且符合你的请求。

许多你日常使用的工具已经与 Claude 连接。但还有更多工具没有，比如内部仪表盘、遗留系统和供应商门户。Claude in Chrome 让 Claude 也能访问这些工具。它可以查看你当前所在的页面，并执行阅读和输入文本、点击链接、页面间导航、填写表单等操作，使用你现有的登录状态。

我们去年首次以预览形式发布了 Claude in Chrome，以便在测试的同时加强我们对提示注入的防御：隐藏在网站、邮件或文档中的恶意指令，试图诱骗 AI 代理做出违背用户意愿的行为。下文描述的这些防御措施，给了我们让 Claude in Chrome 全面可用的信心。

防范提示注入

正如我们发布预览时所述，在浏览器中工作的 AI 代理也容易受到提示注入攻击。因此，在更广泛地发布 Claude in Chrome 之前，我们一直在改进安全防护措施。

在提示注入攻击中，恶意行为者将指令隐藏在网页、邮件或表单字段等网络内容中。你可能永远看不到这些指令，但它们可以指示代理执行你从未要求过的操作。例如，如果你让 Claude 起草邮件回复，一条消息中的隐藏指令可以告诉 Claude 将你的其他邮件转发给攻击者。

在发布时，我们描述了如何测试 Claude 对这些攻击的防御能力以及当时已有的防护措施；后来我们发布了关于浏览器使用安全防护的更详细描述。自那以后，我们改进了对模型和我们的探测器的训练方法，并增加了一组额外的分类器，使 Claude 能够在 Chrome 中更安全地执行更多自主操作。在下一节中，我们将讨论评估结果，这些结果展示了这些防护措施的有效性。

Claude 能识别更多攻击。我们针对不断增长的提示注入攻击库对 Claude 进行训练，这些攻击来自我们的内部自动化攻击器、外部红队测试和真实世界监控。当一种新的攻击在当前模型上成功时，它会被添加到攻击库中，用于指导未来模型的训练和我们部署的防御措施，使它们学会识别这种攻击。自 2025 年 11 月我们首次撰写关于浏览器使用的提示注入防御以来，我们已经使 Claude 对这些攻击的抵抗力大幅提升。

探测器在 Claude 对网络内容采取行动前进行筛查。网络内容通过工具结果到达 Claude。为了执行阅读页面或打开邮件等操作，模型会进行工具调用；工具结果让模型读取输出（本例中为页面或邮件的内容）。我们训练探测器扫描这些结果，寻找潜在的提示注入。当探测器检测到可能的攻击时，Claude 会收到警告，要求对内容保持怀疑，并在必要时在采取行动前与你确认。我们最初在 Claude Opus 4.5 中部署了这些探测器，此后扩展了它们覆盖的攻击类型。

操作在执行前经过验证。在 Claude in Chrome 中，Claude 现在会自动批准它判断为安全的操作，使用与 Claude Code 中的自动模式相同的机制。（如果你希望继续手动批准 Claude 的操作，可以在设置中关闭此功能。）一个分类器会审查 Claude 即将执行的操作，例如导航到新网站或在页面中输入文本，并与你最初的请求进行核对。如果操作与你的请求不匹配，它会被阻止。

衡量 Claude 对提示注入的鲁棒性

我们已经测试了这些防护措施，以确保 Claude in Chrome 在浏览器端工作时的安全性。以下是我们最新评估的结果。

在我们对 Claude Cowork 抵抗提示注入攻击能力的初始评估中（首次开发于我们发布 Claude in Chrome 预览时），在 Cowork 框架中，即使没有上面讨论的探测器和分类器，也没有任何攻击能成功针对 Claude Fable 5、Claude Opus 5 或 Claude Sonnet 5。

由于该评估已经饱和（0% 的成功率证明了这一点），我们决定停止使用它。在我们的当前评估中，使用了由专业红队人员提供的更强攻击，在没有任何额外防护措施的情况下，到达模型的攻击对 Opus 4.5 的成功率为 17.6%，对 Opus 5 为 3.8%。在 2025 年 11 月可用的最强防护措施下，运行探测器的 Opus 4.5 攻击成功率为 16.7%。而对于从 Opus 4.8 开始的每个模型，当运行探测器和安全分类器时，没有任何攻击能成功针对 Claude Sonnet 5、Claude Opus 5 或 Claude Mythos 5。我们观察到对 Fable 5 的攻击成功率为 0.3%。我们已经人工验证所有成功的突破都属于低严重性场景，并正在努力缓解这些问题。

提示注入仍然是一个不断变化的威胁。虽然这种方法可以防御当前的攻击，但我们还需要确保我们的防护措施领先于攻击者不断演化的方法。随着每个模型的发布，我们持续投资于开发更复杂的自动化攻击发现系统、红队测试，以及构建更强的分类器。

开始使用

要开始使用 Claude in Chrome，请从 Chrome Web Store 安装。在 Enterprise 计划中，管理员可以在组织设置中管理它，并将其限制在批准的域名范围内。请参阅管理员设置指南。

你仍然需要使用 Claude 桌面应用程序来处理计算机上的文件或其他应用程序。Claude in Chrome 目前不支持其他 Chromium 浏览器，也不支持移动端。

Message Batches API 介绍

阅读英文原文 →

更新：Message Batches API 现已在 Anthropic API 上正式发布（GA）。在 Amazon Bedrock 中使用 Claude 的客户可以使用批量推理（batch inference）。批量预测功能也已在 Google Cloud 的 Vertex AI 上进入预览阶段。（2024 年 12 月 17 日）

我们推出全新的 Message Batches API——一种强大且经济高效的方式，用于异步处理大批量查询。

开发者每个批次最多可提交 10,000 条查询。每个批次都会在 24 小时内处理完成，且成本比标准 API 调用低 50%。这让处理对时效性要求不高的任务变得更加高效、更具性价比。

Batches API 于今日在 Anthropic API 上进入公开测试阶段，支持 Claude 3.5 Sonnet、Claude 3 Opus 和 Claude 3 Haiku。在 Amazon Bedrock 中使用 Claude 的客户可以使用批量推理。Google Cloud Vertex AI 上的 Claude 的批处理支持也即将推出。

以一半的成本获得高吞吐量

开发者经常用 Claude 处理海量数据——从分析客户反馈到翻译语言——这些场景并不需要实时响应。

你无需管理复杂的队列系统，也不必担心速率限制，只需使用 Batches API 提交最多包含 10,000 条查询的批次，剩下的交由 Anthropic 处理，并享受 50% 的折扣。批次会在 24 小时内处理完成，通常实际耗时更短。其他优势包括：

  • 更强的吞吐能力：享有更高的速率限制，可以处理大得多的请求量，且不影响你的标准 API 速率限制。
  • 面向大数据的可扩展性：无需担心基础设施问题，即可应对大规模任务，例如数据集分析、大型数据集分类或大规模模型评估。

Batches API 为大规模数据处理解锁了新的可能性，而这类工作以前要么不太可行，要么成本过高。例如，分析整个企业文档库（可能涉及数百万个文件），借助我们的批量折扣，在经济上变得更加可行。

定价

Batches API 让你能够享受基础设施成本节约，输入和输出 token 均享有 50% 折扣。

客户聚焦：Quora

Quora 是一个以用户为基础的问答平台，他们利用 Anthropic 的 Batches API 进行摘要生成和高亮内容提取，以打造面向终端用户的新功能。

"Anthropic 的 Batches API 既节省了成本，又降低了运行大量无需实时处理的查询的复杂度，"Quora 产品经理 Andy Edmonds 表示。"提交一个批次，然后在 24 小时内下载结果，这非常方便，不用为了得到同样的结果而去应付大量并行实时查询的复杂性。这让我们的工程师有时间为更有意思的问题工作。"

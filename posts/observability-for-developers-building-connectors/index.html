监控、调试和改进连接器

目录中已发布的连接器现在拥有一个仪表盘，展示其在 Claude 各产品界面上的表现。连接器所有者可以用它来：

  • 追踪采用情况。监控活跃用户数、工具调用总量和目录排名随时间的变化。
  • 诊断错误与延迟。一目了然地查看健康分、错误率和延迟，并按工具细分的错误分布，快速定位问题所在。‍
  • 按产品拆解用量。对比 Claude、Claude Code、Cowork 等产品之间的工具调用，了解用户在哪里使用。

即日起以公开测试版提供。在 Claude 的组织设置中的Directory 里即可找到。需要 Team 或 Enterprise 计划的 Admin 或 Owner 权限。在 Enterprise 计划上，Owner 还可以通过具备目录管理或 Libraries 权限的自定义角色委派访问权限。

加入目录

连接器构建在Model Context Protocol (MCP) 之上。目录中已有 300 多个第三方连接器，每天都有数百万人使用。如果你希望将自己的 MCP 服务器提交到目录，现在可以直接在 Claude 中完成。 了解更多。

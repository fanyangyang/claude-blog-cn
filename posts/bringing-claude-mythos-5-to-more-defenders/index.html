将 Claude Mythos 5 的网络安全能力带给更多防御者

We’re sharing an update on our efforts to help more teams leverage frontier capabilities for cyber defense.

  • Category
    Product announcements
  • Date
    August 21, 2026
  • Reading time
    5 min
  • Share

我们在此分享帮助更多团队使用前沿能力进行网络防御的最新进展。Claude Mythos 5 现已登陆 Claude Security，并即将上线合作伙伴的网络安全防御工具。我们还启动了一项 3500 万美元的基金，用于帮助保护开源软件安全，并分享了扩展 Cyber Verification Program 的计划。

今年四月，我们启动了 Project Glasswing，将我们最强大的前沿模型 Claude Mythos Preview（及其后继者 Claude Mythos 5）交到一小批保护全球最关键软件的组织手中。这为防御者提供了一段窗口期，在具有类似能力的模型广泛可用或落入恶意行为者手中之前，发现并修复漏洞。

我们的目标始终是在安全的前提下，将 Mythos 级别的防御能力扩展到尽可能多的防御者手中。为此，我们一直在开发安全分类器和保护措施，以便在不将网络攻击能力交到错误的人手中的前提下，扩大 Mythos 级别模型的访问范围。Claude Fable 5 是第一步：它使模型广泛可用，同时阻止了双重用途的网络工作。

今天，我们迈出了下一步。最危险的行为发生在用户可以直接访问模型时，恶意行为者可以试图引导模型进行有害用途。但如果用户只能接收特定的输出，例如漏洞的补丁或安全警报，这种风险就低得多。我们宣布的以下变更，在保持对直接访问模型的适当防护的同时，让用户能够更多地访问防御性结果：

  • 将 Claude Mythos 5 集成到防御者信赖的工具中。我们正在与网络安全技术和服务合作伙伴合作，将 Claude Mythos 5 集成到防御者已用于保护其软件的产品和服务中。
  • Claude Security 扫描现在可以在 Claude Mythos 5 上运行。Claude Enterprise 计划的客户现在可以在 Claude Security 中运行我们最强大的模型，用于扫描其代码库中的安全漏洞并提出补丁建议。
  • 3500 万美元用于开源安全的信用额度。我们的新 Defender Advantage Fund（0xDAF）将提供 3500 万美元的信用额度，用于支持那些致力于修复开源项目漏洞、自动化扫描和修补开源软件流程以及尝试新的安全方法的组织。
  • 扩展我们的 Cyber Verification Program。该计划已经为经过审查的防御者提供了 Opus 和 Sonnet 模型的减少安全措施。在接下来的几周内，我们将扩展该计划，在 Opus 和 Sonnet 上纳入更广泛的双重用途能力，随后将推出 Mythos 级别的访问权限。

我们的目标仍然是帮助组织适应随着 AI 模型日益强大而不断变化的网络安全节奏和需求。我们将继续开发安全措施、访问计划和社区支持，以使我们最强大的模型能够安全地提供给广泛的个人和组织使用。

将 Mythos 集成到现有网络防御工具中

保护医院、公用事业、金融系统和软件供应链的团队已经在使用一套产品和服务来进行安全运营、事件响应、威胁情报和检测工程。将这些前沿能力提供给防御者的最快方式，就是将 Mythos 级别的模型集成到他们已经在使用的工具中。

我们的许多合作伙伴已经在 Claude Opus 上构建了网络安全产品，帮助安全团队更快地分类警报、识别威胁和修复漏洞。我们现在正在与这些合作伙伴及更多伙伴合作，将 Claude Mythos 5 构建到他们的产品和服务中，使他们能够向客户提供 Mythos 级别的防御能力。

当终端用户使用这些产品之一时，他们并不直接与 Mythos 交互。相反，他们通过一个专门构建的界面工作，该界面在后台为特定任务运行 Mythos，并且只接收产品旨在提供的特定输出。例如，一个修复漏洞的工具可能会提供一组建议的补丁作为输出。这些输出由 Mythos 生成，但用户无法提示模型去做例如开发漏洞利用程序之类的事情。我们和合作伙伴也采取了滥用预防措施，以确保模型保持在其预期的范围内。

这项工作还处于早期阶段，预计会随着时间的推移而扩展。如果你正在构建安全产品或服务，并希望将 Claude Mythos 5 带给你的客户，可以在此注册你的兴趣。

为 Enterprise 客户提供 Claude Security 与 Claude Mythos 5

从今天开始，Claude Security 扫描现在可以在 Claude Mythos 5 上运行。Claude Security 扫描代码库中的漏洞并建议补丁供人工审查；它目前处于公开测试阶段，适用于 Claude Enterprise 客户，使用 Mythos 5 进行扫描按你现有计划的标准 token 用量计费，无需单独加购。

Enterprise 管理员可以在管理控制台中启用 Claude Security。从 claude.ai/security，用户可以选择一个仓库使用 Claude Mythos 5 进行扫描。然后 Claude 扫描代码库中的漏洞，返回每个发现的 CWE 分类、置信度和严重性评级，以及建议的修复方案。

用户随后可以在 Web 上打开 Claude Code 来实施修复。交互式补丁使用你组织在 Claude Code 中有权访问的模型。Mythos 扫描本身不会将 Mythos 访问权限扩展到其他界面。每个补丁在实施前必须经过人工审查和批准。

Claude Security 使用 Mythos 5 扫描你拥有的代码，返回详细的发现结果而非原始输出，而不暴露模型本身。这意味着防御者可以访问 Claude Mythos 5 的能力，同时防止模型被可能滥用它的人访问。

有关 Claude Security 的更多信息，请参阅我们的入门指南。

启动 Defender Advantage Fund 以保护开源软件

世界上一些最广泛使用的程序都运行在开源软件上。然而，这些项目通常由志愿者或非营利基金会维护，他们可能缺乏资源或人员来全面保护其项目免受攻击。通过 Project Glasswing，我们向开源安全组织提供了 400 万美元的直接捐赠，向该计划中的开源安全基金会提供了信用额度，帮助扫描和修补了广泛使用的项目，并支持了像 Akrites 和 Gold Eagle 这样的协作漏洞修复工作。

我们的新 Defender Advantage Fund（0xDAF）在此基础上，提供 3500 万美元的 Claude 信用额度，用于帮助开源维护者保护其软件的组织。资助将集中在三个领域：修复广泛使用的项目中的活跃漏洞，以可复制的方式自动化扫描和修补流程，以及帮助项目追求更雄心勃勃的安全方案，使其能够抵御整类攻击。

我们将从少量较大规模的试点资助开始，以了解什么最有效且最可扩展。我们将在未来几周内分享首批受助者的详细信息。

扩展我们的 Cyber Verification Program

迄今为止，我们的 Cyber Verification Program 已为组织提供了使用 Claude Opus 和 Sonnet 模型时的双重用途能力访问权限。该计划中的组织会体验到减少的安全措施，从而减少对授权保护系统的合法网络安全工作的中断。

在接下来的几周内，我们将对该计划进行演进，扩展 Claude Mythos 的安全访问权限。作为其中的一部分，漏洞分类和验证等防御能力的访问权限将扩展到 Mythos 级别的模型，而网络防御者将看到 Claude Opus 和 Sonnet 级别模型的拦截减少。此外，我们继续通过与美国政府合作伙伴的合作，通过 Project Glasswing 扩展 Claude Mythos 的访问权限，重点关注那些满足严格安全控制要求的关键基础设施保护者。

我们将在未来几周内分享更多关于 Cyber Verification Program 扩展的详细信息。与此同时，我们鼓励所有执行合法网络安全工作的安全团队申请该计划，以获得 Claude Opus 和 Sonnet 模型的减少安全措施。如果你已经注册并被接受，则无需任何操作；我们会主动联系你提供更新信息。

下一步计划

这些举措是我们持续努力的一部分，旨在让更多个人和组织能够使用前沿模型的防御能力，并支持开源社区加强其项目抵御攻击的能力。我们将继续与政府合作伙伴、组织、开源维护者和更广泛的行业合作，构建当今强大 AI 模型所需的弹性网络基础设施。

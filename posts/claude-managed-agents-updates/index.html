Claude 托管代理新功能：自托管沙箱和 MCP 隧道

阅读英文原文 →

Claude 托管代理迎来重要更新，新增自托管沙箱和 MCP 隧道支持。这些功能让企业能够在自己的基础设施中运行 Claude 代理，同时保持与外部工具和服务的连接。

自托管沙箱

自托管沙箱允许企业在自己的基础设施中运行 Claude 代理的执行环境，满足安全性和合规性要求。代理代码在企业自己的环境中执行，数据不会离开企业网络。

MCP 隧道

MCP 隧道让托管代理可以安全地连接到企业内部的 MCP 服务器，访问内部数据库、API 和服务，而无需公开暴露这些服务。

企业优势

  • 数据主权：代理执行和数据保留在企业基础设施内
  • 合规性：满足严格的安全和监管要求
  • 灵活集成：通过 MCP 隧道连接内部系统

Anthropic 团队如何使用 Claude Code

Teams across Anthropic use Claude Code for everything from debugging production issues and navigating unfamiliar codebases to building custom automation tools. Here's how.

像 Claude Code 这样的智能体编程工具可以帮助开发者加速工作流、自动化重复性任务，并攻克复杂的编程项目。随着这个领域的不断发展，我们每天都在从用户——包括我们自己的员工——身上学到新的应用方式。

为了了解更多，我们与 Anthropic 各个团队的员工进行了深入交流，了解他们如何在工作使用 Claude Code。

虽然他们的许多用例在预料之中——调试、理解代码库、管理工作流——但另一些让我们大吃一惊。法务团队搭建了电话分流系统。营销人员在几秒钟内生成了数百个广告变体。数据科学家在不了解 JavaScript 的情况下创建了复杂的可视化。

规律逐渐清晰：智能体编程不仅仅是加速传统开发。它正在消融技术与非技术工作之间的边界，让任何能够描述问题的人，都能成为可以构建解决方案的人。

以下是我们的发现。

代码库导航与理解

公司各部门的团队都在使用 Claude Code 帮助新员工甚至资深员工快速熟悉我们的代码库。

基础设施团队的新数据科学家会将整个代码库交给 Claude Code，以快速进入工作状态。Claude 会阅读代码库的 CLAUDE.md 文件、识别相关内容、解释数据管道的依赖关系，并展示哪些上游数据源汇入了各个仪表盘，从而取代传统的数据目录工具。

产品工程团队将 Claude Code 称为他们处理任何编程任务的"第一站"。他们会请它指出修复 Bug、开发功能或进行分析需要查看哪些文件，省去了在构建新功能之前手动收集上下文的耗时过程。

测试与代码审查

智能体编程工具之所以广受欢迎，很大程度上在于它们能够自动化两项关键却枯燥的编程任务：编写单元测试和审查代码。

产品设计团队使用 Claude Code 为新功能编写全面的测试。他们通过 GitHub Actions 自动化了 Pull Request 评论，由 Claude 自动处理格式问题和测试用例重构。

安全工程团队将他们的工作流从"设计文档 → 粗糙的代码 → 重构 → 放弃写测试"转变为：先向 Claude 要伪代码，引导它进行测试驱动开发，并定期检查进展。这样产出的代码更可靠、更可测试。

智能体编程还可以用来将测试翻译成其他编程语言。例如，当推理团队需要用 Rust 这类不熟悉的语言测试功能时，他们只需描述想要测试的内容，Claude 就会用代码库的原生语言编写相应逻辑。

调试与故障排查

生产环境的问题需要快速解决，但在压力下理解陌生代码往往会导致延误。对公司里的许多团队来说，Claude Code 通过实时分析堆栈跟踪、文档和系统行为，加快了诊断和修复的速度。

在事故发生时，安全工程团队会将堆栈跟踪和文档输入 Claude Code，让它追踪代码库中的控制流。通常需要 10-15 分钟人工排查的问题，现在解决速度提升了 3 倍。

借助 Claude Code，产品工程团队有信心去处理陌生代码库中的 Bug。他们会问 Claude："你能修复这个 Bug 吗？这是我观察到的行为"，然后审查它提出的解决方案，无需再依赖其他工程团队的协助。

在一个案例中，当 Kubernetes 集群停止调度 Pod 时，数据基础设施团队使用 Claude Code 诊断问题。他们将仪表盘截图喂给 Claude，Claude 带着他们在 Google Cloud 的界面中逐级菜单排查，最终发现是 Pod IP 地址耗尽。随后 Claude 提供了创建新 IP 池并将其添加到集群的确切命令，在系统宕机期间为他们节省了 20 分钟的宝贵时间。

原型设计与功能开发

构建新功能传统上需要深厚的技术知识和大量的时间投入。Claude Code 支持快速原型设计乃至完整的应用开发，让团队无论编程水平如何，都能快速验证想法。

产品设计团队的成员会将 Figma 设计文件交给 Claude Code，然后设置自主循环，让 Claude Code 为新功能编写代码、运行测试并持续迭代。他们给 Claude 抽象的问题，让它自主工作，然后在最终完善之前审查解决方案。有一次，他们让 Claude 以极少的人工审查为它自己构建了 Vim 快捷键。

产品设计团队还发现了 Claude Code 的一个意想不到的用法：在设计阶段就梳理错误状态、逻辑流程和系统状态，从而识别边界情况，而不是等到开发时才发现。这从根本上提升了他们的初始设计质量，也省去了之后数小时的调试时间。

数据科学家虽然不精通 TypeScript，但可以用 Claude Code 构建完整的 React 应用来可视化 RL 模型的性能。在沙盒环境中通过一次提示后，工具就能从零开始编写完整的 TypeScript 可视化，而他们自己并不需要理解这些代码。由于任务本身并不复杂，如果第一次提示效果不理想，他们稍作调整后再试一次即可。

文档与知识管理

技术文档常常分散在 Wiki、代码注释和团队成员的脑海中。Claude Code 借助 MCP 和 CLAUDE.md 文件将这些知识整合成易于获取的形式，让每个需要的人都能用上这些专业知识。

推理团队中没有机器学习背景的成员依靠 Claude 来解释模型相关的函数。原本需要一个小时 Google 检索的工作，现在只需 10-20 分钟——研究时间减少了 80%。

安全工程团队让 Claude 摄取多个文档来源，生成 Markdown 格式的操作手册（runbook）和故障排查指南。这些精炼的文档会成为调试真实生产问题时的上下文，往往比检索完整的知识库更高效。

自动化与工作流优化

智能体编程工具帮助团队构建定制化的自动化流程，这类工作以往需要专门的开发资源或昂贵的软件。

增长营销团队构建了一个智能体工作流，可以处理包含数百个广告的 CSV 文件，识别表现不佳的广告，并在严格的字符限制内生成新的变体。借助两个专门的子智能体，该系统几分钟内就能生成数百个新广告，而过去则需要数小时。

他们还开发了一个 Figma 插件，能够识别画板（frame），并通过替换标题和描述以程序化方式生成多达 100 个广告变体，把数小时的复制粘贴工作缩短到每批广告只需半秒钟。

在一个尤为独特的用例中，法务团队创建了原型"电话分流"系统，帮助团队成员找到 Anthropic 内部合适的律师，展示了各部门如何在没有传统开发资源的情况下构建自己的定制工具。

用 Claude Code 释放更多可能

这些故事揭示了一个规律：当你把注意力放在 Claude Code 能够增强的人工工作流上时，它的效果最好。最成功的团队将 Claude Code 视为思考伙伴，而不仅仅是代码生成器。

他们探索各种可能性、快速制作原型，并在技术和非技术用户之间分享发现。这种人机协作的方式正在创造我们才刚刚开始理解的机会。

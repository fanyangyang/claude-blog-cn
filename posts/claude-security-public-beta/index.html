Claude Security 现已面向 Claude Enterprise 客户开启公开测试。

AI 的网络安全能力正在快速进步。当今的模型已经非常擅长发现软件代码中的缺陷；下一代模型的能力还会更强，尤其擅长自主利用这些缺陷。现在正是各组织采取行动提升安全水平的时机，为"可用的软件漏洞利用变得更容易被发现"的世界做好准备。 

近期，我们通过 Project Glasswing 向多家合作伙伴开放了 Claude Mythos Preview——它在发现和利用软件漏洞两方面都能比肩甚至超越顶级人类专家。 

但我们的网络安全工作不止于 Glasswing：借助 Claude Security，更多组织可以让最强大的通用模型 Claude Opus 4.7 在他们的代码库中大显身手。在发现和修补软件漏洞、以及挖掘那些容易被遗漏的复杂上下文依赖问题方面，Opus 4.7 位居最强模型之列。

Claude Security（前身为 Claude Code Security）在有限的研究预览阶段已被数百家各种规模的组织试用，帮助团队扫描代码库中的漏洞并生成针对性补丁。他们的反馈塑造了今天的正式版本：Claude Security 现已向所有 Enterprise 客户开放，并带来了定时扫描和定向扫描、更便捷的审计系统集成，以及更完善的分级结果跟踪。无需 API 集成，也无需自建智能体：只要你的组织在用 Claude，今天就可以开始扫描。

Opus 4.7 的能力也正通过 Claude 与众多企业既有软件工具的集成，传递给网络防御者。我们的技术合作伙伴，包括 CrowdStrike、Microsoft Security、Palo Alto Networks、SentinelOne、TrendAI 和 Wiz，正在把 Opus 4.7 嵌入他们的工具；此外，Accenture、BCG、Deloitte、Infosys 和 PwC 等服务合作伙伴也在帮助各组织部署集成了 Claude 的安全解决方案。

我们正进入网络安全的关键时期。AI 正在压缩从发现漏洞到利用漏洞之间的时间窗口。我们认为正确的应对之道，是确保防御者能以对他们来说最容易获取的方式用上前沿能力——直接通过 Claude，或通过我们的合作伙伴。

Claude Security 的工作方式

Claude Security 可以直接从 Claude.ai 侧边栏进入，或访问 claude.ai/security。开始时，选择你的一个代码仓库（也可以限定到特定目录或分支），然后启动扫描。 

扫描过程中，Claude 对代码的推理方式很像一位安全研究员。它不是通过检索已知模式来查找漏洞，而是努力理解各个组件如何跨文件和模块交互，追踪数据流，并阅读源代码。 

扫描完成后，Claude 会对每个发现给出详细解释，包括它对该漏洞真实存在的置信度、严重程度、可能的影响，以及如何复现。它还会生成针对性补丁的说明，用户可以在 Claude Code on the Web 中打开，结合上下文完成修复。

初次预览以来我们学到的事

过去两个月里，我们根据数百家企业在生产环境中的使用反馈，对 Claude Security 进行了打磨。具体来说，我们发现：

检测质量高于一切。团队告诉我们，高置信度的发现才真正能加速安全工作。Claude Security 的多阶段验证流水线会在每条结果送抵分析师之前独立核查，从而压低误报率，而且 Claude 会为每个结果附上置信度评级。这意味着到达团队手中的信号是值得行动的。

从扫描到修复的时间才是关键指标。早期用户反复强调这一点，好几个团队已经可以一次性完成从扫描到打补丁，而不用在安全团队和工程团队之间来回拉锯好几天。

团队要的是持续覆盖，而不是一次性审计。我们新增了定时扫描选项，团队可以围绕审查和处理发现建立固定节奏。

在这次发布中，我们还加入了以下能力：针对仓库内特定目录进行定向扫描；以书面理由驳回发现（让后续审查者可以信任之前的分级决策）；将发现导出为 CSV 或 Markdown，对接现有的跟踪和审计系统；以及通过 webhook 把扫描结果发送到 Slack、Jira 等工具。

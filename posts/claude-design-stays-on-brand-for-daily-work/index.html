Claude Design：日常工作中始终保持品牌一致

阅读英文原文 →

Claude Design 现在能跨项目恪守你的设计系统，与 Claude Code 顺畅协作，支持直接在画布上编辑，并连接到更多你已经在用的工具。它在 Claude 桌面应用侧栏中有了新家：https://claude.com/product/design

我们的目标一如既往：让你探索比截止日期通常所允许的更多方向，并让从设计到打磨或构建的交接尽可能无缝。如今，这一目标服务于更多的人。Claude Design 上线首周就有超过一百万人使用，你的反馈正在塑造我们接下来构建的方向。

用你的设计系统组件来构建

我们重构了设计系统导入，为你提供更大的灵活性和更高的精度。可以从 GitHub 仓库、设计文件或直接上传的方式引入一个或多个设计系统。Claude 用你的组件来构建，依据你的设计系统检查产出，并在你看到之前完成修正。对于较大的团队，新增的管理员角色可以批准一套标准系统并锁定编辑权限，确保产出始终符合公司规范。

在设计与代码之间穿梭

相关更新于今天推出，在 Claude Design 和 Claude Code 之间切换工作变得更加容易，且工作内容保持同步。使用 /design-sync 引入你的设计系统，这样你在 Claude Design 中构建的一切都从你现有的组件出发。当设计准备变成软件时，你可以把它交给 Claude Code，它会基于你现有的工作继续，而不是从一张截图从头再来。

更喜欢从 Claude Code 开始？使用 /design，无需离开终端即可创建、编辑和同步设计项目。把设计导入你的代码库，把代码变成可交互的原型，或者让 Claude 把项目一路做到底。

"Claude Design 让我同时拥有前沿模型的智能和久经考验的设计工具的功能与能力。每当我为 Tenex 的网站、新品牌资产或演示文稿做设计方向时，Claude Design 都是我的第一站。平易近人的 UX 加上出色的品味和设计直觉，正是它成为我技术栈核心部分的原因。而 Claude Design 与 Claude Code 之间的交接，让从原型到生产的过程完全无缝。"
- Alex Lieberman，Morning Brew 与 Tenex 联合创始人

为日常工作更加稳定

全新编辑器让你可以直接、精细地控制设计中的每个元素。全新而丰富的布局控件让你可以拖拽、缩放和对齐元素。数百项稳定性修复让编辑器经得起真实使用的考验。

Claude Design 现在还与对话、Claude Cowork 和 Claude Code 共享使用额度，因此大多数人会获得大得多的创作空间，触达上限的频率也会降低。平均每轮对话以更少的 token 达成相同的效果，错误也大幅减少。

从画布到你使用的工具

可靠地导出为 PDF 和 PowerPoint，或把作品发送到你已经在用的应用——连接器列表现已包括 Adobe、Base44、Canva、Gamma、Lovable、Miro、Replit、Vercel 和 Wix，更多目的地即将上线。

使用 Claude 构建电商智能体

在 Claude 上运行购物智能体的零售商看到购物车最多增大 35%，购物者完成购买的可能性提高 60%。

世界上许多最大的零售商、市场平台、电商平台和旅游公司都在使用 Claude 构建让购物更轻松的智能体。像 Shopify、Priceline 等企业客户拥有的智能体可以让消费者用自然语言搜索他们想要的商品，找到它、比较它并购买它。

今天，我们发布了一个蓝图，帮助在 Claude 上构建电商智能体。它包含工程团队在几天内运行电商智能体所需的框架、模式和防护措施，以及针对零售、旅游、电信和票务平台的购物智能体和商家智能体的参考实现。它还包括一个 Claude Code 插件来帮助你开始。

该代码可以部署在你已经使用 Claude 构建的地方，包括 Claude API、Amazon Bedrock、Microsoft Foundry 或 Google Cloud Vertex AI。你也可以与我们的解决方案和生态系统合作伙伴（如 Accenture、Mastercard 和 Visa）合作，他们正在与我们合作，使客户和商家社区能够利用这些蓝图。

它今天已经可用，每个垂直领域都有在线演示，还有一篇关于如何构建它的工程深度解析，正好赶上假日季节规划。

蓝图包含什么

该仓库包含购物智能体和商家智能体的完整工作实现，可以使用 Messages API、Agent SDK 或 Claude Managed Agents（测试版）构建。你可以在编写任何代码之前在自助演示中看到它们的运行情况，然后使用 Claude Code 根据你的目录、政策、品牌等进行定制。

购物智能体

购物智能体位于你的应用或网站内。蓝图包括目录、购物车、结账、客户偏好和订单历史的集成点，并将支付留给你，无论是你现有的结账还是智能体支付提供商。

客户可以说"我需要一个帐篷、睡袋和炉子，带两个孩子周末旅行用"，智能体可以从那里开始处理。以下是它可以做的事情：

  • 搜索目录并组装正确的商品集，包括多商品请求。
  • 记住客户的偏好并定制它建议的内容。
  • 在对话中直接展示产品、比较和购物车，而不仅仅是文本。
  • 构建购物车并提交到结账。
  • 在同一对话中回答客户服务问题，比如订单在哪里、如何退货或换货、退款政策是什么，而不是将客户发送到支持页面。

该智能体具有防护措施，旨在将价格和产品限制为实际目录数据，并避免操纵性的追加销售模式。在仓库中，这些是用于目录搜索、多商品规划、深度研究、个性化、客户服务和对话内 UI 的技能和工具。

商家智能体

商家智能体支持经营商店的人。用户可以问"我们应该打折什么来清理上季的库存？"并根据他们自己的数据得到答案。以下是它可以做的事情：

  • 回答关于销售业绩的问题，比如什么在卖什么不在卖。
  • 跟踪库存并主动标记问题，比如在促销开始前即将售罄的商品。
  • 根据商店自己的销售历史推荐定价和促销。
  • 起草营销活动以推动需要移动的产品。

当智能体主动建议更改时，人员会在任何内容上线之前批准它，这意味着用户在智能体监视商店时拥有最终决定权。在仓库中，这些功能作为销售分析、目录和库存管理、营销和促销以及门户内 UI（如图表和仪表板）的技能提供。
